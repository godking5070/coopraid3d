- 실제 LAN/Steam 연결, 두 계정 친구 초대·재접속·AI 인계. 가짜 transport/정책 검사는 실제 연결 성공을 의미하지 않는다.
- 이유: 사용자 원본 프로젝트를 변경/실행하지 않고 작업용 Unity 실행 금지 규칙을 지켰다.
  실제 Steam 다중 계정 테스트도 이번 세션에서 실행하지 않았다.
- 기존 보스 패턴은 CombatCounterTarget.OpenWindow를 호출하지 않는다. 일반 가드/반격은 사용 가능하지만,
  자연 발생 COUNTER 성공은 패턴 담당자가 명시적 창을 연결해야 한다. 이번에는 신규 패턴을 추가하지 않았다.
- 빈 역할의 기본 봇은 기존 테스트 직업이다. 팔라딘 사용자의 AI 임시 대체만 같은 팔라딘 상태로 전환한다.
- R/F/V와 새 카드 콘텐츠는 의도적으로 미구현/잠김 유지. 테스트 도구도 실행 코드 없는 슬롯을 해금하지 않는다.

6. 원본 Unity에서 확인 순서
1) 원본의 미커밋 작업을 보존한 뒤, 검토한 이번 브랜치 변경을 원본에 반영한다. 이번 작업은 자동 병합하지 않았다.
   작업 폴더를 Unity로 열지 말고 원본 C:/coopraid/coopraid3d에서 컴파일/테스트한다.
2) 싱글플레이 직업 선택창의 별도 '이지스 팔라딘' 버튼 -> 기원 선택 -> 출발.
   '가디언(탱커)'는 기존 테스트 직업이다. 멀티 최초 로비에서는 '이지스 팔라딘 · 직업 / 기원 선택'을 사용한다.
3) 출발 전 3루트를 반복 선택: HP3000/3600, 방어100/120, 속도7.02, 거리2.8m/2충전 확인.
   X 포션과 Q 방어, 타겟 클릭/우클릭 회전, 변경한 실제 키 안내를 확인한다.
4) 1/2를 교대로 사용하여 공유 GCD와 각 콤보 유지 확인. 사거리 밖/죽은 대상에 비용·CD·콤보 변화 없음 확인.
   2충전 대쉬, 얇은 벽/전장 경계/대각선, 4번 짧은 돌진 중 구출/넉백/이동하는 장애물을 확인한다.
5) 성벽: 2번 3타 540보호막, Z1080(수신자 상한 적용), 4초 면역과 만료 확인.
   Q 전/후 피해·남은 부채와 10초 상환, Q 종료 후 상환·사망·재도전 정리 확인.
6) 집행관: 성광100 Z -> 8초/12m/3m 광역/방패의 보조검 변형/GCD 가속 확인.
   쫄 여러 마리에도 3타 성광 +15/보호막/CD 감소는 1회. 종료 후 3m와 기본 외형/간격 복원.
7) 거울방패: 성광30 Z -> 전방 평타/탱크버스터 가드, 옆/후방/장판/Q 상환은 정상 피해.
   첫 충격파 1회, 후속 가드의 성광/반사1초 ICD, 6m 범위 피해와 기록 확인.
8) 빠른 검증은 Unity 상단 Raid Rogue > 스킬 테스트: 성광 채우기, 구현 슬롯 해금, 직업 CD/GCD 초기화.
   사망/클라이언트에서는 적용 불가. R/F/V는 미구현 유지. 선택한 적 카운터 테스트 창 3초를 연 뒤
   적 정면에서 4번 또는 가드를 성공시켜 살아 있는 파티의 Space 충전 전체 복구를 확인한다.

   사망 성광 유지/부채·변신·가드 제거, 재도전 기원/카드 유지와 자원0/충전 초기화 확인.
10) 원본에서 만든 같은 프로토콜9 테스트 빌드 또는 원본의 지원 다중 플레이어 기능으로 호스트+클라이언트 실행.
    호스트/클라이언트 팔라딘을 각각 확인: 피해·CD·성광·보호막·반사·파티 충전 복구가 한 번만 적용되는지 비교.

7. 다음 R/F 구현 연결점
- 기존 CharacterSlot.Active(R)/OffGcd2(F), CharacterDefinition.unlocks의 afterStage/choices,
  CharacterActor.Choose/기존 호스트 sequence·epoch·lease 검증을 재사용한다.
- 새로운 비용/충전/쿨타임은 기존 CharacterRuntimeState, 루트 보정은 실행 상태/공통 계산에 추가한다.
- 피해는 원 소유자/스킬 ID/CombatDamageKind를 유지하고 파생 공격을 Direct로 되먹임하지 않는다.
  같은 공격 콜백은 같은 CombatHitContext.EventId를 재사용한다.
- 지속 효과를 추가할 때 AegisStateSnapshot 검증/복구, 죽음/재도전/새 런 정리와 UI/AI를 함께 연결한다.
- 방어/강인함 평점·돌진·충격파 임시값은 실제 플레이 후 조정 가능. 신규 보스의 카운터 가능 창은 패턴 작업에서 명시한다.

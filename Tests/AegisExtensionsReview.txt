4. 확정 피해 처리 순서와 중복 방지
1) 기존 생존/전투 상태, 공격 EventId 중복, 부활 보호/전투 무적 검사.
2) 원래 대상의 방어와 기존 방어기 계산. 날개/성역 감소는 곱연산(동시 0.4 * 0.8), 여러 날개는 1회.
3) 원래 대상의 유효 저스트 가드. 가드되면 피해 이전 없음.
4) 유효 개입 보호자가 있으면 여기서 확정 수치의 50%를 한 보호자에게 이전.
5) 원래 대상: 남은 50% -> 자신의 보호막 -> Q 즉시/지연 분할 -> HP.
6) 보호자: Transfer 분류의 확정 50% -> 자신의 보호막 -> Q 분할 -> HP.
   방어/DR/가드 재계산, 재이전, 반사, 성광 획득을 하지 않는다. 양쪽 개입도 왕복하지 않는다.
   보호자 무적/부활 보호는 기존 피해 차단 단계에서 적용한다.
7) Q 지연 상환은 기존 직접 HP 경로로 수행, 보호막/DR/이전/반사로 되돌리지 않는다.
   엑스칼리버 완전 전투 무적은 그 시간의 지연 상환 피해도 차단한다. System 판정은 새 무적에 포함하지 않는다.
- 보호막 흡수 집계는 제공자별 기존 원장을 사용한다. 이전 피해 흡수도 흡수 기록은 남지만 성광/반사 트리거는 제외.
- 공격/지속 피해/회복은 기존 적 HP 함수와 ReceiveHeal을 사용하고 실제 적용량을 기존 미터기가 기록한다.
- 네트워크 replica는 장판 타이머/선택/버프를 상태로 복구하며 효과 핸들러나 과거 틱을 실행하지 않는다.
  장판/날개/개입/낙인/궁극기 버프는 서버 절대 종료 시각 기준이다.

   보상으로 이미 확정한 슬롯은 테스트 교체도 거부한다. 다른 후보는 새 런에서 테스트한다.
   이 테스트는 실제 클리어/보상 원장을 조작하지 않으며 플레이어 빌드에는 에디터 창이 없다.
   필요할 때 직업 스킬 쿨타임+GCD 초기화 사용. 현재 활성 효과는 초기화 버튼만으로 재발동하지 않는다.
5) R 각각:
   빛창: 멀리 있는 보스/쫄, 사거리 안/밖, 무력화. 밖에서는 CD 없음.
   대지: 장판 설치 후 이동, 아군/적 진입·이탈, 사망자/풀 HP 제외, 8틱 종료 및 미터기 유효 힐 비교.
   날개: 시작 방향 반대쪽 부채 안/밖의 다른 아군 피해 비교(기본의40%), 자신의 피해에는 미적용.
     WASD로 채널이 움직이지 않고 성공한 Space 및 강제 이동에는 끝나며 효과가 남지 않는지 확인.
6) F 각각:
   개입: 아군 선택, 자기/사망자/원거리/벽 너머 실패, 접근 후 겹침/전장 이탈 없음.
     대상과 보호자에게 들어간 피해·보호막·Q 잔액 합계를 비교. 보호자 사망/대상 제거 시 연결 해제.
   낙인: 대상 상태와6초 종료 표시, 파티 공격에서 치명 추가(확률 효과이므로 여러 번 관찰).
   응징: 보호막 0 거부, 현재 보호막의200% 기준 피해, 보호막 보존, 전방 밖 적 제외,
     성벽의 이미 강화된 보호막에 1.5를 다시 곱하지 않는지 확인.
7) V 각각 (현재 런의 전투는 Stage3으로 끝나므로 전투 중 에디터 테스트 장착 사용):
   A: 즉시 큰 타격, 자기만3초 무적/이후 정상 피해, 사망자/다른 파티원에는 무적/부활 없음.
   B: 생존 파티10초 공격력+10%/피해20%감소, 기존 날개와 곱연산, 종료 후 원복.
   Z 성광을 채우지 않아도 사용 가능해야 한다. 두 종류 동시 장착 불가,120초 개별 CD.
8) 각 기원에서 기본 1/2/3/4/Q/E/Space/X/Z와 함께 사용한다.
   변신이 R/F/V를 교체하지 않고, R/F/V 틱/파생 피해가 태양 불꽃/성광/반사를 재귀 생성하지 않는지 확인.
9) 원본에서 만든 같은 프로토콜10 테스트 빌드 또는 원본의 지원 다중 플레이어 기능으로 호스트/클라이언트 실행.
   팔라딘은 기존 탱커 한 자리 정책으로 호스트/클라이언트가 번갈아 선택하여 검사한다.
   선택 결과·CD·장판/부채/연결·버프 남은 시간·피해/힐/미터기가 각 화면에서 같은지 확인.
10) 서로 다른 Steam 계정으로 장판/개입/궁극기 도중 팔라딘 연결을 끊고60초 내 복귀.
    AI가 동일 캐릭터와 선택 스킬로 행동, 복귀는 현재 남은 효과만 표시, 과거 틱/힐/보상이 재실행되지 않아야 한다.
    카드/스킬 선택 중 끊어15초 후 첫 후보 자동 선택, 복귀 안내, 재접속 중 재도전/다음 단계도 확인.
11) 전멸/재도전, 메뉴/새 런 반복. 이전 장판·연결·무적/버프·해금 기록·입력 차단이 남지 않아야 한다.

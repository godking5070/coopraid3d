2. 사용 방법
원본에 검토한 변경을 반영한 뒤 기존 자동 구성 씬에서 Play → 메인 메뉴 [훈련장].
현재 열려 있는 원본 브랜치에는 이 변경을 반영하지 않았으므로 아직 버튼이 나오지 않는다.
훈련장은 로컬 전용이다. 호스트/클라이언트 세션이나 진행 중인 런에서 진입할 수 없다.
정규 RunFlow는 Lobby에 유지되고 클리어/보상/해금 호출을 차단한다.
파일 저장이나 영구 해금/재화/카드 보상 지급을 하지 않는다. 기존 로컬 설정은 그대로 쓴다.
기존 SceneAutoBuilder의 바닥·카메라·플레이어·3명 아군·타겟 링·HUD를 재사용한다.
추가 표적, 패널과 예고선은 런타임 생성하므로 인스펙터 연결이 없다.

구성 탭:
  12직업 → 3기원 → R 3후보 → F 3후보 → V A/B → 진화 없음/극복/극대화.
  각 항목을 누르면 즉시 적용한다. 모든 슬롯의 실제 바인딩, 설명, 수치 표시.
  구성 변경은 새로운 플레이어별 실행 상태를 만들며 이전 장판/채널/연결/시전/보호막을 정리한다.
  훈련 해금은 PreviewSkillChoice를 사용하며 가짜 스테이지 클리어나 보상 이력을 만들지 않는다.
  구현 표시와 실행기 등록이 없는 후보는 비활성 표시한다.
시험 탭:
  일반/강타/파티 광역/카운터/정화 가능 속박/일반 넉백/투사체/시스템 피해.
  선택한 살아 있는 아군을 공격하며 아군 선택이 없으면 자신을 공격한다. 광역은 파티 전원.
  피해 1~10000, 반복 2~30초. 시작과 반복마다 1.5초 예고, 정지 즉시 예약 취소.
  기본 피해 300, 강타 선택 시 1200, 기본 반복 간격 4초. 패널에서 변경 가능.
  강타는 현존 탱크버스터와 같은 Direct 분류이며 독립 보스 패턴을 추가하지 않았다.
  시스템 피해는 일반 가드/반사 제외 경로, 투사체는 기존 Projectile 방어 연결점 시험이다.
  표적 1개/3개, 느린 이동, 위치/방향 초기화. 표적 HP 1,000,000 및 매 프레임 복원.
  아군 HP 25/75%, 보호막 제거, HP 50%+정화 속박, 가까이/멀리 배치.
  HP·자원 복원, 직업 GCD/CD/이동기 충전 복구, 전투 기록 초기화, 구성 유지 전체 초기화.

  위치 초기화는 이동/시전만 중단한다. HP와 보호막을 몰래 초기화하지 않는다.
수치 탭:
  기본/최종 HP·방어·이동, 실제 대쉬 거리/충전, 콤보/GCD/시전, 고유 제약/진화/루트.

입력:

4. 발견한 결함과 수정
- 쿨감이 부분 충전(예: 2개 중 1개 남음)에 적용되지 않던 조건 수정. 공유 GCD는 쿨감에서 제외.
- 전체 초기화와 일반 쿨감 구분: 드래곤 V는 최대 충전 복구, 일반 쿨감은 초과 충전 없음.
- 카운터 일반 무력화가 카운터 창을 먼저 닫던 순서 수정. 성공 여부를 먼저 확정하고 1회 집계.
- 타겟 링 45/135도와 다른 60/120도 측후면 판정을 동일 기준으로 통합.
- 다음 공격 피해/치명 버프가 광역 첫 대상 또는 다단 첫 타격에만 적용되던 오류 수정.
  한 번의 실행에 값을 고정하고 첫 유효 적중 후 1회 소모하며 지속/파생 피해는 소모하지 않는다.
- 바드 Q와 채널의 범위가 진화 카드 범위와 달랐던 문제 수정. 범위 그림도 같은 값을 쓴다.
- 약사 GCD 2 장판이 일반 회복과 특수 회복 경로에서 중복 치유하던 문제 수정.
- 빈 화살비가 자원을 만들던 문제 수정: 틱당 유효 적중이 있을 때 한 번만 획득.
- 미러 같은 콤보 반복 자원 획득, 합동 Z의 분신 추가타 중복을 수정.
- 미러 빙의 자연 종료 시 유효 대상/사거리 확인 후 피니시. 사망·취소·초기화에서는 실행하지 않음.
- 드래곤 Z의 공통 자원 비용도 고갈 이벤트에 포함. 복원/패널 충전은 과열 재발동 안 함.
- 강화된 피흡의 초과 회복량 계산과 보호막 전환에 동일한 회복 보정 적용.
- 역할 기본 HP 재설정 뒤 이전 임시 최대 HP 배율을 다시 나누던 문제 수정.
- 팔라딘이 새 파티 공속을 GCD에 반영하지 않던 문제 수정. 개별 논글쿨 재사용에는 미적용.
- 일반 런 종료/재도전 CleanupAttempt에 CharacterKit 정리 추가.
- 거부된 직업 변경 요청이 먼저 스탯 보정 추적값을 지우던 순서 수정.
- 대체 AI가 없는 선택 슬롯을 역참조하는 경로에 방어 처리 추가.
- 훈련 기록 초기화는 encounter generation을 유지하여 살아 있는 장판의 틱을 끊지 않음.

5. 수치 정책
기존 기본 스탯/위력/쿨타임/대쉬/회복/무력화/진화 카드 값을 재사용했다.
TwelveCharactersTuning.txt의 기존 임시 수치를 이번에 밸런스 확정값으로 승격하지 않았다.
이번에 정한 시험 수치: 표적 HP 1,000,000, 느린 이동 ±2m, 주기 sin(time*0.25),
예고 1.5초, 피해 기본 300/강타 1200, 반복 기본 4초(허용 2~30초), 넉백 4m.
명세 다단 표현 보완: 레인저 Z1 4회, 미러 Z3 8회 분할(조정 가능한 hits 데이터).
기존 총 위력/총 무력화를 나눠 사용한다. 정수 피해 반올림에 따른 작은 차이는 생길 수 있다.
미러 Z2 피니시는 기존 GCD 2 3타 위력(기본 위력 * 2.2), 기존 범위/무력화 재사용.
피니시 발동 방식과 분할 타수는 명세에 정확한 값이 없어 채택한 임시 설정이다.

7. 남은 위험/제약 — 우선순위 순
P1 미확인: 실제 Unity Play에서 자동 UI 배치/스크롤/입력·카메라, 물리 충돌/이동·구출,
  범위 시각화, 반복 입장과 다수 표적, 실제 효과 틱/피해가 일치하는지 실행 검증 필요.
  순수 계산 검사로 이 항목이 성공했다고 판단하면 안 된다.
P1 미확인: 같은 빌드의 실제 호스트+클라이언트에서 직업 변경, AI 대체, 재접속,
  다단·장판·반사·피해 이전과 기록의 중복 여부. 프로토콜 검사는 실제 통신 시험이 아니다.
P2 기존 제약: 지면 설치 스킬은 기존 대상 위치/발밑 방식이며 자유 지면 조준 UI는 없다.
  훈련장에서 이 기존 조작 방식으로 시험한다.

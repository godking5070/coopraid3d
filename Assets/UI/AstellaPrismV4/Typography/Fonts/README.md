# MaruBuri SemiBold

Unmodified static TTF, font internal version 2.000. Chosen by the user for Prism headings and boss/cast names. Numeric typography remains a separate decision.

Official source: https://hangeul.pstatic.net/0/hangeul/2023/fonts/MaruBuri-SemiBold.ttf
Official license: https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko
SHA256: d8f98594ef5b2f37936dc7ddcd3ba67b6249f27a641d203beef41e589f917e7c

The font copyright notice and complete OFL 1.1 text are in `Assets/StreamingAssets/ThirdPartyLicenses/MaruBuri-LICENSE.txt`, so Unity includes a readable copy in player distributions. Keep that notice with the font. Fonts are not sold separately. Outlines are authored uGUI effects, not modifications to the font file.

## Oxanium Medium

User-selected numeric font (alternative 3), unmodified static TTF version 2.000. Source: https://github.com/sevmeyer/oxanium/blob/master/fonts/ttf/Oxanium-Medium.ttf . Its copyright notice and full OFL 1.1 text are shipped in Assets/StreamingAssets/ThirdPartyLicenses/Oxanium-LICENSE.txt. Use only for numeric fields and supported symbols. MaruBuri remains the heading font. Thicker-outline alternatives are reviewed separately before changing the current effects.

네 방향의 뜻
front.png=정면, left.png=대상의 왼쪽, right.png=대상의 오른쪽, back.png=후면.
Y는 위, +Z는 정면, +X는 대상 오른쪽으로 해석한다.
왼쪽 카메라에서는 정면 장식이 화면 오른쪽을 향하고, 오른쪽 카메라에서는 화면 왼쪽을 향한다.
측면에서 멀리 있는 다리가 겹쳐 보이더라도 다리 수는 총 6개다.
네 시점은 하나의 모델을 설명한다. 노멀과 하드, 다른 건축물 이미지를 한 모델의 시점으로 섞지 않는다.

본체 포즈와 리깅
캄파넬라는 청동 종과 6개 기계 거미다리로 된 비휴머노이드다.
원래 디자인을 유지하기 위해 인간형 T포즈로 바꾸지 않고, 6족 다리를 벌린 고정 중립 자세로 4방향을 준비했다.
Mixamo용 휴머노이드 본체로 취급하지 않는다. 이 보스는 Blender/Maya 등에서 사용자 정의 리깅을 진행해야 한다.
최소 구조 제안: 중앙 몸체 루트, 6개 다리 각각 고관절/무릎, 종치 피벗, 하드 외피 4개 패널의 힌지.
본체의 세 지지 기둥은 중앙 종치를 둘러싼 삼각 배치로 정리한다. 투영에서 중앙에 겹쳐 보이는 뒤쪽 기둥과 종치의 실제 깊이를 분리한다.
노멀은 닫힌 종 외피, 하드는 갈라져 열리는 네 외피 패널이다. 외피는 지지 프레임에 붙은 큰 조각으로 구성한다.
본체에는 망토·종치·후면 구동부·봉인 체인을 합치지 않았다. 생성 뒤 별도 부품으로 조립한다.

부속품 시트 규칙
네 장 모두 왼쪽부터 정상 망토 / 찢긴 망토 / 종치 / 구동부 / 봉인 체인 순서다.
후면에서도 시트 전체를 좌우 미러하거나 부품 순서를 뒤집지 않았다.
3840×1800px, 모든 부품 바닥선 Y=1600px.
정상 망토: 중심 X=400, 높이1050px.
찢긴 망토: 중심 X=1170, 높이1050px.
종치: 중심 X=1870, 높이1250px.
구동부: 중심 X=2480, 높이650px.
봉인 체인: 중심 X=3340, 높이500px.
외곽 경계의 수평 중심과 높이, 바닥선을 코드 템플릿으로 고정했다. 측면 투영 폭은 자연스럽게 좁아진다.
accessory-layout.json에 실제 배치 좌표를 기록했다. 이 배율은 시트 정렬용이고, 본체에 장착할 때 실제 크기를 맞춘다.
정상 망토와 찢긴 망토는 난이도별 교체 부품이다. 둘 다 동시에 착용시키지 않는다.
망토는 바람 없이 세운 모델링용 휴지 자세이며, 종 덮개 위에 실제로 걸칠 때 형태와 접촉을 조정한다.
종치 상단 베어링을 종 상단 축 아래에 붙이고, 구동부는 후면 장착판에 맞춘다.
봉인 체인은 큰 링크 부조를 연속된 굵은 연결부 위에 만든 모델링용 하네스다. 개별 고리 물리 시뮬레이션용 분리 메시가 아니다.
부속품 세트 생성 후 각 부품을 DCC에서 분리하고, 사이에 생긴 연결 면을 정리한다.
작업용 개별 부품 원화와 폐기 시안은 전달 ZIP에 넣지 않았다.

맵 사용
BelfryArch는 두 기둥·한 고딕 아치·목재 가로보·중앙 고리를 묶은 반복 모듈이다.
Railing은 세 패널이 있는 낮은 난간 구간이다. 후면은 단순한 직사각 패널, 측면은 좁은 끝기둥이다.
WindingStation은 로프 드럼과 받침대가 연결된 권양기다. 좌우 원형 드럼 끝과 후면 받침대 정보를 따로 제공했다.
Floor/top.png는 전장 반경18m 기획에 맞춘 원형 배치 참고다. 북쪽을 위로 놓으면 I=왼쪽 위, II=오른쪽 위, III=오른쪽 아래, IV=왼쪽 아래 공명판 위치다. 이미지 자체에는 문자를 넣지 않았다.
바닥은 평면의 색상·배치 참고 한 장이다. 반복 타일 또는 완성된 PBR 재질 세트가 아니다.
계단·연석·발판 높이 차는 별도 메시로 만들고 실제 기믹 위치는 게임 설정값에 맞춘다.
이 패키지는 종루 핵심 모듈 세트이며, 마을 원경과 모든 장식물 전체를 포함하지 않는다.

이미지 제작과 검수
내장 image_gen으로 원화를 생성했고, 결정적 좌표 템플릿으로 시트 조립·정렬했다.
본체2048×1800px, 부속품3840×1800px, 건축물1600×1600px, 바닥1254×1254px.

외곽 위치 정렬과 실제 입체 형상의 완전 일치는 별개다. 곡률·장식·관절 깊이는 3D 블록아웃에서 조정한다.
선택된 수정본: hard-front-fixed.txt, drive-right-fixed.txt. hard-front.txt와 drive-right.txt는 수정 전 생성 기록이다.
Tripo 업로드·3D 모델 생성·Mixamo/사용자 정의 리깅은 실행하지 않았다.
게임 코드·씬·원본 컨셉은 수정하지 않았다.

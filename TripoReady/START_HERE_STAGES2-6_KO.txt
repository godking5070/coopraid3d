아스텔라 1부 — 남은 2~6스테이지 Tripo 입력 자료
2026-11-10 / 스테이지별 병렬 제작

총 입력 PNG 133장
본체48장 + 고정 부속품 시트20장 + 건축물60장 + 바닥5장.
기존 전체 컨셉 참고15장과 내장 image_gen 제작 프롬프트191개도 포함했다.

폴더별로 시작
Stage2_v1 : 플로라 기어 / 기억의 유리 온실 — 입력25장
Stage3_v1 : 캄파넬라 / 침묵의 종루 — 입력25장
Stage4_v1 : 마리오네트 / 오페라 극장 — 입력25장
Stage5_v1 : 유스티티아 / 성채 재판소 — 입력25장
Stage6_v1 : 야누스 알파 & 오메가 / 시계탑 정문 — 입력33장
각 폴더의 START_HERE_KO.txt에 생성 작업 단위와 조립 순서가 있다.

공통 형식
본체는 정면·대상왼쪽·대상오른쪽·후면을 각각 한 장의 전신 PNG로 제공한다.
휴머노이드는 무기와 큰 부속을 분리한 T포즈다.
부속은 모든 부품을 한 이미지에 모은 네 시점 시트다. 네 장에서 각 부품 칸·중심·높이·바닥선을 고정했다.
후면에서 부품 순서를 바꾸거나 시트 전체를 미러하지 않았다.
주요 건축물3종은 각각 네 방향, 평평한 바닥은 탑뷰 한 장이다.
한 폴더의 네 방향을 한 대상의 시점으로 사용한다. 다른 본체나 스테이지의 시점을 섞지 않는다.
ReferenceOnly는 전체 컨셉 참고이며 직접 모델 시점으로 넣지 않는다.

리깅과 조립에서 구분할 보스
3스테이지 캄파넬라는 여섯 다리 종 형태를 유지했다. Mixamo 휴머노이드 자동 리깅 대신 별도 기계 리그가 필요하다.
4스테이지 마리오네트의 네 팔은 기본 두 팔 T포즈 본체 + 추가 팔 모듈 복제/미러와 별도 본 작업으로 복원한다.
6스테이지는 알파·오메가 각각 노멀·하드로 나눠 본체4종을 별도로 생성한다.
날개·망토·천칭·추가 팔·슬라이딩 방패는 본체 리깅 뒤 DCC에서 장착/분리/가중치/추가 관절을 정리한다.
이 자료는 PNG 입력 리소스다. 실제 Tripo 모델 생성·업로드와 Mixamo 리깅은 실행하지 않았다.

검수
각 스테이지의 verification.json에는 파일/해상도/시점/고정 배치의 실제 픽셀 검사 결과가 있다.
CrossAudit/stage2.json~stage6.json에는 다른 담당자가 원본 컨셉과 실제 이미지 및 ZIP 바이트를 대조한 독립 검수 기록이 있다.
stages2-6-verification.json은 통합 파일 목록과 범위 검사 결과다.
완성된 1스테이지 v2 패키지와 게임 코드·씬·프리팹은 보존했다.

자료의 한계
이미지는 동일 디자인을 맞춘 AI 참고도이며 단일3D원형의 정밀 정투영 렌더가 아니다.
작은 장식·곡률·천 주름·투영 폭 차이는 생성 모델에서 맞춘다.
바닥은 평면 배치/색상 참고로, 이음새 없는 반복 타일이나 완성 PBR 세트가 아니다.
입체 단차·계단은 별도 모듈과 측면 정보가 필요하다.

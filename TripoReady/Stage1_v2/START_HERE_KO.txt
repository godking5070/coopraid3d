아스텔라 1맵 — 마을의 수호 석상 / Tripo·Mixamo 입력 자료 v2
작성일: 2026-11-10
제공물: 모델링용 PNG 25장 + 기존 컨셉 참고 3장 + 생성 프롬프트와 배치 정보

구성
Bodies/Normal/ : 무기 없는 노멀 본체 T포즈 4장
Bodies/Hard/ : 무기·날개 없는 하드 본체 T포즈 4장
Accessories/ : 돌봉·방패·날개 모듈을 모두 담은 고정 배치 시트 4장
Buildings/ClockGate/ : 시계탑 성문 4장
Buildings/House/ : 반복 배치용 주택 4장
Buildings/Plinth/ : 빈 수호 석상 받침대 4장
Floor/top.png : 광장 바닥 탑뷰 1장
ReferenceOnly/ : 전체 디자인과 배치 참고용. 모델 생성 입력에 섞지 않는다.
GenerationPrompts/ : 이미지 제작에 사용한 프롬프트. Tripo의 텍스트 입력란에 넣는 자료가 아니다.

각 폴더의 네 방향
front.png = 정면
left.png = 대상의 왼쪽에서 본 모습
right.png = 대상의 오른쪽에서 본 모습
back.png = 후면
인물 기준 Y 위, +Z 정면, +X 인물 오른쪽으로 해석한다.
left에서 인물 얼굴은 화면 오른쪽, right에서는 화면 왼쪽을 향한다.
측면에서 겹쳐 보이는 팔은 같은 T포즈의 투영이다. 팔을 내린 자세로 해석하지 않는다.
네 파일은 네 모델이 아니라 한 대상의 네 시점이다. 서로 다른 폴더의 이미지를 한 모델의 시점으로 섞지 않는다.

부속품 시트 — 사용자 요청 반영
한 이미지에 돌봉·방패·날개가 전부 들어 있다.
모든 방향에서 왼쪽 칸=돌봉, 가운데 칸=방패, 오른쪽 칸=날개다.
후면에서도 시트 전체를 뒤집거나 부품 순서를 바꾸지 않았다.
캔버스 3200×1800px, 공통 바닥선 Y=1600px.
돌봉: 중심 X=450, 외곽 높이 1400px.
방패: 중심 X=1400, 외곽 높이 1360px.
날개: 중심 X=2500, 외곽 높이 1200px.
각 부품 외곽 경계의 수평 중심과 바닥선, 높이를 고정해 조립했다. 측면에서는 투영 폭만 좁아진다.
세부 좌표는 accessory-layout.json에 있다.
이 배율은 시트 정렬 기준이다. 실제 게임에서의 본체 대비 크기는 장착할 때 맞춘다.
전달용 Accessories 폴더에는 이 네 시트만 있다. 작업용 개별 부품 이미지는 전달 ZIP에 넣지 않았다.

Tripo에서 진행
1. ZIP을 풀고 Bodies/Normal의 네 장을 한 본체의 시점으로 사용한다.
2. Bodies/Hard는 별도의 본체 생성 작업으로 사용한다.
3. Accessories의 네 장은 한 부속품 세트의 시점으로 사용한다.
4. 건축물은 ClockGate, House, Plinth별로 각각 별도 생성 작업을 진행한다.
5. 화면에 표시되는 각도 이름에 맞춰 front/left/right/back을 배치한다.
6. 생성된 부속품 세트는 Blender 등에서 돌봉·방패·날개를 분리하고, 부품 사이에 생긴 연결 면이 있으면 정리한다.
7. 본체와 장비를 분리한 상태로 내보낸다. Mixamo용 본체는 FBX를 우선 사용한다.

Mixamo와 장비 조립
Mixamo에는 무기·방패·날개가 없는 본체 3D 파일을 올린다. 이 패키지의 PNG를 Mixamo에 직접 올리는 방식이 아니다.
리깅 뒤 돌봉은 오른손, 방패는 왼손/전완 쪽에 장착한다.
하드의 등 부착점에 날개 모듈을 붙인다. 시트의 날개는 한쪽 모듈이며, DCC에서 복제·미러해 반대쪽을 만든다.
날개를 움직이려면 별도 관절과 가중치·애니메이션 작업이 필요하다.
하드의 큰 손·발, 치마형 골반 판금은 실제 관절 변형을 확인하며 정리한다.

맵과 바닥
시계탑 성문·주택·빈 받침대는 각각 정면/왼쪽/오른쪽/후면 개별 전신 이미지다.
성문의 시계와 태엽 장치는 전면, 후면에는 잠금장치와 창이 있다.
주택은 앞쪽에만 출입문이 있으며, 뒤쪽은 창과 벽으로 구성했다.
받침대의 별 장식은 정면에만 있다.
기존 맵 컨셉의 색과 건축 양식을 바탕으로 만든 첫 모듈 세트다. 전체 마을의 모든 장식물을 포함하는 목록은 아니다.
Floor/top.png는 평평한 광장 바닥의 배치·색상 참고라서 탑뷰 한 장으로 사용할 수 있다.
바닥 이미지는 이음새 없는 반복 타일이나 완성된 PBR 재질 세트가 아니다. 평면에 적용할 때 UV와 반복 규모를 정한다.
계단·연석·높이 차가 필요한 바닥은 별도 입체 모듈과 측면 정보가 필요하다.

제작·검수 범위
래스터 원화: 내장 image_gen 사용. 고정 시트 조립과 정렬: 공통 좌표 템플릿 사용.
본체 2048×1600px, 부속품 시트 3200×1800px, 건축물 1600×1600px, 바닥 1254×1254px.
이미지들은 동일 디자인을 맞춘 AI 생성 참고도다. 한 3D 원형을 렌더링한 도면은 아니어서 장식·곡률·투영 폭에 차이가 남을 수 있다.
배치 좌표 고정과 실제 입체 형상의 완전한 일치는 별개다. 생성된 모델에서 전후면 장식과 두께를 확인한다.
실제 Tripo 생성·업로드, Mixamo 리깅은 이 자료 제작 과정에서 실행하지 않았다.
기존 v1 자료와 게임 코드·씬은 수정하지 않았다.

아스텔라 4스테이지 — 기억의 인형사, 마리오네트 / Tripo·Mixamo 입력 자료 v1
작성일: 2026-11-10
제공: 모델링 입력 PNG 25장, 기존 컨셉 참고 3장, 생성·수정 프롬프트 35개

폴더와 입력 단위
Bodies/Normal/ : 노멀 본체 4방향, 빈손 T포즈, 2048×1600px
Bodies/Hard/ : 하드 본체 4방향, 빈손 T포즈, 2048×1600px
Accessories/ : 추가 팔·십자 조종대·등 릴 프레임을 한 장에 담은 4방향 고정 시트, 3200×1800px
Buildings/PuppetStage/ : 북쪽 보조 인형극 무대, 4방향, 2400×1600px
Buildings/AudienceBox/ : 반복 배치용 2층 객석 박스, 4방향, 2400×1600px
Buildings/FlyRig/ : 무대 승강 장치/횡대 모듈, 4방향, 2400×1600px
Floor/top.png : 주무대 바닥 탑뷰 1장, 1254×1254px
ReferenceOnly/ : 기존 승인 컨셉과 극장 배치 참고. 모델 생성 입력에 섞지 않는다.
GenerationPrompts/ : 내장 image_gen으로 제작한 원문 프롬프트. Tripo 텍스트 입력값이 아니다.

네 방향
front.png는 정면, left.png는 대상의 왼쪽, right.png는 대상의 오른쪽, back.png는 후면이다.
Y 위, +Z 정면, +X 대상 오른쪽으로 해석한다. 인물은 left에서 화면 오른쪽, right에서 화면 왼쪽을 본다.
네 PNG는 한 대상의 네 시점이다. 네 모델로 따로 만들거나 다른 폴더의 시점을 섞지 않는다.
T포즈 측면의 팔은 카메라 축과 겹쳐 어깨 높이에 짧게 보이는 같은 자세다.

4팔 컨셉과 리깅
기존 마리오네트는 노멀·하드 모두 팔이 네 개다.
자동 휴머노이드 리깅을 위한 본체에는 상단 두 팔만 남겼으며, 하단 추가 팔은 별도 부품으로 분리했다.
완성 캐릭터는 본체 + 추가 팔 모듈 2개로 조립해 네 팔을 복원한다. 추가 팔이 사라진 최종 디자인을 제안한 것이 아니다.
시트의 추가 팔은 한쪽 모듈 한 개다. DCC에서 복제·좌우 미러하고 면 방향/트랜스폼을 정리해 반대쪽을 만든다.
추가 팔 어깨·팔꿈치·손목에 별도 본과 가중치를 만들고 하부 옆구리의 금색 소켓에 연결한다.
Mixamo 리깅 결과가 추가 팔이나 인형 실 애니메이션까지 만드는 것으로 기대하지 않는다.
하드는 열린 반쪽 가면 두 장, 중앙 시계 얼굴, 흉부 나선 태엽, 갈라진 코트 자락을 본체에 유지했다.
하드의 등 릴 프레임은 리깅 뒤 상부 등 소켓에 붙인다. 본체와 큰 프레임을 합쳐 자동 리깅하지 않는다.

부속품 고정 배치 — 시점만 변경
한 이미지에 추가 팔·십자 조종대·등 릴 프레임이 모두 들어 있다.
정면·왼쪽·오른쪽·후면 모두 왼쪽 칸=추가 팔, 가운데 칸=조종대, 오른쪽 칸=등 릴 프레임이다.
후면에서도 시트 전체를 좌우 미러하거나 부품 칸을 바꾸지 않았다.
캔버스 3200×1800px, 바닥선 Y=1600px.
추가 팔: 외곽 중심 X=450px, 높이 1400px.
십자 조종대: 외곽 중심 X=1400px, 높이 380px.
등 릴 프레임: 외곽 중심 X=2520px, 높이 1080px.
각 부품 외곽 경계의 중심·높이·바닥선을 고정했다. 측면의 투영 폭은 물체 두께에 맞게 좁아진다.
상세 값은 accessory-layout.json, 실제 픽셀 검사는 verification.json에 있다.
이 높이는 시트 정렬용이다. 게임에서의 본체 대비 크기는 장착할 때 조정한다.
Accessories에는 전달용 네 시트만 있다. 개별 부품 원화는 작업 폴더에만 보관했다.

Tripo와 조립 순서
1. 노멀 본체 네 장을 한 생성 작업의 시점으로 사용한다. 하드는 다른 작업으로 생성한다.
2. 부속품 네 시트는 한 부속품 세트의 시점으로 사용한다.
3. 각 건축 모듈도 폴더별 한 생성 작업으로 사용한다. 시점 이름을 확인해 배치한다.
4. 생성 후 부품 사이의 임의 연결 면을 정리하고 추가 팔·조종대·등 프레임을 DCC에서 분리한다.
5. 본체 3D 파일을 FBX 등 지원 형식으로 내보낸 뒤 리깅한다. PNG를 Mixamo에 직접 넣는 방식이 아니다.
6. 리깅 뒤 추가 팔 두 개, 손에 잡는 십자 조종대 복제본, 하드 등 릴 프레임을 조립한다.
7. 조종대와 릴의 황금 실은 별도 곡선/스플라인 또는 이펙트로 연결한다. 얽힌 가는 실을 본체 메시로 굳히지 않는다.
8. 추가 팔의 넓은 동작, 팔꿈치·손목 관절, 코트와 다리 간섭, 가면 힌지와 흉부 태엽의 연결을 확인한다.

맵 제작
게임 문서의 주무대는 30m×30m, 북쪽에 보조 인형극 무대가 있다.
Floor/top.png는 그 평평한 목재 무대의 색상·배치 참고이므로 탑뷰 한 장을 제공했다.
바닥은 이음새 없는 반복 타일이나 PBR 재질 묶음이 아니다. UV와 반복 크기는 제작 단계에서 정한다.
계단·단차는 입체 무대 모듈을 사용한다. 추가 연석·비평면 지형은 별도 측면 자료가 필요하다.
객석 박스는 좌우 벽에 반복 배치하고, 승강 장치는 무대 위쪽 구조에 배치한다.
건축물 세 종은 기존 극장 원화에서 재구성한 첫 모듈 세트다. 전체 극장의 모든 소품·이펙트를 포함한 목록은 아니다.
실제 배치와 크기·이동 공간은 기존 전장/카메라 범위에 맞춘다.

제작·검수 범위
이미지 원화는 내장 image_gen으로 생성했다. 시트 위치와 본체/건축물의 높이·중심은 공통 좌표 템플릿으로 정렬했다.
25개 입력 PNG의 파일명·해상도·가독성, 4방향 완전성, 부속품 12개 배치의 실제 픽셀 위치를 검사했다.
모든 방향의 본체·부속·건축물과 바닥을 시각 검수했다.
이 자료는 AI 생성 모델링 참고도이며, 단일 3D 원형에서 렌더한 측정 도면은 아니다. 장식·곡률·투영 폭 차이는 생성된 메시에서 정리한다.
실제 Tripo 업로드·3D 생성, Mixamo 리깅, Unity 임포트/플레이는 실행하지 않았다.
원본 컨셉과 게임 코드·씬은 변경하지 않았다.

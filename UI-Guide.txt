RAID ROGUE — 공허 원정 UI / 첫 번째 디자인

방향
짙은 남색 패널에 보라색 보스 체력, 청록색 안내, 금색 플레이어 강조를 사용합니다.
월드의 장판과 위치 판정을 가리지 않도록 화면 중앙은 비워 둡니다.
1920×1080 기준이며 CanvasScaler Expand로 좁거나 넓은 화면에서도 전체 배치를 유지합니다.

적용
메인 씬 Assets/Scenes/SampleScene.unity에 UI가 직접 저장되어 있습니다.
메인 씬을 열면 편집 중에도 UI가 보이며, Play를 누르면 실시간 상태를 표시합니다.
필요 시 Tools > RaidRogue > Apply UI to Main Scene으로 다시 적용할 수 있습니다.
같은 HUD Canvas를 사용하는 Step1~5 씬에도 적용됩니다.
기존 씬 파일을 다시 생성할 필요가 없습니다.
RaidHudTheme는 기존 UI를 배치하고 기존 컴포넌트의 연결을 유지합니다.
RaidSkillGlyph는 기본 UI 선으로 그리는 아이콘이므로 별도 이미지나 패키지가 필요 없습니다.

구성
좌측: 플레이어와 AI 3명의 실시간 체력, 역할 색상.
상단: 스테이지, 보스 체력, 시전 진행도, 기믹 경고.
우측: 실제 StageManager 원정 경과 시간.
하단: 플레이어 체력/방어/구출 상태, 4개 스킬, 쿨타임, 콤보 유지 시간.
보상: 기존 무작위 카드 3개와 선택 기능에 새 카드 레이아웃 적용.
결과: 기존 승리 요약 및 재시작 버튼에 패널 테마 적용.

미리보기
Tools > RaidRogue > Export UI Previews로 UI-Preview 폴더에 3개 PNG를 생성합니다.
이 명령은 메인 씬으로 미리보기를 생성한 뒤 원래 씬으로 돌아갑니다.
미리보기의 보상/승리 문구는 디자인 확인용 예시 데이터입니다.
실제 플레이에서는 기존 카드 선택, 보스 상태, 승리 요약 데이터를 사용합니다.

색상 수정

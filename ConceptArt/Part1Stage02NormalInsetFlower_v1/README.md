# 2스테이지 노멀 · 가슴 꽃 유리함 매립 수정

[수정본 PNG](01-character-sheet.png) · [수정 전후 비교](INDEX.html) · [생성 프롬프트](prompt.txt) · [제작 기록](manifest.json)

가슴 밖에 붙어 있던 두꺼운 원통과 황동 캡을 몸 안쪽으로 넣었습니다. 앞에는 얕은 유리창과 얇은 금테가 남고, 흉부 갑주가 유리함 양옆을 감싸도록 바꿨습니다. 큰 Hero·FRONT·SIDE에 같은 구조를 적용했으며 특히 측면의 돌출을 줄였습니다. 파란 꽃 한 송이와 초록 줄기·잎은 계속 보입니다.

노멀의 얼굴·모자·곱슬머리·체형·의상·가위·포즈·시트 배치와 BACK 태엽은 유지했습니다. 하드 보스는 수정하지 않았습니다. 이전 원본은 `BossOverview/originals/p1-s2-normal.png`에 보존하고, 전체 보스 모음의 노멀 이미지에는 이 수정본을 연결했습니다.

내장 `image_gen`으로 편집한 2D 캐릭터 시트입니다. 실제 3D 메시 깊이와 리깅은 검증하지 않았습니다.

후속 [손 파지·팔 연결 수정본](../Part1Stage02NormalGripFix_v2/INDEX.html)에서 이 시트의 유령손 문제를 교정했습니다. 꽃 매립은 그대로 이어갑니다.

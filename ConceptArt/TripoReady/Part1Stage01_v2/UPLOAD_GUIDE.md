# Tripo 입력 순서

캐릭터와 장비는 별도의 입력 세트입니다. 아래 세 그룹을 서로 섞지 않습니다.

1. **노멀 캐릭터:** `Characters/Normal/`의 네 장.
2. **하드 캐릭터:** `Characters/Hard/`의 네 장.
3. **돌봉 + 방패:** `Equipment/`의 네 장. 각 이미지에 두 장비가 함께 들어 있습니다.

각 세트의 순서는 정면(`01-front`) → 왼쪽면(`02-left`) → 오른쪽면(`03-right`) → 후면(`04-back`)입니다. 좌우는 캐릭터의 해부학적 좌우를 기준으로 표기했습니다. 왼쪽면에서는 코가 화면 왼쪽을, 오른쪽면에서는 화면 오른쪽을 향합니다. 사용 중인 화면이 방향별 슬롯을 제공한다면 해당 슬롯에 파일을 대응합니다.

캐릭터는 장비를 들지 않은 A포즈입니다. 하드의 날개는 몸체에 부착된 상태입니다. 장비 이미지는 돌봉이 왼쪽, 방패가 오른쪽이며 두 물체는 겹치지 않습니다. 네 장의 원본 PNG를 그대로 사용하면 장비의 중심 좌표·높이·하단 위치가 유지됩니다. 방향별로 다시 자르거나 각 장비를 따로 자동 확대하면 정렬이 달라집니다.

| 항목 | 모든 방향에 적용하는 값 |
|---|---|
| 캐릭터 캔버스 | 2048×2048, `#eeeeee` |
| 캐릭터 중심 / 발 하단 | X=1024 / Y=1888 |
| 장비 캔버스 | 3072×2048, `#eeeeee` |
| 돌봉 중심 / 높이 / 하단 | X=768 / 1600px / Y=1856 |
| 방패 중심 / 높이 / 하단 | X=2304 / 1464px / Y=1856 |

상세한 방향별 경계 상자와 원화 출처는 [layout.json](layout.json), 파일 해시는 [manifest.json](manifest.json)에 기록했습니다. 같은 장비를 회전하면 폭은 달라지므로 폭을 억지로 통일하지 않았습니다.

이 자료는 4방향 입력 이미지까지 준비한 것입니다. 실제 Tripo 서비스에 업로드하거나 메시 생성 결과를 확인하지 않았습니다. 여러 이미지의 형태가 동일 메시에서 나온 것처럼 완전히 일치한다고 보장하지 않습니다.

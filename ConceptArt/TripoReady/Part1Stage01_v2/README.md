# 1부 1스테이지 · Tripo 입력 v2

캐릭터와 장비를 분리한 정면·왼쪽면·오른쪽면·후면 이미지입니다. [미리보기](INDEX.html)에서 12장을 한눈에 확인할 수 있습니다.

| 그룹 | 파일 위치 | 구성 | 크기 |
|---|---|---|---|
| 노멀 캐릭터 | `Characters/Normal/` | 장비 없는 몸체 | 2048×2048 |
| 하드 캐릭터 | `Characters/Hard/` | 장비 없는 몸체와 부착 날개 | 2048×2048 |
| 장비 | `Equipment/` | 돌봉과 방패를 같은 이미지에 함께 배치 | 3072×2048 |

각 폴더에서 `01-front.png`, `02-left.png`, `03-right.png`, `04-back.png` 순서로 사용합니다. [사용 가이드](UPLOAD_GUIDE.md), [레이아웃 좌표](layout.json), [전체 생성 프롬프트](prompts-all.txt)를 함께 제공합니다.

장비 네 장은 돌봉의 중심 X=768, 방패의 중심 X=2304, 두 장비의 하단 Y=1856으로 고정했습니다. 돌봉 높이는 1600px, 방패 높이는 1464px입니다. 방향에 따른 자연스러운 폭 변화는 유지합니다. 캐릭터는 그룹별 키와 중심, 발 하단 위치를 통일했습니다. 파일 안에는 글자·가이드선·치수선을 넣지 않았습니다.

`SourceAssets/`에는 built-in `image_gen`으로 만든 방향별 투명 원화와 정확한 프롬프트·생성 출처를 보존합니다. 최종 입력은 이 원화를 회색 배경에 고정 좌표로 조판한 PNG입니다. 원화의 낮은 알파 잡티는 연결 성분으로 제외했습니다. 좌우 반전으로 측면을 대신하지 않았습니다.

이전 v1은 보존했습니다. AI로 재구성한 참고 이미지로, 단일 3D 메시를 돌려 렌더한 결과는 아닙니다. 실제 Tripo 업로드·크레딧 사용·3D 재구성 검증은 진행하지 않았습니다.

최종 ZIP에는 입력용 PNG 12장과 가이드·좌표·프롬프트·검증 기록만 포함합니다. 투명 생성 원화는 이 폴더의 `SourceAssets/`에 별도로 보존합니다.

# 1부 1스테이지 · 날개 분리 입력 v3

하드의 날개와 연결부를 몸체에서 분리했습니다. 모든 세트는 정면·왼쪽면·오른쪽면·후면의 PNG 네 장입니다. [미리보기](INDEX.html)에서 확인할 수 있습니다.

| 세트 | 위치 | 내용 |
|---|---|---|
| 하드 몸체 | `Characters/Hard/` | 날개·날개 연결부가 없는 맨손 캐릭터 |
| 하드 날개 | `Attachments/HardWings/` | 좌우 날개와 각각의 힌지·짧은 연결봉을 같은 이미지에 배치 |
| 노멀 몸체 | `Characters/Normal/` | v2와 같은 맨손 캐릭터 |
| 돌봉 + 방패 | `Equipment/` | v2와 같은 두 장비의 합본 시트 |

총 16장입니다. 이번에 하드 몸체 네 장과 날개 네 장을 새로 제작했고, 나머지 여덟 장은 검증한 v2 PNG를 그대로 복사했습니다. 몸체에는 어깨갑주·별·얼굴·투구·코어·팔·다리·A포즈를 유지했습니다. 날개 쪽에는 블레이드, 금색 원형 힌지, navy 연결봉, gold collar와 등쪽 root joint를 포함했습니다.

날개 시트에서도 image-left / image-right 물체의 중심·높이·하단 위치를 네 방향 전체에서 통일했습니다. 두 날개는 각각 자체 축을 기준으로 회전하며 화면 슬롯을 유지하므로 측면에서도 서로 겹치지 않습니다. 날개 앞·뒷면의 navy/별 장식은 기존 디자인을 따릅니다.

입력 순서는 [UPLOAD_GUIDE.md](UPLOAD_GUIDE.md), 실제 좌표·해시는 [layout.json](layout.json)과 [manifest.json](manifest.json)에 있습니다. [ASSEMBLY_REFERENCE.jpg](ASSEMBLY_REFERENCE.jpg)는 날개가 붙어 있던 v2의 4방향 참고용입니다.

새 원화는 내장 `image_gen`으로 제작하고 투명 PNG와 정확한 프롬프트·생성 출처를 `SourceAssets/`에 보존했습니다. 최종 PNG는 원화를 회색 배경의 고정 좌표에 조판한 파일입니다. [전체 프롬프트](prompts-all.txt)에는 새 생성 프롬프트와 기존 참고 세트의 프롬프트를 함께 보존했습니다.

ZIP에는 입력 PNG 16장과 가이드·조립 참고 이미지·좌표·프롬프트·검증 기록을 포함합니다. 투명 생성 원화는 프로젝트 폴더의 `SourceAssets/`에 별도로 보존합니다.

이미지 준비 단계까지의 작업입니다. 실제 Tripo 업로드·크레딧 사용·메시 생성·날개 부착 테스트는 수행하지 않았습니다. 독립적으로 생성한 AI 참고 이미지로, 동일 3D 메시의 회전 렌더는 아닙니다. 이전 v2는 보존했습니다.

# 2스테이지 노멀 · 손 파지와 팔 연결 수정

[수정본 PNG](01-character-sheet.png) · [전후 비교·손 확대](INDEX.html) · [최종 생성 프롬프트](refine.prompt.txt) · [제작 기록](manifest.json)

위쪽 고리는 화면 왼쪽 어깨에서 이어지는 손이, 아래쪽 고리는 화면 오른쪽 어깨에서 이어지는 손이 잡도록 고쳤습니다. 아래 손을 아래 고리의 오른쪽 곡선으로 옮겨 팔꿈치·전완·손목과 연결했고, 가위 중앙 앞을 지나는 전완이 보이게 했습니다. 허벅지에서 나오던 유령손·손목 장식은 제거했습니다.

양쪽 어깨에서 각 손까지 팔 경로를 확대해 확인했으며 두 팔·두 손만 남겼습니다. 매립된 꽃 유리창과 노멀 디자인, 작은 FRONT/SIDE/BACK 및 무기 상세는 유지했습니다. 이전 꽃 매립 시트는 별도 폴더에 보존했습니다.

내장 `image_gen` 편집입니다. 첫 시도는 팔 연결이 잘못되어 폐기했고, 원래 꽃 매립 시트에서 다시 편집한 두 번째 결과를 채택했습니다. `prompt.txt`는 첫 시도, `refine.prompt.txt`는 채택한 최종 편집의 정확한 프롬프트입니다. 실제 3D 손·가위 리깅은 검증하지 않았습니다.

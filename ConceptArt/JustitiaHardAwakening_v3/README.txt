유스티티아 하드 변형 5안

INDEX.html에서 노멀 기준과 하드 5안을 비교합니다. 이미지 클릭으로 확대하고 원본 PNG를 열 수 있습니다.
01 개안한 단죄자 / 02 천칭의 집행수 / 03 네 팔의 대심판 / 04 벌어진 판결의 감옥 / 05 저울에 매달린 성상
모두 선택 전 비교 후보입니다. 2부는 재작업 의견만 기록했으며 새 이미지를 만들지 않았습니다.

내장 image_gen 사용. 각 폴더에 최종 PNG, 정확한 prompt.txt, 생성 원본·참조·SHA256·시각 QA가 담긴 manifest.json을 저장했습니다.
원본 normal은 Reference/01-normal.png에 복사했습니다. 기존 컨셉과 프롬프트는 보존했습니다.
각 하드의 생성/보정 프롬프트 전체는 prompts-all.txt에서 확인합니다.

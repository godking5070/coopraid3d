# ASTELLA · 입체 아트 타이틀 6~10

사용자가 처음의 은빛·보라색 입체 로고 퀄리티로 5종을 더 요청해 만든 별도 시안이다. 앞선 서체·SVG형 1~5번은 `../2026-11-17-prism-engraved/`에 보존한다. 이번 6~10번은 **내장 image_gen.imagegen**을 사용해 각기 생성한 투명 래스터 로고다. CLI/API fallback은 사용하지 않았다.

| 번호 | 시안 | 재질과 장식 |
|---|---|---|
| 6 | 프리즘 코어 | A 안쪽의 수정 면과 짧고 각진 금속 받침 |
| 7 | 멈춘 시계 | 미완성 시계 원호·멈춘 바늘·작은 자수정 장식 |
| 8 | 성소 각인 | 세로 각인과 양 끝의 챔퍼 금속·보라 인레이 |
| 9 | 깨진 봉인 | 끊어진 금속 선·글자의 미세 균열·수정 파편 |
| 10 | 은빛 서약 | 은빛 곡선·매듭 같은 하단 세공·보라 연결부 |

디자인 이름은 시안을 구분하는 이름이며 공식 세계관 고유명이나 새 상징을 확정한 것이 아니다. 기존 시계탑·멈춘 시간과 승인된 Prism 재질을 시각적으로 참고했다. 제목 표기는 다섯 개 모두 ASTELLA다.

`index.html`을 열고 6~10번을 누르면 같은 배경·메뉴에서 PNG 로고만 바뀐다. 숲과 기존 폰트는 앞선 폴더의 파일을 상대 경로로 재사용하며 수정하지 않았다. `?capture=1&concept=09-fracture`처럼 시안을 직접 지정할 수 있다. 메뉴 동작은 선택 표시 확인용이며 실제 게임·저장·종료와 연결되지 않는다.

- `Artifacts/*.png`: 2172×724 원본 투명 RGBA PNG 5개. 생성 결과를 바이트 변경 없이 복사했다.
- `Artifacts/*.webp`: 채팅용 축소본. 원본의 알파를 유지한 540×180 표시용 변환이며 PNG를 덮어쓰지 않는다.
- `prompts.json`: 다섯 개의 정확한 생성 요청문, 도구와 입력 역할.
- `generation.json`: 생성 원본 경로·치수·샘플 알파·SHA256 및 원본 보존 기록.
- `preview-*-1920.png`: 다섯 화면의 1920×1080 브라우저 렌더. `preview-06-prism-1366.png`는 작은 화면 확인.
- `render-preview.cjs`, `validation.json`: PNG·폰트 로드, 정확한 한글 메뉴, 영역, 선택, 저장 예시, 키보드, 시안 탭·URL 검사.
- `compression.json`, `native-validation.json`: 채팅용 형식 변환·원본 보존과 5개 탭·확대/복원 검사.
- `publish-inline.cjs`: 배경·공통 메뉴와 WebP 로고를 합성한 채팅용 5종 미리보기. 전체 원본 퀄리티는 PNG로 확인한다.

PNG의 ASTELLA 철자는 시각적으로 확인했고, 브라우저 검사의 이미지 alt 확인과 구분한다. 두 입력은 첫 입체 로고의 퀄리티·재질 참고와 기존 승인 HUD의 재질 참고이며, 전경 배경이나 메뉴를 로고 안에 합성하지 않았다. 별도의 벡터·PSD 원본은 없다.

검사는 브라우저 디자인 시안 범위다. Unity 스크립트·씬·프리팹·프로필을 변경하거나 실제 Play를 검증한 결과가 아니다. 메인에도 이 독립 폴더만 추가한다.

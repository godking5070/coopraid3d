# ASTELLA · 새로운 입체 로고 11~15

기존 입체 아트의 재질감은 유지하되 글자 형태와 전체 실루엣을 바꿔달라는 요청으로 만든 5종이다. 기존 로고를 이미지 참조로 사용하지 않고, **내장 image_gen.imagegen**으로 각 방향의 알파벳을 새로 생성했다. CLI/API fallback은 사용하지 않았다.

| 번호 | 시안 | 글자와 재질 |
|---|---|---|
| 11 | 석판 조각 | 두껍고 낮은 기하학적 글자·은빛 석재의 부조 |
| 12 | 은빛 필기 | 앞으로 기울어진 필기 흐름·은빛 리본 같은 획 |
| 13 | 첨탑 각인 | 길고 좁은 글자·정밀 금속의 수직 리듬 |
| 14 | 은목의 결 | 은빛 나뭇결과 가지가 글자 형태를 이루는 유기적 구조 |
| 15 | 수정 활자 | 글자 자체가 반투명 보라색 광학 수정인 각진 구조 |

번호와 디자인 이름은 비교를 위한 명칭이며 새로운 공식 세계관 설정이 아니다. 별도의 문구나 슬로건을 추가하지 않았다. 기존 1~10번과 게임 자산은 보존한다.

`index.html`의 11~15번 버튼으로 같은 배경·같은 메뉴에서 비교할 수 있다. 숲·폰트는 `../2026-11-17-prism-engraved/`의 원본을 재사용한다. 메뉴는 표시 확인용으로 실제 게임·저장·종료와 연결되지 않는다. 캡처 주소 예: `?capture=1&concept=14-silverwood`.

- `Artifacts/*.png`: 내장 생성 도구의 원본 투명 PNG 5개. 원본 바이트는 변경하지 않았다.
- `Artifacts/*.webp`: 채팅용 축소·형식 변환. 원본 PNG는 별도 유지한다.
- `prompts.json`: 5개 정확한 프롬프트와 도구·입력 조건. 기존 워드마크 참조 없음.
- `generation.json`: 원본 경로·치수·알파 샘플·SHA256·보존 기록.
- `preview-*-1920.png`, `preview-11-monolith-1366.png`: 실제 브라우저 렌더.
- `render-preview.cjs`, `validation.json`: 로드·글자·배치·메뉴·포커스·시안 전환 검사.
- `compression.json`, `native-validation.json`: 채팅용 변환과 카드·전환·확대 검사.
- `publish-inline.cjs`: 5종 한눈에 보기·화면 배치·확대가 있는 채팅용 HTML 제작.

ASTELLA 철자는 이미지에서 시각 확인하고, DOM alt 검사와 구분한다. 이 결과는 래스터 로고이며 편집용 벡터나 PSD 원본은 없다. 검증은 디자인 시안 범위로, Unity 적용이나 실제 Play 검증을 뜻하지 않는다. 메인에는 독립 시안 폴더만 추가한다.

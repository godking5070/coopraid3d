# ASTELLA 타이틀 21~25 — Steam 헤더 관찰과 시안 해석

2026-11-17에 확인한 공식 Steam 스토어의 `header.jpg` 5개를 참고했다. 관찰 대상은 각 **460×215 픽셀 헤더 이미지**이며, 독립된 로고 원본이나 공식 브랜드 가이드가 아니다. 출처 URL·수집 시각·원본 해시는 [출처 기록](sources.json), 관찰 문장은 [시각 분석 기록](visual-analysis.json)에 남긴다.

## 아스텔라의 재질·이야기와 연결하는 범위

은빛 금속·차가운 상아색·어두운 인디고·절제된 자수정색은 승인된 UI의 재질 언어를 타이틀로 옮기는 디자인 선택이다. 숲은 비교 화면의 배경 분위기이며, 로고 PNG 안에 숲이나 풍경을 굽도록 요청하지 않았다. 멈춘 시간·시계탑·원정은 저장소에서 확인한 모티프를 사용하되, 그 위에 새로운 신·종교·성좌 체계·지명·프리즘의 창세 이야기를 만들지 않는다.

`ASTELLA`는 일곱 대문자 `A S T E L L A`로만 표시한다. 참고 로고의 글자·수치·캐릭터·문장·대표색을 합성하거나 동일한 윤곽을 복원하는 것이 목표가 아니다. 원리에서 출발해 새 획·배치·장식을 탐색한다.

## 결과물과 확인 상태

제작 방식은 내장 `image_gen.imagegen`에 공식 Steam 헤더 한 장을 시각 참고로 제공하는 래스터 콘셉트 생성이다. 투명 알파 PNG에 조각된 금속·에나멜·붓결과 입체 질감을 표현하도록 요청했다. **편집 가능한 벡터 로고, 글꼴 파일, 3D 모델 또는 확정 브랜드 원본을 제작한 결과가 아니다.** 참고용 JPG·파생 썸네일은 비교 자료이며 게임에 가져올 에셋이 아니다.

완료한 비교 화면과 검사 기록은 다음과 같다.

- 원본 PNG 5개의 `ASTELLA` 철자와 글자 노출은 [generation.json](generation.json)의 시안별 `manualReview`에 육안 확인으로 기록했다. [compression.json](compression.json)은 실제 투명 알파, 원본 SHA256 보존, 축소 WebP와 기준 캔버스 사이의 알파 차이 0을 기록한다. 최종 WebP 5개는 최대 폭 480픽셀·품질 0.70, 합계 113,418바이트다.
- [validation.json](validation.json)은 21~25 각각의 1920×1080 렌더와 21번의 1366×768 렌더, 총 6개 경우의 검사 통과를 기록한다. PNG 철자는 위 육안 기록으로 확인하며 HTML의 `alt` 확인을 OCR 검사로 취급하지 않는다.
- [native-validation.json](native-validation.json)은 참고 썸네일 5개·생성 로고 5개 로드, 카드·탭 선택·확대·전체 보기 복귀 검사 통과와 원격 이미지 요청 0건을 기록한다.
- [review-assets.json](review-assets.json)은 참고 헤더의 작은 JPEG와 공유 숲 배경의 파생본 6개를 만들면서 원본 해시가 유지됐음을 기록한다.

이 결과는 래스터 타이틀 시안과 브라우저 비교 화면의 검증이다. 최종 브랜드로 확정한 상태가 아니며 Unity에는 적용하지 않았다.

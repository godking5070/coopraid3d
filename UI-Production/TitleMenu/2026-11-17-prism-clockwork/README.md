# ASTELLA · 태엽과 시계 16~20

태엽·시계 요소를 타이틀에 넣어보자는 요청으로 만든 입체 아트 5종이다. 은빛 금속·보라색 재질을 유지하고, 태엽·기어·시곗바늘을 글자 구조에 연결했다. **내장 image_gen.imagegen**으로 각각 새로 생성한 투명 래스터 로고이며 CLI/API fallback은 사용하지 않았다. 이전 1~15번은 보존한다.

| 번호 | 시안 | 중심 모티프 |
|---|---|---|
| 16 | 감긴 태엽 | 중심축에 감긴 납작한 금속 태엽과 글자로 이어지는 끝선 |
| 17 | 맞물린 시간 | 글자 사이의 톱니바퀴와 작은 조속 장치 |
| 18 | 멈춘 초침 | T의 획과 연결되는 시곗바늘·부분 눈금 |
| 19 | 깨진 태엽 | 끊어져 풀리는 태엽과 비대칭 금속 곡선 |
| 20 | 회중시계 | 작은 용두·고리·열린 시계 테두리와 연결된 제목 |

기존 스토리에는 시계탑·열두 번째 종소리와 과거 인형극 속 멈춘 시간이 등장한다(`StageManager.cs:304–308`, `BossMarionetteNormal.cs:499–501`). 이를 시각 모티프로 참고했으며 새 세계관 고유명이나 공식 문장을 정한 것은 아니다. 시안 이름은 비교용 명칭이다.

`index.html`에서 16~20번을 전환한다. `?capture=1&concept=19-brokencoil`처럼 직접 지정할 수 있다. 숲과 폰트는 `../2026-11-17-prism-engraved/` 원본을 재사용한다. 메뉴는 선택·저장 예시·키보드 포커스 확인용이며 실제 게임·저장·종료와 연결되지 않는다.

- `Artifacts/*.png`: 원본 투명 PNG 5개. 생성 파일의 바이트를 변경하지 않았다.
- `Artifacts/*.webp`: 채팅용 알파 보존 축소본. 원본 PNG는 별도로 유지한다.
- `prompts.json`: 정확한 5개 생성 요청문과 도구·입력 조건.
- `generation.json`: 원본 경로·치수·샘플 알파·SHA256·원본 보존 기록.
- `preview-*-1920.png`, `preview-16-mainspring-1366.png`: 같은 배경 위 브라우저 렌더.
- `validation.json`, `compression.json`, `native-validation.json`: 화면·입력·형식 변환·채팅용 카드·전환·확대 검사.
- `render-preview.cjs`, `publish-inline.cjs`: 실제 렌더와 채팅용 5종 비교 화면 재생성.

ASTELLA 철자는 비트맵에서 시각 확인하고 DOM alt 검사와 구분한다. 편집용 벡터나 PSD 원본은 없다. 기계 장식은 아트 표현이며 제목 아래에 새 문구나 스포일러 도상을 넣지 않았다. 이번 변경은 독립 디자인 시안 폴더 추가로, Unity 스크립트·씬·프리팹·프로필 적용이나 실제 Play 검증을 뜻하지 않는다.

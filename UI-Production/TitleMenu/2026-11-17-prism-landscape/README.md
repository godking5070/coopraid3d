# 아스텔라 첫 화면 — 풍경과 텍스트 메뉴 시안

사용자가 보여준 두 첫 화면에서 큰 풍경, 독립된 로고, 단순한 텍스트 메뉴 구성을 참고했다. 사용자는 **시안부터 보기**, **첫 번째 예시처럼 중앙 로고 + 하단 텍스트 메뉴**를 선택한 뒤, 중앙 안을 보존하면서 **Shape of Dreams처럼 왼쪽 로고 + 세로 메뉴**의 비교안을 추가로 요청했다. 중앙 안은 `title-centered-preview.html`, 새 숲 풍경 비교안은 `title-dreams-preview.html`이다. 중앙 안과 초기 왼쪽 메뉴 파일은 그대로 보존한다. 기존 게임 화면·Unity 자산은 변경하지 않는다.

배경은 아스텔라의 은색·자수정 공명을 바탕으로 새로 생성했다. 글자를 구워 넣지 않은 원본 `title-environment.png` 위에 HTML로 로고와 메뉴를 배치한다. 로고와 메뉴에는 기존 MaruBuri, 보조 안내에는 기존 Pretendard 파일을 사용한다. 배경 이미지 자체는 UI 합성 과정에서 수정하지 않는다.

- `title-environment.png`: 새 풍경 배경 원본
- `title-centered-preview.html`: 중앙 로고·하단 메뉴 시안. 클릭·포커스·저장 상태 예시 확인
- `title-centered-preview.png`: 중앙 구도의 1920×1080 전체 화면 캡처
- `title-dreams-environment.png`: 새 숲 풍경 배경 원본. 전경의 나무·수정 식물과 오른쪽 빛으로 깊이를 만드는 별도 배경
- `title-dreams-preview.html`: 왼쪽 로고·세로 메뉴 비교안. 기존과 같은 6개 메뉴와 저장 상태 예시
- `title-dreams-preview.png`: 숲 풍경 비교안의 1920×1080 전체 화면 캡처
- `dreams-generation.json`: 숲 풍경의 내장 이미지 생성 요청문·원본 경로·해시
- `title-preview.html`, `title-preview.png`: 이전 왼쪽 메뉴 구도와 캡처
- `generation.json`: 내장 이미지 생성 도구의 정확한 요청문·원본 경로·배경 해시

HTML은 이 폴더에서 열면 된다. `?capture=1`은 바깥 검토 도구를 숨기는 촬영 모드다. 클릭은 화면 반응만 보여주며 실제 게임·저장·종료를 실행하지 않는다. 배경은 입체감을 가진 정지 이미지이며, 실시간 3D 장면이나 영상으로 제작한 결과는 아니다.

중앙 구도는 같은 배경과 기존 폰트로 비교하도록 구성했다. 로고는 화면 가로 중앙에 크게, `새 원정 시작·설정·종료`는 하단 주 메뉴로, `이어하기·파티 참가·저장 관리`는 작은 보조 줄로 배치한다. 하단의 넓고 약한 어둠 그라데이션과 글자 그림자로 돌길 위 글자를 읽기 쉽게 한다. 픽셀아트나 반사 효과는 추가하지 않았다. 좌우 방향키는 같은 줄, 위아래는 두 줄 사이의 가까운 활성 항목으로 이동한다. 저장 안내 영역은 높이를 확보해 예시 저장 상태를 바꿔도 배치가 움직이지 않는다.

새 숲 풍경 안은 두 번째 참고 화면의 몰입감 있는 전경·중경·배경과 왼쪽 세로 메뉴 구도를 참고했다. 아스텔라의 은빛·자수정 색감과 기존 MaruBuri·Pretendard 폰트로 별도 구성했다. 오른쪽의 나무와 자수정 핵, 빛나는 식물은 새로 생성한 원본이며 참고 게임의 로고·계정·통화·크레딧은 사용하지 않는다. 메뉴는 기존 기능 6개만 보여준다. 위아래 방향키와 Home·End로 활성 메뉴 사이를 이동한다. 새 풍경도 정지 이미지로, 실시간 배경이나 애니메이션을 구현한 결과는 아니다.

| 시안의 메뉴 | 기존 기능 연결 기준 |
| --- | --- |
| 이어하기 | `_homeContinue`, `이어하기  >`, `ContinueFromMenu`; 저장·미정산 보상·busy 상태를 기존 writer가 결정 |
| 새 원정 시작 | `_hostEntry`, `방 만들기`; 기존 혼자 시작·Steam·LAN·난이도 선택 화면으로 이동 |
| 파티 참가 | `_joinEntry`, `들어가기`; 기존 친구·LAN·재접속 화면으로 이동 |
| 저장 관리 | `저장 관리`; 기존 기록·체크포인트 관리 유지 |
| 설정 | `설정`; 기존 설정 창 유지 |
| 종료 | `게임 종료`; 기존 종료 처리 유지 |

실제 적용 때는 홈의 기존 버튼·콜백을 유지하며 표시만 바꾼다. 공유 `_menuTitle`, `_menuSubtitle`, `_menuLayout`을 홈 요구로 전역 변경하지 않는다. 배경의 가시성은 `_homeMenu.activeInHierarchy`와 연결해 대기실·전투 위에 남지 않도록 한다. 이 문서는 시안의 연결 기준이며 Unity 구현·Play 검사 완료를 뜻하지 않는다.

검사: JavaScript 문법, 로컬 폰트 로드, Edge headless의 1920×1080 렌더, 예시 저장 상태와 메뉴 6개 표시를 확인했다. 배경 원본 해시는 `generation.json`과 일치하며 PNG 두 파일은 Git 저장 바이트와 로컬 파일이 같다. Unity 소스·씬·프리팹·프로필은 변경하지 않았다.

중앙 시안 추가 검사: JavaScript 문법, 1920×1080·1366×768 Edge 렌더, `document.fonts`의 두 폰트 로드 완료, 예시 저장 있음에서 이어하기 활성화를 확인했다. 원래 배경의 SHA256은 그대로이며 Unity 적용·Play 검사는 수행하지 않는다.

숲 풍경 비교안 추가 검사: JavaScript 문법, Edge의 1920×1080·1366×768 렌더와 화면 내 로고·6개 메뉴 가독성을 확인했다. 기본 상태의 이어하기 비활성화, 예시 저장 상태의 활성화와 안내, 두 로컬 폰트 로드 완료를 실제 DOM에서 확인했다. 방향키·Home·End의 활성 항목 이동과 선택 표시는 코드 검토했다. 이전 중앙·왼쪽 HTML과 PNG 4개의 SHA256 및 원 배경 해시가 작업 전과 같다. 새 배경의 해시는 `dreams-generation.json`에 기록했다. Unity 적용·실제 게임 Play 검사는 범위에 포함하지 않는다.

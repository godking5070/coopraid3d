랜서 핫바 입력 피드백 — 2026-11-05

변경
- SkillHotbarUI.cs: 공용 핫바의 키 입력에 0.18초 테두리 강조, 누르는 동안 강조 유지. 클릭도 같은 강조 사용.
- CharacterFrameworkUI.cs: 추가 슬롯 입력 강조는 매 프레임 확인. 기존 자원/툴팁 갱신 주기와 분리.
- 기존 버튼 색상·폰트·배치를 덮지 않는 별도 테두리 사용. 입력 가림 상태에서는 표시하지 않음.
- 1/2 등 기본 슬롯에 사용 가능, 공유 GCD/대기 시간, 다음 콤보 단계, 자원 부족 표시.
- 강조는 입력 확인이며 서버 실행 성공 또는 적중 확인이 아님. R 길게 입력도 실제 발동 전에 입력만 강조함.

명령 확인
- Run-StudioChecks.ps1 -Group Compile: runtime/editor managed compilation 통과.
- Unity 실행/직접 조작, 씬·프리팹 편집, 병합·푸시 없음.

사용자 플레이 확인 — 미검증
1. 원본 Unity에서 변경 코드가 컴파일된 후 랜서로 1/2/3/4/Q/R을 누른다. 해당 슬롯 테두리가 즉시 강조되어야 한다.
2. 1/2를 번갈아 사용한다. 각각 다음 단계가 독립적으로 유지되고 공유 GCD가 끝나면 사용 가능이 보여야 한다.
3. 쿨타임/전류 부족에서도 키 입력 강조는 보이지만 상태 안내는 대기/자원 부족으로 남아야 한다.
4. R 짧게/길게 입력의 원래 기술 동작이 유지되어야 한다. 강조만으로 발동 성공을 판단하지 않는다.
5. 메뉴·채팅 등 입력 가림 중에는 스킬 입력 강조가 나오지 않아야 한다.
6. 사용자 편집 핫바의 작은 글씨/테두리 가독성 및 온라인 실행 상태와의 체감은 별도 확인한다.

미확정
- 0.18초 입력 강조와 테두리 3px은 UI 초기값. 사용자 플레이 후 조정 가능.
- 스킬 실행 성공/적중 전용 효과 및 서버 확정 ACK는 이번 입력 표시와 별개이며 추가되지 않음.

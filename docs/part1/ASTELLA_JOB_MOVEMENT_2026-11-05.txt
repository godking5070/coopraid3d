조작
- 팔라딘은 이동키와 관계없이 발동 순간 바라보는 방향의 반대로 후퇴. 후퇴 중 몸을 이동 방향으로 돌리지 않음.
- 다른 직업은 이동키 방향. 입력이 없으면 바라보는 방향. 적을 자동 추적하지 않음.
- 모든 이동은 기존 충돌 스윕·지상 판정 사용. 공중 상태·기본 무적·이동으로 공격 자원 생성 없음.
- 도약은 기술 이름이며 공중 전용 판정을 추가하지 않음. 현재는 지상 이동 구현, 별도 점프 애니메이션은 제작하지 않음.
- 아스트로맨서의 기존 일반 영창 유지 규칙 보존. 종말의 분할 영창은 기존 중단 규칙을 따름.
- 충전은 순차 회복. 기본 개성과 기존 보조 특성의 추가 충전/재충전 대가는 함께 적용.
- 신중한 보폭은 기존 거리 +1m / 재충전 +2초 유지.
- HUD는 특성을 포함한 실제 최대 충전 수와 후퇴/방향 입력 규칙 표시.

플레이 미검증
1. 원본 Unity 재컴파일 후 허수아비를 바라보고 팔라딘 Space: 입력키와 무관하게 뒤로 이동하고 몸은 정면 유지.
2. 나이트/바드/레인저: 짧게 세 번 이동 후 추가 입력 차단, 충전 한 개씩 회복.
3. 아스트로: 방향 입력으로 긴 단발 이동, 벽·장애물을 관통하지 않음. 일반 영창/분할 영창의 서로 다른 규칙 확인.
4. 나머지 직업의 거리·속도·회복 주기와 역할별 기믹 대응 난이도 비교.
5. 기동 보조 특성 장착·해제, 구세이브·재도전·스테이지 전환 후 충전/HUD 확인.
6. 호스트/클라이언트에서 후퇴 정면 유지, 짧은 다회 이동 예측·보정 확인.
Unity 실행·자동 조작·씬/프리팹 YAML 변경·병합·푸시 없음.

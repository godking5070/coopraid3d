ORCA 전달용 프롬프트 — 근딜·유격대·캐스터 6직업 / 18루트 / 9키
작성 기준: 2026-11-02 대화

너는 보스 레이드 게임의 기획 협업자다. 아래 내용을 이전 탱커·힐러 명세와 연결하여 딜러 기획에 반영해 줘.
사용자 조건, 이전에 제안한 템페스트 설계, 이번 신규 설계 제안을 구분한다. 수치는 구조 확인용이며 밸런스 검증 결과가 아니다. 참고 원문의 수치·패널티·옛 키를 자동으로 덧붙이지 않는다.

1. 유지할 조건과 공통 키

- 4인 1탱·1힐·2딜, 8인 2탱·2힐·4딜. 고정된 보스 스테이지와 클리어 후 대기실 정비.
- 스킬·특성은 직접 선택한다. 빌드 획득을 랜덤 보상에 맡기지 않는다.
- 근딜: 나이트블레이드·템페스트 랜서. 유격대: 건슬링어·스피릿 레인저. 캐스터: 아스트로맨서·미러 팬텀.
- 공중 상태·공중 전용 자원·착지 입력 없음. 화살·별·환영이 공중에 보이는 연출과 캐릭터의 공중 판정은 구분한다.
- 스피릿 레인저는 소환수 없는 궁수다. 정령시는 화살 연출이다.
- 딜러 9키: 1 기본 콤보 / 2 교체 콤보 / 3 교체 기술 / 4 역할 기술 / Q 개인 방어 / Space 이동 / R 루트 핵심 / F 교체 전술 기술 / V 필살기.
- 1→1′→1″, 2→2′→2″. 두 콤보는 독립적으로 진행을 보존한다. 이동·일반 논글쿨·다른 콤보 선택으로 초기화하지 않는다.
- 2·3·4·F를 교체한다. 4는 카운터·무력화·동료 보호 중 하나. 카운터 미장착 시 다른 동료가 담당하도록 대기실에서 확인한다.
- 탱커 F 도발·인계, 힐러 F 광역 회복을 딜러에게 복제하지 않는다. E·Z 등 별도 스킬 키를 추가하지 않는다.
- 핵심 특성 1개 + 서로 다른 보조 특성 2개. 루트는 1·2·R만으로 성립해야 한다.
- R 짧게/길게·상태별 재입력은 같은 키의 동작이다. 다음 동작·비용·남은 시간을 아이콘으로 표시한다. 마우스 대상·지점 선택은 추가 스킬 키가 아니다.
- 루트 자원 규칙이 기본을 덮어쓴다고 명시되면 두 규칙을 중복 적용하지 않는다.

2. 공통 전투·협동 기준

- 4의 카운터는 신호 중 정면 적중으로 공격을 중단·그로기 처리한다. 원거리 카운터도 정면 조건을 지킨다. 보스 반대편 자동 순간이동이나 자동 후방 반사로 조건을 우회하지 않는다.
- 무력화·보호 선택은 카운터 성공을 대신하지 않는다. 역할 슬롯을 평상시 딜 때문에 반드시 소모해야 하는 버튼으로 만들지 않는다.
- Q·4·Space는 직업 자원이 없어도 사용 가능하다. 탄이 비거나 주문을 준비 중이어도 필수 대응 입력을 봉쇄하지 않는다.
- 조준·영창·채널은 대응 입력에 우선권을 준다. 취소된 공격을 동시에 완주시키지 않는다. 직업에 명시한 보존·환급만 적용한다.
- 기본 이동에 무적을 자동으로 붙이지 않는다. 플레이어가 지정한 합법적인 지상 지점으로 이동하며 위험 지역으로 자동 추적 이동하지 않는다.
- Space 사용에 장전·공격 자원 보상을 붙여 불필요한 이동을 딜 의무로 만들지 않는다.
- 원거리 직업에게 최대 거리 유지·받는 치유 감소·근거리 피해 급감 패널티를 기본으로 주지 않는다. 보스를 돌리거나 아군과 멀어져야만 강해지는 규칙을 피한다.
- 고의 피격·저체력 유지로 공격 자원을 얻지 않는다. 특정 직업 동료가 없으면 핵심이 멈추는 연계도 만들지 않는다.
- 자원은 명시한 직접 입력/완주로만 획득한다. 다단히트·적 수·도트·복제·추가타로 획득량이 불어나지 않는다.
- 예약 자원은 즉시 사용 가능 자원에서 제외한다. 완료 또는 취소 중 한 번만 정산하며 환급은 상한을 넘지 않는다.
- 적이 무적·공격 불가이면 자동 폭발·기록 재생도 해당 판정을 따른다. 무적을 무시하거나 실패한 추가타를 무한 재시도하지 않는다.
- 협공 표식은 기본적으로 다른 동료의 직접 공격에 반응하며, 동료별 1회 권한과 짧은 유효 시간을 사용한다. 자동 공격·도트·복제·추가타는 다시 협공을 생성/발동하지 않는다.
- 특정 기술이 본인+다른 동료 1명의 공격을 요구하면 그 개별 규칙을 우선한다. 같은 시전자의 표식 재적용으로 발동권을 무한 비축하지 않는다.
- 4인·8인의 총 협공 예산을 별도 검증한다. 피해 감소·이동 지원의 동일 효과는 중첩하지 않고 갱신한다. 동료 보호는 힐러 명세의 출처별 보호막 규칙을 따른다.
- V는 별도 필살기 자원을 쓴다. 일반 자원·스킬 쿨타임 초기화나 복제는 기본 제공하지 않는다.
- 전투 전 파밍 대신 스테이지 진입·재도전 시작 자원을 고정한다. 구체 시작값·계수·쿨타임·사거리·해금은 미정/검증 대상이다.

3. 나이트블레이드 — 위치 기회, 연계 길이, 적 행동을 읽는다

기본 자원: 그림자 인장 최대 5. 1·2 완주 적중 시 각각 1개. 잘못된 방향에서도 기본 수급은 유지한다.
1 [암영 검술]: 그림자 베기 → 초승달 교차 → 흑월 절개.
2: [절개 연격] 근접·짧은 출혈 / [비수 투척술] 중거리·낮은 근접 효율 / [파쇄 연격] 무력화.
3: [순간 절개] 빠른 근접 추가 공격 / [급소 투척] 원거리 공격 / [연막 수호] 지정 동료 보호.
4: [그림자 반전] 전방 카운터(자동 순간이동 없음) / [아킬레스 절단] 무력화 / [밤의 장막] 동료 보호.
Q [연막 외투]: 개인 피해 감소. 기본 완전 무적·어그로 초기화 없음.
Space [사각 스텝]: 방향 지정 지상 이동.
R: 종언의 일격 / 흑월 종결 / 기폭 봉인.
F: [암기 주머니] 인장 1 보충 / [유도 독침] 본인+다른 동료 1명의 직접 공격으로 협공 완성 / [야행로] 동료 이동 지원.
V [영겁의 절명]: 연속 비수 공격과 마무리. 보스 행동 강제 정지 없음.

N1 사각의 집행자 — 위치 기회의 저장
- 1·2 완주를 측면·후방에서 맞히면 해당 적의 약점 정보 1개. 기본 보관 최대 2개. 기본 인장과 별개다.
- 방향 판정이 없는 적에는 완주로 정보를 획득하는 대체 규칙을 제공한다. 유효 방향을 UI에 표시한다.
- R [종언의 일격]: 인장 2 소비. 대상의 정보가 있으면 1개를 함께 소비해 강화한다. R 자체는 현재 방향과 무관하다.
- 정보는 획득한 적에 귀속되며 다른 적에게 옮기지 않는다. 정보가 없어도 기본 R은 사용 가능하다.
- 시너지: 정보 소비 R이 약점 공유 표식을 남긴다. 카운터를 위해 앞쪽으로 이동해도 저장한 정보를 쓸 수 있다.
- 흐름: 측·후방에서 정보 확보 → 위치 변경·기믹 대응 → 동료 공격 기회에 R.
- 핵심 특성: [집중 처형] 정보 상한 1·강한 소비 / [예비 암살] 상한 3·개별 보상 감소.

N2 무한 그림자 춤 — 콤보의 조기 종결
- 인장 대신 춤의 박자 0~3. 1·2 직접 공격 적중마다 1, 다단히트 중복 없음. 완주 인장 획득을 중복 적용하지 않는다.
- R [흑월 종결]은 논글쿨 위빙이 아닌 GCD 마무리기다. 박자를 전부 소비하고 직전에 사용한 1 또는 2 콤보의 남은 진행만 소모·초기화한다. 다른 콤보 진행은 보존한다.
- 1박: 짧은 종결, 다음 기본 공격 1회 중거리 도달. 2박: 무력화 종결. 3박: 피해 집중 종결.
- R은 박자·완주 자원을 만들지 않는다. 이미 정상 완주한 콤보가 있다면 그 콤보를 다시 완주한 것으로 계산하지 않는다.
- 암기 주머니는 이 루트에서 박자 1을 준다. 최근 콤보 진행이 없더라도 박자가 있으면 R은 사용 가능하며 소모할 콤보 진행만 생략한다.
- 시너지: 2박의 무력화 지원, 종결의 짧은 이동 지원. 이동 지원에는 별도 재발동 제한을 둬 1박 반복으로 무한 갱신하지 않는다.
- 흐름: 1→1′→R로 빠르게 종결 / 2→2′→2″→R로 3박 피해 집중.
- 핵심 특성: [짧은 무곡] 상한 2·짧은 종결 강화 / [삼막의 춤] 3박 강화·짧은 종결 피해 감소.

N3 인술의 달인 — 행동 종료를 예약하는 부적
- R [기폭 봉인]: 인장 2, 적에게 부적 최대 1개. 짧게=종언부, 길게=추적부. 길게 입력은 선택이며 차징 강화가 아니다.
- 종언부: 현재 또는 다음 시전바가 있는 보스 행동의 종료. 정상 완료와 동료 카운터·정상 기믹 중단을 모두 인정한다.
- 추적부: 보스의 스킬에 의한 자발적 이동 종료. 일반 탱커 추적 보행은 제외한다.
- 제한시간 안에 조건이 맞으면 강화 기폭. 조건이 없으면 만료 시 기본 기폭. 어느 기폭도 무적을 관통하지 않는다.
- 부적은 카운터·속박·공격 중단 기술이 아니다. 활성 부적이 있으면 새 부착을 막고 상태를 표시한다.
- 시너지: 종언부 성공은 후속 동료 보호, 추적부 성공은 재접근 이동 지원. 동료의 카운터 성공이 개인 보상을 빼앗지 않는다.
- 흐름: 다음 행동 확인 → 조건 선택 R → 기본 공격 유지 → 행동 종료에 기폭.
- 핵심 특성: [속결 인술] 기본 피해 일부를 부착 시 선지급 / [장기 봉인] 대기 시간과 조건 보상 확대. 총 피해를 중복 지급하지 않는다.

4. 템페스트 랜서 — 기존 지상 설계 유지

자원: 뇌룡의 전류 0~100. 1의 세 단계 적중은 10/10/20. 교체 2의 수급은 아래 개별 규칙.
1 [기본 창술]: 질풍 찌르기 → 나선 관통 → 뇌전 일섬.
2 선택:
- [회전창술] 창자루 후리기→회전 파쇄→폭풍 횡단. 전류 10/10/20. 완주로 다음 수동 3을 강화하는 연격 준비 1회.
- [뇌전투사] 뇌전 파편→나선 번개→천둥 관통. 중거리, 전류 5/5/10, 완주에 감전. 도트는 전류를 만들지 않음.
- [뇌운각인] 풍압 베기→유도 창격→뇌운 각인. 전류 10/10/10. 다음 자기 강습·회수·기폭을 1회 강화.
3 선택: [스카이 다이브] 짧은 제자리 강습·전류 10 / [전광 추격] 전류 20의 추가 창격 / [천뢰 투창] 중거리 2충전, 전류 소비·획득 없음.
4 선택: [뇌룡 파쇄창] 카운터 / [폭풍 분쇄] 무력화 / [풍벽 수호] 자신+지정 동료 보호.
Q [폭풍의 눈]: 개인 피해 감소.
Space [라이트닝 대시]: 방향 지정 지상 이동, 기본 2충전 제안 유지.
R: 창성 강하 / 뇌룡출수 / 폭풍창 설치·회수.
F 선택: [초전도 축전] 전류 30 / [유도 표식] 본인+다른 동료 1명의 직접 공격으로 기폭·무력화 / [폭풍의 씨앗] 독립된 짧은 설치 공격, F 재입력으로 조기 기폭.
V [천뢰 강림]: 지정 대상의 강한 뇌전 공격. 캐릭터 공중 상태·무적 없음.
스카이 다이브·창성 강하의 짧은 동작은 공중 규칙이 아니다. 지상 충돌·피격 판정을 유지한다.

T1 창공의 지배자 — 짧은 강습과 파티 후속 공격
- R [창성 강하]: 전류 50, 지정한 가까운 지점으로 짧은 지상 강습. 상승·체공·착지 재입력 없음. 초기 재사용 12초.
- 적중 시 뇌전 표식. 다른 동료에게 각각 1회 후속 직접 공격 권한을 제공한다. 표식 재발동 제한 12초, 자동 추가타 재귀 없음.
- 흐름: 전류 확보 → 개인 뇌운각인 등 준비 → 강습 → 동료 후속 공격.
- 핵심 변형 예: [연속 강습] R 2충전·비용 30·회당 피해 감소 / [잔류 뇌운] 강습 피해 일부를 짧은 지면 효과로 분배.

T2 뇌제의 창술 — 두 콤보 완주의 교차
- 다른 종류의 콤보 완주를 이어가면 전류 10 추가. 동일 콤보 반복을 큰 기본 피해 패널티로 처벌하지 않는다.
- R [뇌룡출수]: 전류 80, 초기 12초 가속 상태. GCD 초기 2→1.5초. 상태 중 1·2 콤보 수급(교차 보너스 포함)은 절반.
- 상태 중 교차 완주에 자동 뇌전격. 선택한 3의 충전·전류를 쓰거나 연격 준비를 소비하지 않는다. 활성 중 R 중첩 금지.
- 협공: 미리 지정한 동료가 교차 완주 신호에 직접 공격 적중 또는 직접 치유로 응답하면 랜서 전류 5, 동료의 작은 보호막. 재발동 제한 12초.
- F 직접 전류와 협공 환급은 상태의 절반 규칙에 포함하지 않는다.
- 흐름: 1 완주↔2 완주 → 전류·협공 → R 가속 → 교차 완주 유지.
- 핵심 변형 예: [사단연격] 선택 2에 전류 20의 선택적 4타, 추가 완주 보상·전류 획득 없음 / [집중 방출] 전광 추격을 비용 60의 큰 일격으로 변경.
- 사단연격의 선택적 4타는 다른 GCD를 사용하면 기회가 사라진다. 이동·논글쿨로는 보존한다. 기본 1·2의 독립 진행과 구분되는 예외다.

T3 태풍의 핵 — 두 창의 충전과 회수
- R 짧게: 전류 40으로 폭풍창 설치, 최대 2개, 초기 20초. 주기적으로 공격하되 전류를 만들지 않는다.
- 선택한 2의 기본 세 단계 적중마다 모든 활성 창에 충전 1, 각 최대 3. 추가 4타·도트·자동 타격은 충전하지 않는다.
- R 길게: 모든 루트 폭풍창을 회수·기폭. 충전당 전류 5 반환, 창당 최대 15. 자연 만료에는 기폭·환급 없음.
- 시너지: 회수 시 짧은 파티 이동 속도 지원, 재발동 제한 12초.
- F 폭풍의 씨앗은 별도 개체다. R로 회수하지 않으며 기본 루트 충전·환급도 받지 않는다.
- 흐름: 창 배치 → 2로 충전 → 보스 이동·공격 기회에 맞춰 회수.
- 핵심 변형 예: [유영 폭풍] 1 완주로 설치물을 대상 위치로 이동·기본 수명 감소 / [압축 폭풍] 자동 피해를 제거하고 예정 틱 위력의 일부를 상한 있는 회수 피해로 저장·수명 증가. 자동 피해와 저장 피해를 중복 지급하지 않는다.

템페스트 기존 보조 특성 후보 유지: 연계 축전(1 완주 수급 증가), 여분 축전지(상한 확대), 이탈 연계(Space 후 다음 1·2의 사거리 보완), 장기 기류(설치 지속 증가, 압축 저장 상한은 그대로), 표식 보존(표식 시간 연장, 횟수 증가 없음), 보호 기류(R 자원 사용 후 자기 보호, 재발동 제한).
주요 변형은 호환되는 선택 스킬 한 개에만 적용한다. 예를 들어 전광 추격 미장착 시 집중 방출을 선택하지 않는다.
템페스트의 여섯 주요 변형은 루트 전용 잠금이 아니다. 연속 강습은 R 창성 강하 또는 3 스카이 다이브, 사단연격은 선택 2, 유영·압축 폭풍은 R 폭풍창 또는 F 폭풍의 씨앗 중 하나에 적용한다. 잔류 뇌운은 호환되는 강습·투사 기술, 집중 방출은 전광 추격에 적용한다.

5. 건슬링어 — 사격 수단의 가용 시간과 발사 준비를 관리

기본 자원: 마탄 최대 6. 피스키퍼 외 루트에서 1 완주 +2발, 2 완주 +1발. 기본 1·2 공격 자체는 탄이 없어도 가능하며 R 준비에 마탄을 쓴다.
1 [은탄 속사]: 패스트 드로우 → 더블 탭 → 실버 불릿.
2 선택: [관통 사격] 단일·직선 / [확산 사격] 범위·무력화 / [은화 사격] 짧은 지속 피해.
3 선택: [트릭 샷] 즉발 공격 / [섬광탄] 무력화 / [추적 은탄] 지연된 추가 공격.
4 선택: [피스키퍼 산탄] 카운터 / [충격 유탄] 무력화 / [엄호탄] 동료 보호.
Q [사냥꾼의 외투]: 개인 피해 감소.
Space [전술 구르기]: 지상 이동. 마탄 획득 없음.
R: 교대 장전 / 파열 유탄 / 은빛 관측.
F 선택: [예비탄] 일반 루트 +2발, 피스키퍼 양손 각 +1발 / [엄호 연막] 동료 보호 / [전술 신호] 이동 지원.
V [은빛 세례]: 강한 은탄 공격. 탄창·Q·카운터 쿨타임 자동 초기화 없음.
3·4·Q·Space·지원 F는 주 탄창과 별도 기능이며, 빈 탄창에서도 사용 가능하다.

G1 피스키퍼 — 양손의 사격·장전 교대
- 일반 마탄을 왼손 3발+오른손 3발로 교체한다. 1 매 단계는 왼손 1발, 선택한 2 매 단계는 오른손 1발을 실제 발사 시 소비한다.
- 기본 완주 장전(+2/+1)은 적용하지 않는다. 선택한 2는 사격 형태만 바꾸고 오른손 비용은 같다.
- R [교대 장전] 짧게: 마지막으로 1·2를 쏜 손을 장전. 기록 없으면 왼손. 그 손이 가득 차 있으면 현재 탄 수가 최대치 미만인 반대 손을 선택한다. 양손 모두 가득 차면 사용하지 않는다.
- R 길게: 마지막 발사 손의 반대 손을 직접 선택해 장전한다. 선택한 손이 가득 차면 사용하지 않는다. 활성 장전 작업은 1개이며 진행 중 새 장전은 시작하지 않는다. 짧게/길게의 대상 손을 UI에 표시한다.
- 장전 대상 손과 완료 시간을 아이콘에 표시한다. 초기 장전 2초, R 재사용 6초.
- 한 손을 장전하는 동안 반대 손 사격·Q·4·Space는 가능하다. 장전 중인 손 공격만 대기한다. 같은 손의 콤보 진행은 보존된다.
- 빈 손으로 공격하려 하면 탄·콤보 진행을 소비하지 않고 안내한다. 방어와 이동까지 잠그지 않는다.
- R만으로 빈 양손을 다시 채울 수 있어야 한다. 공용 F 예비탄을 필수로 요구하지 않는다.
- 시너지: 장전 완료 후 해당 손의 첫 적중이 협공 표식을 부여. 별도 재발동 제한으로 조기 장전 반복을 제한한다.
- 흐름: 왼손 사격 → 왼손 R 장전 → 오른손 사격 → 오른손 R 장전 → 왼손 복귀.
- 핵심 특성: [교대 속장] 적은 탄을 자주 장전 / [심부 탄창] 손별 용량 증가·긴 장전.

G2 전술폭파수 — 유탄 타이머를 콤보로 조절
- R [파열 유탄]: 마탄 3발 소비, 적에게 유탄 1개 부착. 초기 6초 후 자동 기폭.
- 활성 유탄은 시전자당 최대 1개다. 활성 중 R로 추가 부착·대상 변경·덮어쓰기를 하지 않는다.
- 부착 중 1 완주가 남은 시간을 2초 앞당기고, 2 완주가 2초 늦춘다. 최초 부착 후 최대 수명 초기 10초.
- 시간이 0 이하가 되면 1회 기폭. 활성 중 R 재입력으로 수동 기폭하지 않는다. 타이머와 각 완주 후 예상 시점을 UI에 표시한다.
- 유탄은 적에 부착되어 이동한다. 설치 장판·포탑·열기 게이지가 아니다. 일반 완주 장전은 유지한다.
- 시너지: 기폭 뒤 짧은 파쇄 표식, 다음 다른 동료의 직접 공격 1회에 추가 무력화. 무력화 가능한 상태에서만 작동, 카운터 대체 없음.
- 흐름: 필요하면 콤보를 중간까지 준비 → R → 완주 선택으로 기폭 시점 조절 → 동료 공격·무력화 기회.
- 핵심 특성: [충격 신관] 짧은 기본 시간·작은 조정 폭 / [계획 폭파] 긴 시간·큰 조정 폭. 무한 연장 금지.

G3 데드아이 — 조준 완료와 실제 발사를 분리
- R [은빛 관측] 첫 입력: 초기 마탄 3발 예약, 짧은 정해진 조준. 오래 누른다고 단계가 증가하지 않는다.
- 완료하면 비용을 확정하고 준비된 저격 1개를 보관한다. 완료 즉시 자동 발사하지 않는다.
- R 재입력: 조준한 적에게 즉시 발사. 이동 중 가능. 목표는 조준 때의 적에 귀속한다.
- 준비 완료 전 Q·4·Space·다른 공격 입력으로 취소하면 예약 탄 반환. 완료한 저격은 이동·방어·기본 사격 중에도 제한시간 유지한다.
- 적이 잠시 무효이면 보관 시간 안에서 기다릴 수 있다. 발사를 거부한 입력은 준비를 소모하지 않는다. 발사 후 적중 실패는 재시도하지 않는다.
- 새 저격 중복 준비 금지. 준비 완료 후 만료는 공격 없이 소멸하며 이미 확정한 비용을 반환하지 않는다.
- 시너지: 발사 후 협공 표식. 조준을 미리 끝내고 카운터 성공·파티 공격 기회에 발사 가능.
- 흐름: 안전할 때 조준 완료 → 이동·대응·기본 사격 → R 즉발 저격.
- 핵심 특성: [연속 저격] 준비분을 작은 3회 사격으로 분할 / [종결탄] 높은 비용·준비 부담의 한 발. 추가 발사는 새로운 장전·준비를 생성하지 않는다.
- 협공 표식은 준비한 저격 한 세트에서 첫 유효 적중에 1회만 부여한다. 연속 저격의 각 발이 협공을 새로 생성하지 않는다.

6. 스피릿 레인저 — 탄착·연사 묶음·계절 순환

자원: 사계의 풍압 0~100. 기본 1·2 완주 적중마다 20. 원거리이지만 근접 사격에 기본 피해·치유 패널티 없음.
1 [바람 궁술]: 바람 화살 → 이중 시위 → 매의 눈 관통.
2 선택: [관통시] 단일 관통 / [갈래시] 넓은 범위·무력화 / [바람매듭시] 짧은 후속 피해. 모든 선택지는 루트의 곡사·완주 규칙을 전달한다.
3 선택: [유도 정령시] 유도 화살 / [쐐기시] 무력화 / [귀환시] 정해진 시간차의 왕복 공격. 다단히트로 자원 증가 없음.
4 선택: [돌풍 파쇄시] 카운터 / [뿌리 쐐기시] 무력화 / [수호 깃털] 동료 보호.
Q [바람의 장막]: 개인 피해 감소. 보스 기믹 표식 자동 정화 없음.
Space [윈드 워커]: 지상 이동.
R: 쌍성 관통시 / 질풍노도 / 계절의 발도·유예.
F 선택: [깃털 축전] 풍압 30 / [순풍의 이정표] 이동 지원 / [숲의 위장막] 자신과 지정 동료 보호. 어그로 초기화·보스 대상 해제 없음.
V [사계의 종언]: 계절 바람을 합친 강한 화살. 캐릭터는 지상에 남는다.

S1 천궁의 명사수 — 직사와 곡사의 탄착 합류
- 선택한 2의 각 직접 공격을 늦게 도착하는 곡사로 변형한다. 1은 직사다.
- 곡사 도착 전 UI가 보여 주는 넉넉한 예약 구간에서 1을 쏘면 해당 직사의 도착을 곡사와 맞춰 합류시킨다. 0.1초 반응을 요구하지 않는다.
- 초기 예: 곡사 4초 지연, 마지막 2.5초가 직사 예약 구간. 같은 적의 가장 먼저 도착할 미배정 곡사에 연결한다. 곡사 하나와 직사 하나는 각각 한 쌍에만 사용한다.
- 거리 때문에 예약 구간이 갑자기 짧아지지 않게 보정한다. 기본 자원 수급은 합류 성공과 독립적이며, 완주 자원은 해당 마지막 화살 적중 시 1회 획득한다.
- 합류 성공으로 작은 추가 타격과 합류 1개, 최대 3개. 추가 타격은 풍압·추가 합류를 생성하지 않는다.
- 예약 성공만으로 보상을 지급하지 않는다. 짝지은 두 화살이 같은 유효 적에게 실제 적중했을 때 합류·추가 타격을 1회 지급한다.
- R [쌍성 관통시]: 초기 풍압 40과 현재 합류를 소비, 강한 관통 사격. 합류 0이어도 기본 R 가능.
- 시너지: 합류를 사용한 R의 협공 표식.
- 흐름: 2 곡사 → 예약 구간에 1 직사 → 합류 → 2′/1′ 등 독립 콤보 유지 → R.
- 핵심 특성: [너른 합류] 넓은 예약 구간·합류 보상 감소 / [연속 탄착] 적은 합류로 작은 R을 자주 사용.

S2 질풍의 연사수 — 유한한 연사 묶음을 분배
- R [질풍노도]: 풍압 50, 첫 묶음 발사와 후속 묶음 2회 준비. 이동 중 사용 가능.
- 활성 중 R은 후속 묶음 1개씩 발사. 짧은 재입력 간격과 제한된 보관 시간을 둔다(초기 전체 16초 검토).
- 사이에 1·2 콤보를 완주하면 정교한 시위 1개, 최대 1개. 다음 후속 묶음에 소비해 강화한다.
- R은 풍압·정교한 시위를 만들지 않는다. 정상 콤보의 기본 풍압 수급은 유지한다.

C1 종말의 메테오 — 분할 영창

C2 유성우 지휘자 — 앞으로 쓸 주문의 즉시시전권 배분

M1 환영의 군단장 — 실제 사용한 행동의 기록 재생
- 자신의 1·2 마지막 공격이 실제로 적중하면 해당 기본 기술의 기록을 최근 2개까지 보관한다.

- R 짧게 [거울의 재연]: 초기 파편 2와 유효 기록 2개 소비, 해당 기술들을 환영으로 재생. 사용한 기록은 제거하고 잠금을 해제한다.

- 흐름: 원하는 1·2 완주 기록 → 잠금 → 기본 공격 유지 → 기회에 R 재연 → 새 기록.
- 핵심 특성: [선명한 잔상] 기록·비용을 1개로 바꾸고 한 기술 집중 / [연속된 기억] 2기술의 분할 재생과 두 번째 보상 강화.

M2 사신의 대낫 — 원격 유지와 공격 투자 사이의 파편 배분
- 이 루트의 2는 본체 근접 대낫 콤보다. 원거리 1은 그대로 파편을 얻는다. 원거리만 반복했다고 피로도·기본 피해 감소를 주지 않는다.
- R 짧게 [사신 투영]: 파편 1, 현재 진행 중이거나 다음에 시작할 2 콤보의 남은 단계를 원격 환영이 대신 사용한다. 이미 실행한 단계는 반복하지 않는다.

- 투영이 중간에 만료되어 남은 단계를 본체로 사용하더라도 그 2 콤보의 투영 사용 기록은 완주까지 유지한다. 만료를 이용해 자원 획득 예외를 우회하지 않는다.

- 흐름: 1로 확보 → 안전하면 직접 2 → 파편을 참수에 투자 / 위험하면 R 투영으로 남은 2 진행.
- 핵심 특성: [긴 그림자] 투영 거리·보관 여유 강화 / [실체의 칼날] 직접 2 완주 후 다음 참수 강화, 중첩 상한 1.

M3 프리즘 아키텍트 — 광선의 반사 경로
- R [프리즘 배치]: 파편 1로 거울 최대 2면 배치. 위치·방향을 지점 지정/드래그로 설정하고 광선 경로를 미리 표시한다.
- 기존 거울을 R로 선택해 방향·위치를 조정할 수 있다. 조정은 파편을 새로 쓰지 않되 짧은 재조정 제한과 기존 수명을 유지한다. 최대 수에서 새 거울을 놓으면 가장 오래된 것을 교체하며 미리 표시한다.
- 2 마지막 공격에는 기본 직접 타격과 별도의 반사 광선 보너스가 있다. 광선은 지정 첫 거울을 거쳐 최대 2회 반사한다. 거울 조정으로 경로를 설계한다.
- 같은 적에 여러 번 교차해도 한 번의 정해진 광선 피해 예산만 적용한다. 반사가 자원·추가 광선을 만들지 않는다.
- 경로가 실패해도 기본 1·2와 완주 자원은 정상 사용 가능하다. 보스가 움직일 때 경로를 다시 만들 이유가 생긴다.
- 거울은 자기 공격용이며 보스 투사체를 자동 반사하거나 카운터 조건을 우회하지 않는다.
- 시너지: 유효한 반사 완주에 추가 무력화. 동료가 광선 위에 서도록 요구하지 않는다.
- 흐름: 거울 배치·경로 확인 → 2 완주 → 보스 이동에 맞춰 재조정.
- 핵심 특성: [단일 초점] 거울 1면의 간단한 경로 / [다중 굴절] 2면 경로 성공 보상 강화.

9. 보조 특성과 같은 루트의 빌드

템페스트는 기존 전용 보조 목록을 유지한다. 다른 다섯 직업은 다음 공통 후보에서 서로 다른 2개를 고르는 초기안을 사용한다. 수치는 조정 대상이며 R 핵심을 대신하지 않는다.
- [사거리 조정]: 선택 2의 기본 사거리 증가, 직접 피해 효율 소폭 감소. 카운터·반사 횟수·설치 범위는 바꾸지 않는다.
- [기동 예비]: Space 최대 충전 증가, 한 충전 재충전 시간 증가. 이동에 공격 자원을 추가하지 않는다.
- [방어 여유]: Q 지속 증가, 재사용 시간 증가.
- [대응 전문]: 선택 4의 역할에 맞게 카운터 후딜 감소 / 무력화 보완 / 보호 지속 증가 중 해당 효과만 적용. 신호·정면 조건은 그대로.
- [지원 지속]: 선택 F에 존재하는 표식·보호·이동 지원의 시간 연장. 발동권 수·계수·자원 획득은 증가하지 않는다. 자원 전용 F에는 장착 불가 표시.
- [회복 호흡]: Q 사용 후 짧은 시간 받는 회복 효율 보완. 저체력·고의 피격·공격 보상을 조건으로 붙이지 않는다.

빌드 예:
- 나이트 N1 집중 처형: 절개 연격 / 순간 절개 / 카운터 / 유도 독침 / 집중 처형 / 대응 전문+기동 예비. 위치 정보를 빠르게 써 파티 공격·카운터에 맞춤.
- 나이트 N1 예비 암살: 비수 투척술 / 급소 투척 / 보호 / 야행로 / 예비 암살 / 지원 지속+회복 호흡. 이동 전에 정보를 저장하고 분리 구간 지원.
- 템페스트 T1: 뇌운각인 / 스카이 다이브 / 카운터 / 초전도 축전 / R 연속 강습 / 연계 축전+표식 보존.

공유되는 기본 동작이나 지원 효과 자체를 전부 없애려 하지 마. 루트의 지배적인 판단과 입력 흐름이 실제로 달라지는지 확인해.

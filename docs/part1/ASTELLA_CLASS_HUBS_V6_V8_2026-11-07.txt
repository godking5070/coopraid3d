요청: astella-player-hud-v6.zip + astella-player-hud-v8.zip, 중앙 궁극기 허브와 오른쪽 직업 자원 허브를 독립 적용.
기준 이미지: 사용자가 보낸 이지스 팔라딘 충전 중 하단 HUD.

두 계기는 독립된 값이다.
- 중앙: 실제 .ultimate 전용 자원의 현재/최대 비율과 궁극기 사용 제한 상태.
- 오른쪽: 실제 직업 고유 자원. .ultimate 자원을 제외한 주 자원과 현재 루트의 표시 단위.
- HP는 두 자원과 별도이며 실제 현재 체력 숫자를 크게 표시한다.
리소스의 예시 체력48639, 자원60, 기획 최대값은 게임 데이터로 사용하지 않는다.

사용 자산:
Assets/UI/AstellaClassHubs: 직업별 정적 레이어, 토큰, 상태 배지, 제공 manifest.
Assets/UI/Resources/AstellaUltimateMotion: 현재 직업에 필요한 때만 불러오는 모션 시트.
v6의 12직업 궁극기 기본 조형을 UltimateBaseV6에 보존했다.
v8의 충전 중/준비/사용 불가 상태 레이어는 같은 v6 조형 계열이며 추가 모션을 사용한다.
v6와 v8의 직업 자원 manifest는 완전히 동일하다.
이 두 패키지를 서로 대체되는 버전으로 취급하지 않는다.

궁극기 허브:
12직업, 공통 캔버스360x280, 직업마다 별도 chargeBounds.
track -> 고정된 fill을 아래에서 위로 노출하는 마스크 -> frame -> core -> 준비 발광 -> 모션 -> 실제 충전% -> 실제 키.
채움은 chargeBounds의 높이를 기준으로 하며 PNG 전체280px 높이에 바로 Filled를 적용하지 않는다.
장식의 날개·조각은 추가 스택으로 해석하지 않는다.
자원 부족으로 충전 중인 상태와 사망·잠금·행동 제한 등으로 사용 불가인 상태를 구분한다.
제한 중에도 실제 충전량은 보존하고 제한용 레이어만 사용한다.

애니메이션:
- 12직업별 충전 완료: 16프레임,24fps,약0.667초,1회.
- 12직업별 준비 대기: 48프레임,20fps,2.4초 반복.
- 실제 사용 가능한 상태에서 미충전->만충전으로 넘어갈 때만 완료 효과.
- 같은 만충전 값을 반복해도 효과를 재시작하지 않는다.
- 제한 중 만충전이 된 뒤 제한이 풀리면 완료 효과 없이 대기 효과로 진입.
- 처음부터 만충전인 화면, 직업 전환, 메뉴 복귀에도 새 충전 완료를 가정하지 않는다.
- reduceMotion=true이면 모션 없이 준비 기본 그림·밝은 배지만 표시.
- RawImage의 UV를 제공된 시트의360x280 프레임 순서대로 갱신한다.
- 현재 직업의 시트만 지연 로드하며 최대3장 캐시. 직업 변경/비활성화/파괴 시 해제한다.
- 직업 게이지에는 별도 프레임 애니메이션이 없고 실제 값에 따라 마스크/토큰이 바뀐다.

직업 자원 허브:
12직업,400x240. 연속형6개, 토큰형6개.
연속형은 각 fillBounds 안에서 채움 마스크만 줄이고 원본 그림의 위치·크기는 유지한다.
기계형 토큰은44/60px 로컬 위치, 유기형/환영형 토큰은 전체400x240 원점 레이어로 배치한다.
이미 그림 안에 들어간 중심·회전 좌표를 이중으로 적용하지 않는다.
토큰은 실제 정수 개수만 활성화하며 실제 최대값을 표시한다.
현재 루트에 따라 기본 아트 토큰 수를 넘는 자원이 있으면 전체 실제 current/max 수치를 유지한다.
패키지는 기본12직업 모양이며 모든 기원별 추가 계기까지 새로 그린 리소스는 아니다.

하단 구성:
1600x420 원본을0.5배율로 표시. HP와 왼쪽4칸, 중앙궁극기, 오른쪽4칸, 오른쪽위 직업 자원.
기존 위쪽 원형 아덴 그림은 오른쪽 직업 전용 계기로 대체한다.
좌우 스킬 그림은 미정이라는 이전 지시대로 빈칸을 유지한다.
기존 버튼, 실제 키, 쿨타임, 툴팁, 타기팅·전투 동작은 유지한다.
PlayerHUD와 left/right/center/identity 등 배치 편집 ID·객체를 보존한다.
파티·포션·공유 부활·보스 HUD는 변경하지 않는다.

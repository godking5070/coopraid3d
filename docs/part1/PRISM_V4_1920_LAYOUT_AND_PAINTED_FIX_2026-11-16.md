# Prism V4: 1920×1080 배치와 페인팅 리소스 정정

사용자가 제공한 로스트아크·파이널 판타지 XIV HUD의 크기와 위치를 참고해, 전투 공간을 남기는 하단 중앙 배치로 조정했다. 승인 그림을 단순 SVG로 다시 그리며 사라졌던 금속 베벨·창끝형 보스 보석·반투명 수정 질감도 페인팅 리소스로 교체했다.

## 활성 자산과 보존

- 브랜치: `ingame-move-system` (`Astella-Main` 작업 영역).
- 활성 프리팹: `Assets/UI/AstellaPrismV4/AppliedMain/Layout1920-20261116-162926-372/RaidHUD.prefab`.
- 이전 적용 프리팹과 해당 씬 인스턴스는 보존하고 비활성화했다. 원본 프리팹 및 메타 SHA256은 적용 전후 동일하다.
- 씬·프리팹은 원본 Unity 6000.3.26f1의 Editor API로 복사·저장했다. YAML은 직접 편집하지 않았다.
- 기존 Sprite GUID와 버튼·아이콘·입력·데이터 바인딩을 유지했다. 배치 저장 파일은 `hud-layout-prism-v4-1920.json`으로 분리해 이전 배치 파일을 보존했다.

## 실제 1920×1080 크기

전체 화면을 1672×941 시안에 맞춰 확대하던 별도 fit을 비활성화하고, 기존 CanvasScaler의 Expand 정책을 유지했다. 화면 전체에 stretch한 Prism 루트 안에 하단 공통 부모를 만들었다. 고정 크기 자식들이 따로 남는 문제를 피하도록 공통 부모를 0.5배로 저작했다.

| 항목 | 실제 RectTransform 크기/위치 |
|---|---|
| 하단 공통 영역 | 폭 836px, 하단 여백 24px |
| 스킬 슬롯 | 각 68×68px |
| 중앙 궁극기 | 136×136px, 중심 x=960 |
| HP·주 자원 | 각각 310×29px |
| 보스 HP | 672×50.4px, 상단 중앙 |
| 파티 행 | 255×51px, 좌측 상단 x=28, y=100부터 |

이 크기는 투명 여백을 포함하는 UI 사각형이다. 실제 페인팅 실루엣은 그 안에 있다. 툴팁은 별도 화면 좌표로 하단 HUD 위에 표시해 읽을 수 있는 크기를 유지한다.

## 게이지 넘침 수정

기존 Gauge는 `DataUtility.GetOuterUV`가 반환한 잘린 Sprite 영역을 전체 UI 사각형에 펼쳤다. 일반 Image는 투명 padding을 반영하므로 두 레이어의 실제 그림 크기가 달랐다. Gauge도 원래 Sprite 좌표에서 clipping하고 padding에 맞춰 UV를 변환하도록 수정했다. FullRect·Tight·atlas subrect와 preserveAspect/pivot을 함께 처리한다.

전체 전투 구성을 숨기는 `presentationRoot`를 브리지에 연결했다. 메뉴/결과 화면에서는 버튼과 보조 동작을 포함한 구성을 숨기고, 원본 데이터 presenter는 계속 동작한다. 메인 메뉴에서 설정을 통해 명시적으로 시작한 HUD 배치 편집은 미리보기를 허용한다. 저장된 기본값은 비활성이라 Edit Mode의 시작 화면도 가리지 않는다.

## 그림의 출처와 재현

승인 RGB 시안은 `UI-Production/PrismV4/approved-reference.png`에 보존했다. 내장 image_gen 편집으로 배경·텍스트·아이콘을 제외한 투명 아틀라스를 만들고, 그 페인팅 픽셀을 기계적으로 분리해 37개 Sprite를 정정했다. 기존 8개 상태 레이어는 유지했다. 원본 PSD나 원본 분리 레이어를 복구한 것은 아니다.

`UI-Production/PrismV4/raster-recovery/README.md`, `prompt.txt`, `Extract-Frames.ps1`, `Extract-Gauges.ps1`에 정확한 요청과 처리 방법이 있다. 이전 SVG는 구조 참고 자료로 남겼으며 현재 페인팅 PNG를 재현하는 소스가 아니다. 과거 SVG 생성기는 현재 PNG를 덮지 못하도록 차단했다. 새 아이콘 그림과 구워진 문자·수치는 없다.

## 검증과 증거

- UI 회귀검사 6개 스크립트 모두 통과. 실제 브리지 42개, 핫바 피드백 17개, UI 저작 진입점 51개 검사 포함.
- 패키지 검증: RGBA PNG 45개, 게이지 5개 계약 통과. 전체 채움의 양끝과 프레임 중앙 투명 확인.
- Gauge 실제 C# 기하 검사 64개 통과.
- 실제 Direct3D12/uGUI GPU 검사: 5종 × 0/50/100% 총 15개. 일반 Image 기준의 채움 실루엣 밖 픽셀 0, 100% 채움 및 프레임 합성 불일치 0. 경고 0.
- 원본 프로젝트의 실제 Play 2회 관찰 세션, 1920×1080 표본 221개. 가시 게이지 값 차이 0, 안정 불일치 0. Space 이동 후 쿨다운 표본 6개 확인.
- 실제 마우스 hover 툴팁, Space 이동/쿨다운, 메뉴를 열었을 때 HUD 숨김과 timeScale=0을 확인했다.
- 최종 캡처 도구는 명시 메뉴로만 실행하며, runtime 브리지의 coroutine을 통해 프레임 종료 후 실제 GPU 화면을 저장한다. Editor 컴포넌트를 붙이거나 자동 UI 저작 hook을 등록하지 않는다.

증거는 [evidence/prism-v4-1920](evidence/prism-v4-1920)에 있다. `ingame-1920.png`는 실제 싱글플레이 로비 캡처이며, `composite-gpu.png`는 별도 GPU 회귀 검사 화면이다. 이미지에 게임 배경을 합성하거나 게이지 값을 주입하지 않았다. 툴팁/쿨다운 데스크톱 증거 원본은 `C:/Astella/prism-v4-layout-1920-20261116/`에 보존했다.

이번 변경에서는 Windows 재빌드, 전체 직업/기원, 실전 궁극기 100%, 실제 멀티플레이·Steam 및 다른 해상도를 다시 검증하지 않았다. 이 검증 범위를 이전 적용 보고서의 범위와 구분한다.

# Stage 1 마을 수호 석상 하드 구현 기준

## 2026-11-07: 노말·하드 전투 템포와 연속 낙석 변경

사용자 요청으로 아래 초기 기획의 느린 준비·회복 시간을 변경했다. 이 절의 시간이 이전 기록보다 우선한다. 피해량·HP·카운터 기회·무력화 요구량은 이번 변경 대상이 아니다.

| 항목 | 노말 | 하드 |
| --- | --- | --- |
| 일반 준비 | 약 1.5~2초, 공명 집합 3초 | 약 1.5~2초, 공명 집합 3초 |
| 일반 / 무거운 패턴 뒤 휴식 | 0.9 / 1.2초 | 0.75 / 1초 |
| 낙석 시전 | 1.25초 | 1.2초 |
| 낙석 장판 생성 간격 / 횟수 | 0.75초 / 6회 | 0.55초 / 8회 |
| 각 낙석 장판 생성부터 타격까지 | 1.1초 | 0.95초 |
| 연속 휩쓸기 / 내려찍기 외곽 후속 간격 | 해당 없음 | 0.55 / 0.65초 |
| 뒤틀린 집행 준비 / 후속 간격 | 해당 없음 | 2.1 / 0.55초 |
| 봉쇄 조준 / 파쇄선 / 내부 소거 시점 | 해당 없음 | 시작 후 1.8 / 2.7 / 6초 |

낙석은 현재 생존자 위치를 매 회 고정해서 장판을 만들며, 기존 장판의 낙하를 기다리지 않고 다음 장판을 만든다. 각 장판의 타격 시간과 수명은 독립적이다. 낙석 중 보스는 추적·자동 공격을 이어가고, 다음 일반 패턴은 낙석 종료 후 선택한다. 변신·무력화 중단·처치·전멸·재도전·비활성화 시 남은 낙석을 취소한다. 참가자는 기존 AoE 스냅샷으로 같은 위치·마감 시간을 표시하며 피해는 호스트만 적용한다.

봉쇄는 파쇄선 이후 기본 탈출 시간이 6초에서 3.3초로 줄었다. 열린 출구가 있고 살아 있는 파티원 전원이 캐릭터 반경까지 포함해 원 바깥으로 나왔으면, 남은 시간이 더 긴 경우에만 0.55초 뒤 폭발하도록 단축한다. 일부가 안에 남아 있으면 단축하지 않는다. 폭발 후 벽을 제거하고 별도의 긴 회복 단계를 생략해 보스가 통상 휴식 중 바로 추적한다. 완전 봉쇄의 후속 돌진·카운터는 유지한다.

2차 템포 조정에서는 공중 돌진·완전 봉쇄·힘겨루기의 명시적 회복 이후 일반 휴식을 다시 붙이지 않는다. 완전 봉쇄·힘겨루기의 회복은 기본 0.9초다. 공격 준비와 카운터 기회를 줄여 휴식 시간을 대신하지 않는다.

작은 전방 부채꼴이었던 `ShieldPush`는 기존 저장·전송 ID를 유지한 채 **방패 충격파**로 교체했다. 보스의 시전 시작 방향을 기준으로 앞뒤·좌우에 길이 20m, 폭 3.2m인 두 직사각형을 교차시킨다. 두 범위의 합집합에서 피해·넉백을 대상당 한 번 적용하며, 대각선에서는 근접 공격을 이어갈 수 있다. AI도 같은 십자 판정을 사용해 가까운 대각선으로 이동한다. 노말은 준비 전체, 하드는 기존 마지막 0.4초의 바닥 강조를 사용하고 임시 방패를 들어 바닥에 내리는 준비 동작을 표시한다. 참가자에는 기존 직사각형 AoE 두 개로 전송한다.

기존 씬의 출하 기본 수치만 `tempoRevision`으로 이전하며 다른 사용자 조정값과 이전 이후 편집은 보존한다. 1차 템포를 이미 적용한 씬도 revision 2에서 짧은 간격으로 이전한다. 명령 검증: GuardianNormal 20,048개, GuardianHard 1,757개, 템포/이전/탈출/스케줄/십자 판정 40개, 실제 낙석 메서드 16개 및 네트워크·관리 컴파일 통과. 낙석 메서드 검사의 엔진·장면 의존성은 스텁이다. 실제 Unity 화면, 근접 복귀 동선, 4인 네트워크 체감은 아직 미검증이다.

## 2026-10-29 추가: 탱커 직업별 힘겨루기 애니메이션

힘겨루기 게임 판정과 6초 유지 시간은 세 탱커가 공통으로 사용한다. 카운터 **성공 후에만** 받아내기→유지→성공 밀어내기 또는 실패·중단→복구 연출을 시작한다. 클립 길이와 애니메이션 이벤트는 피해·성공·종료 시간을 결정하지 않는다. 호스트가 단계와 참여자를 전송하고 각 화면에서 해당 직업의 연출을 재생한다. 실패한 카운터는 탱커를 붙잡기 위치·자세로 옮기지 않는다.

원본 Unity 에디터의 보스 `BossController`에서 `guardianClashAegis`, `guardianClashBerserker`, `guardianClashDragon` 항목을 조정한다. 각각 `catchClip`, `holdClip`, `releaseClip`, `interruptClip`, `weaponContactPath`, `visualRootPath`, `contactLocalOffset`, `visualOffset`, `visualEuler`, `fallbackWeaponEuler`, `maxContactCorrection`, `requireWeaponVisible`, `catchVfx`, `releaseVfx`, `catchSound`, `releaseSound`가 있다. `visualRootPath`는 Animator가 직접 키를 찍지 않는 안정적인 시각 부모를 지정한다. 코드가 무기·Animator 상태와 루트 모션 설정을 종료 시 복구한다. 위치 보정은 캐릭터의 네트워크 이동 루트 대신 시각 부모에만 적용한다.

| 직업 | 기본 접촉 경로 | 임시 자세 |
| --- | --- | --- |
| 이지스 팔라딘 | `AegisSwordAndShield/GreatShield` | 방패를 들어 표면으로 받침 |

가고일 모델 프리팹에는 주먹 접촉 기준점 `FistContact`를 만들고 `guardianClashBossFistPath`에 그 상대 경로를 입력한다. 보스의 내려누르기·유지·밀어내기·중단 클립은 `guardianClashBossPress/Hold/Release/Interrupt`에 연결한다. 기준점·클립이 없으면 충돌 판정 없는 임시 주먹과 팔이 탱커의 무기 접촉점까지 닿도록 보인다. 사용자 모델·클립·VFX·효과음은 생성 코드가 만들거나 덮어쓰지 않는다. 실제 방패 표면·검신 접촉, 팔 관통, 발 미끄러짐과 직업별 보정은 Play에서 조정해야 한다.

## 2026-10-29 확정: 거대 가고일과 역할별 협동

이 항목이 아래의 이전 오염 석상 변신 설명보다 우선한다. HP 40% 변신은 진행 중 패턴과 석편을 마친 뒤 한 번 시작한다. 보스가 공중 도약하는 임시 연출 또는 사용자 Timeline을 재생하고, 현재 HP와 기존 보스·처치·보상 흐름을 유지한다. 변신 중 보스 HP 피해와 공격을 막는다. 변신 프레젠테이션의 카메라를 복구한 다음 중앙 힘겨루기 준비를 시작한다. 극한 설정은 변경하지 않는다.

일반 카운터의 신호·훈련장 안내를 금색으로 통일했다. 노멀의 카운터 가능 조건·시간·성공 효과는 유지한다. 임시 아이콘은 글꼴 지원 여부에 따라 달라질 수 있으므로 사용자 Play에서 확인한다. 빨간 범위는 기존 하드의 타격 직전 강조 규칙을 유지한다.

탱커는 중앙 원 안에서 보스 정면을 향해 기존 카운터 기술을 실제 적중시켜야 한다. 서버가 기존 `CombatCounterTarget` 기회를 한 번만 소비한다. 8초 변신과 11초 준비로 직전 기본 10초 카운터 재사용을 기다린다. 원에 서 있기·일반 공격은 성공 조건이 아니다. 원 중심의 보스 기존 타기팅 지점을 사용하고, 거대 모델 콜라이더는 꺼서 표시 크기와 타격 판정을 분리한다. 기본 보스 전투 반경 3.2m 바깥 약 0.5m에 AI 탱커가 접근하므로 파란 원은 4.2m다. 탱커 3직업은 공통 `PartyLife.IsTank`로 판정한다.

성공하면 탱커만 이동·공격·이동기를 제한한다. 자기 대상 스킬과 포션은 사용할 수 있고 외부 회복·보호막·감소 효과를 받는다. 기존 AI 탱커는 맥동 전 방어기를 사용하며, 힐러 AI는 기존 최저 체력 치료 판단을 계속한다. 다른 파티원은 자유롭게 공격·이동·회복한다. 맥동은 `guardian.clash.pulse`, 성공 해제 충격파는 `guardian.clash.release`, 실패 충격파는 `guardian.clash.failure` 출처로 피해 기록에 남긴다. 성공 시 마지막 1.5초에 충격파를 재예고한다. 실패·탱커 사망은 충격파를 한 번만 적용하고 복구 가능한 전투로 돌아간다. 보스 처치·전멸·장면 이탈·재도전은 기존 정리 흐름에서 붙잡기를 해제한다. 부활이나 부활 횟수는 변경하지 않는다.

성공 후 강화된 좌우 휩쓸기와 중심→도넛을 각각 소개하고, 뒤틀린 집행을 기존 반복 구간에 둔다. 25% 완전 봉쇄는 힘겨루기 종료와 회복 뒤 한 번 실행한다. 딜러에게 별도 필수 피해량은 없다. 원본 에디터에서 `BossController.guardianHardTransformationPresentation`에 사용자 Timeline 프리팹, `guardianHardGargoyleVisual`에 사용자 모델 프리팹을 연결할 수 있다. 연결 전에는 임시 도약·날개·머리·팔이 사용된다. 사용자 애니메이션의 팔·날개 동작과 실제 공격 방향 정렬은 Play에서 확인해야 한다.

이 문서는 이번 하드 구현의 초기 조정값을 기록한다. `research/cactbot/보스 패턴 설계 기준.md`, `사례별 설계 노트.md`, 최신 석상 기획안은 작업 공간에서 찾지 못했다. 아래 값은 확정된 외부 기획 수치가 아니라 이번 요청에 따른 구현 기준이다.

## 선택과 설정

메인 메뉴 → 방 만들기 → `Stage 1 난이도`를 하드로 바꾼 뒤 새 원정을 시작한다. 이어하기와 재도전은 저장된 난이도를 사용한다. 1부 Stage 2 이후의 보스 구성은 이 작업에서 바꾸지 않는다. 하드 전투는 `BossController.guardianHard`의 `GuardianHardSettings`와 그 안의 독립된 `combat` 설정을 사용한다. 노멀은 기존 `guardian` 설정을 사용한다.

하드 HP 30,000은 **개발 검증용 임시값**이다. 하드 전투 목표 5~6분은 강제 전멸 시간으로 쓰지 않는다. 공격력·시전·간격도 모두 초기 조정값이다. 하드 `combat.tempo=1`이며 노멀의 1.2 배율을 다시 적용하지 않는다.

방패 밀쳐내기와 돌봉 직선 파쇄는 노멀의 단독 회피 의미를 유지한다. 추가적인 양면 봉쇄, 두 조 분담, 연속 교대 카운터, 필수 R/F/V, 탱커 교대, 강제 HP 잠금은 없다.

## HP 임계치와 실패 정책

70% 봉쇄 → 50% 무력화 → 40% 변신 → 25% 완전 봉쇄 순서다. 한 번 시작한 패턴과 그 후속 공격을 끝내고 기본 회복 시간을 준 뒤 다음 임계치를 시작한다. 높은 화력으로 여러 임계치를 넘더라도 생존한 보스는 순서대로 한 번씩 실행한다. 먼저 처치되면 남은 예약을 취소하고 기존 처치·정산으로 간다.

70%와 25%의 벽은 광장 중심 반경 12m의 실제 충돌이 있는 석벽이다. 매 시전마다 세 구역에 간격을 두고 무작위 균열을 만들며 모두 밝게 표시한다. 파쇄선이 세 균열 중 하나에 닿으면 맞은 벽 조각의 시각과 충돌을 함께 끈다. AI 표적은 세 곳 중 가까운 균열로 유도한다. 표적은 살아 있는 딜러를 우선하고 딜러가 없으면 비탱커, 마지막으로 생존자 중에서 선택한다. 조준 고정 전에 표적이 죽으면 새 대상을 정하고 **3초 조준부터 다시 시작한다**. 고정 뒤에 죽어도 고정된 직선은 유지한다. 열린 틈 바깥은 기존 18m 광장 안이다. 11초 내부 소거는 벽 안쪽에서만 판정하며, 실패는 복구 가능한 큰 피해 후 벽 제거와 회복 시간으로 끝난다.

하드 휩쓸기는 보스 기준 왼쪽 또는 오른쪽을 먼저 공격하고 0.85초 뒤 반대쪽을 공격한다. 중심 내려찍기 뒤 외곽 고리는 1.05초 후 타격한다. 뒤틀린 집행도 각각 같은 간격을 쓴다. 준비 동작과 시전 이름이 먼저 방향·순서를 알리고, 붉은 피해 범위는 타격 전 약 0.4초만 보인다. 중심 원과 도넛은 8m 경계에서 맞닿는다. 느린 이동 직업의 실제 회피 가능성은 사용자 Play 결과로 조정한다.

하드 석편 낙하는 2초 시전 뒤 석상이 일반 행동으로 돌아가고, 위에서 각 생존 대상을 추적하는 낙하가 4회 순차적으로 진행된다. 각 회는 1.1초 대상 추적 표식 → 위치 고정 금색 표시 0.7초 → 타격 전 약 0.4초 붉은 폭발 범위 → 폭발 → 0.2초 후 다음 회 순서다. 표식 대상이 고정 전에 죽으면 해당 장판을 만들지 않고, 고정된 장판은 폭발까지 유지한다. 이 낙하는 일반 공격과 겹칠 수 있지만 HP 임계치 특수 기믹은 낙하가 끝난 뒤 시작한다. 방패 공명은 하드에서 시전 시작에 파티를 5m 밀친 뒤 기존 6초 집합 표식을 유지하고, 타격 전 약 0.4초에만 분담 범위를 강조한다.

50% 무력화 실패는 큰 광역 피해 뒤 하드 기본 6초 회복을 제공한다. 25%는 출구 탈출 후 방향이 고정된 4초 돌진 준비, 1.6초 카운터, 돌진 또는 카운터, 8초 재집결, 9초 무력화 순서다. 카운터 실패는 일반 직선 돌진이며 즉시 전멸로 처리하지 않는다. 25% 무력화 실패 시 광역 피해와 6초 회복을 제공한다.

40% 변신 이후의 구현과 리소스 연결은 문서 맨 위 `거대 가고일과 역할별 협동` 항목을 따른다. 기존 등장·처치 컷씬과 사용자 자산은 변경하지 않는다.

## 검증 구분

`Tests/Run-GuardianHardChecks.ps1`: 하드 설정 시간, 임계치 순서와 1회성, 균열 판정, 카운터 중복 차단을 확인한다. `Tests/Run-GuardianNormalChecks.ps1`: 노멀 시간·순서 회귀 검사. `Tests/Run-CombatMetricsChecks.ps1 -OriginalProject C:/coopraid/coopraid3d`: Unity 참조를 사용한 관리 코드 런타임·에디터 컴파일.

Unity 원본 프로젝트 Play에서 실제 이동 회피, 벽 충돌·시각, AI 역할별 수행, 컷씬과 포탈, 보상·중간 종료 복구, 전투 시간은 별도로 확인해야 한다. 개발 명령으로 강제한 패턴은 정상 전투 결과로 기록하지 않는다. 4인 Steam 동기화는 후속 작업이다.

## 사용자 Play 확인 순서

일반 저장을 보존하려면 **원본 Unity 에디터에서 사용자가** Play 전에 `Tools → RaidRogue → Guardian → Use Isolated Save For Next Manual Play`를 선택한다. 이 메뉴는 테스트 저장 프로필만 지정하고 Play를 자동 시작하거나 캐릭터를 조작하지 않는다. Play를 끝내면 프로필 설정이 해제된다. Codex는 사용자 재허용 전까지 Unity·Steam·게임 창을 직접 실행하거나 조작하지 않는다.

1. 새 원정에서 `Stage 1 난이도: 하드`를 고르고 1명+AI 3명으로 출발한다. 보스 제목이 하드이고 시작 HP가 30,000이며 4인 역할이 1탱커·1힐러·2딜러인지 확인한다. 노멀 별도 시도에서는 제목과 30,000 HP, 기존 예고 시간을 확인한다.
2. 기본 패턴을 관찰한다. 징벌은 붉은 대상 표식과 1/2·2/2 시전 이름을 유지하며 같은 탱커에게 2초 간격 두 타를 준다. 휩쓸기는 첫 방향 타격 0.85초 뒤 반대쪽, 내려찍기는 중심 판정 1.05초 뒤 외곽 고리다. 일반 카운터 준비 4초 뒤 금색 ⚔ 신호가 1.6초만 켜지고 성공하면 6초 그로기다. 석편은 2초 시전 뒤 4회 연속 낙하하며, 석상은 그동안 자동 공격과 다음 일반 패턴을 계속할 수 있다. 공명은 먼저 밀쳐낸 뒤 집합 표식을 유지한다. 밀쳐내기는 방패 자세를 보고 피하며, 직선 파쇄는 주황 추적선·금색 고정선과 타격 직전 붉은 범위를 구분한다.
3. HP 70% 이하에서 진행 중 공격과 석편 낙하가 끝난 뒤 봉쇄 명령이 한 번 나온다. 매 시도 무작위로 표시된 균열 세 곳 중 하나로 파쇄선을 유도하고 3초 조준 고정 후 옆으로 빠진다. 5초 파쇄가 맞은 균열 벽 조각의 시각과 충돌을 함께 없애야 한다. 열린 출구로 나간 파티는 11초 내부 소거를 피한다. 다른 시도에서는 균열을 빗나가게 하여 큰 피해 후 벽과 표식이 사라지고 회복할 수 있는지 확인한다.
4. HP 50%에서 9초 보라색 무력화가 한 번 나오며 성공 시 8초 그로기, 실패 시 광역 피해와 공격 없는 회복 시간이 이어진다. HP 40%에서는 현재 HP가 올라가지 않고 도약·가고일 변신 뒤 파란 원이 열린다. 탱커 플레이어는 원 안에서 정면 카운터 4키(또는 사용자 설정 키)를 누르고 6초 버틴다. 힐러 플레이어는 2초 간격 맥동 뒤 탱커를 회복하고 종료 1.5초 예고에서 파티 충격파에 대비한다. 딜러 플레이어는 변신 전 금색 일반 카운터를 맡고, 버티기 중 보스를 공격한다. 세 역할을 바꿔 한 번씩 시도한다. 성공 시 충격파→5초 공격 기회→5초 재정렬을 확인한다. 다른 시도에서 카운터 미성공과 버티기 중 탱커 사망을 확인한다. 이후 좌우→중심→외곽 연출과 판정이 일치해야 한다.
5. HP 25%의 완전 봉쇄에서 출구 탈출→4초 돌진 준비→1.6초 카운터→8초 재집결→9초 무력화 순서를 확인한다. 카운터 실패도 옆으로 피할 수 있어야 하고, 무력화 실패 후 전투로 복귀해야 한다.
6. 전멸·재도전과 전투 중 종료·이어하기에서 벽·표식·장판·카운터가 남지 않는지, 저장된 하드 난이도가 유지되는지 확인한다. 처치 후 기존 등장·처치 컷씬, 입력·카메라 복구, 보상 1회, 중앙 포탈, 대기실 북쪽 문을 통한 Stage 2 출발을 확인한다.

가능하면 시도별 실제 전투 시간, 각 패턴 피격과 사망 원인, 실패한 균열·카운터·무력화 상황을 기록한다. 빠른 처치로 미등장한 패턴은 미검증으로 남긴다.

# 딜러 6직업 18루트 9키 통합 설계

기준: 2026-11-02 사용자 제공 상세 프롬프트 및 후속 설명. [상세 원문 사본](DPS_ORCA_SOURCE_20261102.txt)을 파일 해시가 같은 상태로 보존했다. 원래 OneDrive 파일은 수정하지 않았다. 반복 전달된 설명은 동일 명세이며 효과를 두 번 적용할 근거가 아니다. 이 문서는 비교·전환·검토용이며 상세 입력/스킬/빌드 예는 원문을 함께 따른다.

연결 기준: [탱커](TANK_REDESIGN.md), [힐러](HEALER_REDESIGN.md). 세 역할을 합쳐 12직업·36루트의 기획 범위가 마련됐다는 뜻이며, 현재 게임에 모두 구현됐다는 뜻은 아니다. 루트 ID는 직업 이름 범위를 포함해야 하며 탱커/힐러/딜러의 A/B/C 숫자를 서로 공유하지 않는다.

## 조건과 제안의 지위

- 유지할 사용자 조건: 4인 1탱/1힐/2딜, 8인 2탱/2힐/4딜, 고정 보스→대기실 진행, 직접 빌드 선택, 9키 내부 독립 콤보, 공중 상태 없음, 동료 시너지, 역할 분담과 정면 카운터. 근딜은 나이트/템페스트, 유격대는 건슬/레인저, 캐스터는 아스트로/미러. 레인저는 소환수 없는 궁수다.
- 이전 템페스트 제안의 유지: 지상 강습/완주 교차/두 창 충전·회수의 세 운영, 전용 교체/특성 목록. 명칭의 ‘창공’과 시각 연출이 공중 판정을 만들지 않는다. 이전 제안의 유지가 수치 검증 완료를 뜻하지 않는다.
- 이번 신규 제안: 나머지 5직업의 15루트, 상세 스킬·시너지·특성 및 아래 구조 확인용 수치. 템페스트와 공유하는 동작이 있어도 지배적인 판단을 복제하지 않는 방향이다.
- 시작 자원, 계수, 재사용 시간, 사거리, 보존 시간, 해금 및 명시되지 않은 입력 예외는 미정/검증 대상이다. 문서에 있는 수치도 초기안이다. DPS 균형·체감 차별화·실제 4인/8인 성능을 검증하지 않았다.

## 공통 키와 전투 규칙

| 키 | 딜러 역할 | 다른 역할과의 차이 |
|---|---|---|
| 1 | 기본 공격 콤보 | 1→1′→1″ |
| 2 | 교체 공격 콤보 | 힐러의 기본 치유 콤보와 다름 |
| 3 | 교체 보조 기술 | 공격/무력화/지원 등 |
| 4 | 교체 역할 기술 | 카운터/무력화/동료 보호 중 선택. 카운터 미장착이면 대기실 담당 확인 |
| Q | 개인 방어 | 직업 자원 없이 사용, 공격 보상을 위해 소모하도록 강제하지 않음 |
| Space | 지상 이동 | 기본 무적/장전·공격 자원 보상/위험 지점 자동 추적 없음 |
| R | 루트 핵심 | 짧게/길게/상태별 재입력, 동작·비용·남은 시간 표시 |
| F | 교체 전술 기술 | 탱커 도발/인계, 힐러 광역 회복을 복제하지 않음 |
| V | 별도 게이지 필살기 | 일반 자원/쿨타임 초기화·복제는 기본 제공하지 않음 |

2·3·4·F를 교체하고 핵심 특성 1개+서로 다른 보조 2개를 선택한다. 1·2·R만으로 핵심 루프가 성립해야 하며 특정 F/3을 자원 복구의 필수로 만들지 않는다. 1·2의 진행은 이동·일반 논글쿨·다른 콤보 선택으로 초기화하지 않는다. N2의 자기 종결과 T2 선택 4타 기회 소실은 명시된 별도 예외다. E/Z를 추가 스킬 키로 되살리지 않는다.

- 원거리 카운터도 신호·정면 조건을 유지한다. 자동 반대편 이동·후방 반사로 우회하지 않는다. 무력화/보호는 카운터 대체가 아니다. 4를 평상시 딜 때문에 반드시 소모하게 하지 않는다.
- Q/4/Space는 자원 없이 조준·영창·채널보다 우선한다. 취소한 공격 자동 완주 금지, 보존/환급은 직업에 명시한 것만 적용한다.
- 원거리의 최대 거리 강제·받는 치유 감소·근거리 급감, 고의 피격·저체력 수급, 특정 직업 동료 필수 연계는 제외한다.
- 자원은 명시된 직접 입력/완주당 한 번이다. 타수·적 수·도트·복제·추가타로 늘지 않는다. 예약은 가용 자원에서 즉시 제외하고 완료/취소 중 한 번만 정산, 상한 내 환급한다.
- 자동 폭발·재생도 적의 무적/공격 불가를 따른다. 실패한 추가타의 무한 재시도 없음. 스테이지/재도전 시작 자원은 향후 고정값, 대기실 파밍 금지.
- 기본 협공은 다른 동료의 직접 공격, 동료별 1회·유한 시간·재적용 무한 비축 금지. 자동 공격/도트/복제/추가타는 일반 협공을 생성·발동하지 않는다. 본인+다른 동료 1명을 요구하는 개별 표식은 별도 정책이다.
- 4인/8인 협공 총량을 따로 검토한다. 동일 피해 감소/이동 지원은 비중첩 갱신, 동료 보호막은 최신 힐러안의 시전자별 보관을 따른다. 합산 상한·소모/수명 정책은 아직 미정이다.

## 18루트 자원과 R 상태

아래 숫자는 프로토타입 초기안이다. ‘직접 적중’은 자동 공격을 뜻하지 않는다. 원문 예외 외의 자원 보상을 과거 구현에서 자동 승계하지 않는다.

### 나이트블레이드

기본 인장 최대5, 1·2 완주 적중 각+1. 방향 실패에도 기본 수급 유지.

| 루트 | 자원과 R | 시너지/판단 |
|---|---|---|
| N1 사각의 집행자 | 측·후방 완주로 적 귀속 정보,기본 최대2. 방향 없는 적은 완주 대체 획득. R 종언의 일격:인장2,해당 정보 있으면1 추가 소비/강화. 정보 없어도 기본R,현재 방향 무관 | 정보 소비R의 약점 공유. 유리한 위치에서 비축하고 기믹/정면 카운터 후 사용 |
| N2 무한 그림자 춤 | 인장 대신 박자0~3,1·2 직접 적중 행동당+1. R 흑월 종결은 GCD,전부 소비/직전 사용 콤보의 남은 진행만 초기화.1박 사거리 보완,2박 무력화,3박 피해. R은 박자/완주 보상 없음. F박자가 있고 진행 없어도R 가능 | 다른 콤보는 보존. 이미 정상 완주한 것을 다시 완주로 계산하지 않음. 종결 이동 지원에 재발동 제한 |
| N3 인술의 달인 | R 기폭 봉인:인장2,부적 최대1. 짧게 종언부=현재/다음 시전바 행동 종료(정상/동료 카운터/정상 기믹 중단 포함),길게 추적부=스킬 자발 이동 종료(일반 추적 제외). 조건 강화/만료 기본기폭,활성 중 새 부착 차단 | 종언 성공 후 보호,추적 성공 재접근 이동. 부적은 행동 중단기가 아니고 무적 관통 없음 |

전류0~100,기본1 직접 적중10/10/20. 2는 선택지 규칙이며 도트/자동은 수급하지 않는다.

### 템페스트 변형은 루트 전용 잠금이 아님

위 T1/T2/T3 표의 배치는 대표 운영 비교다. 여섯 변형은 호환되는 **선택 스킬 하나**에 적용한다. 연속 강습은 R 창성 강하 또는3 스카이 다이브, 사단연격은 선택2, 유영/압축은 R폭풍창 또는F씨앗 중 하나, 잔류 뇌운은 호환 강습/투사, 집중 방출은 전광 추격에 적용한다. 미장착/비호환 기술의 변형은 선택 불가 표시해야 한다. 여러 기술 동시 적용은 하지 않는다.

사단연격4타 기회는 다른 GCD 사용 시 소멸, 이동/논글쿨에는 보존한다. 이는 두 기본 콤보 진행 보존과 별도 상태다. F씨앗에 유영/압축을 적용해도 루트R의 회수·충전·환급을 자동 상속하지 않는다. 해당 변형의 F재입력/자연만료 세부 처리는 추가 명세가 필요하다.

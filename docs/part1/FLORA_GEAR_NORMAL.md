# Stage 2 노멀 — 기억의 유리 온실 : 플로라 기어

## 확정 기획과 이번 연결

이전 쌍둥이 성문지기·봉쇄된 통행로 제안 대신 박제된 정원사 플로라 기어를 Stage 2 노멀 보스로 사용한다. Stage 1의 HP 배율, 가고일 변신, 탱커 힘겨루기, 하드의 짧은 바닥 예고는 적용하지 않는다. 전투는 1탱·1힐·2딜을 기준으로 한다. 전정, 시곗바늘 가위질, 뿌리 솟구침, 박제의 꽃잎, 추모의 개화, 가지치기 돌진, 기생하는 태엽 덩굴, 영원한 박제 정원 순서로 처음 소개한 후 일반 일곱 패턴을 반복한다. 두 핵심 기믹은 겹치지 않는다. HP 50% 이하는 덩굴을 소개한 뒤 다음 휴식 경계에서 전멸기 한 번을 예약한다. HP 잠금·무적은 없다.

기존 북쪽 문→진입로→플레이어 진입→파티 소환→컷씬→전투, 처치 컷씬→F 선택 및 보상→포탈→대기실 흐름을 사용한다. 12직업 데이터의 Stage 2 `OffGcd2`는 기존 `f1/f2/f3` 세 선택을 사용하며 설정된 키 표시를 따른다. 4인 파티 정원과 공용 부활 횟수는 기존 시스템이 관리한다.

진입로의 선택적 `시들지 않는 푸른 헌화`는 `Interact` 키로 조사한다. 성향 성장 시스템은 현재 없으므로 `RaidApproachField.floraDevelopmentVoice`에서 개발용 독백을 지정한다. 조사는 대사만 표시하고 저장하지 않는다. 꽃을 건너뛰어도 입장할 수 있다.

## 초기 조정값

모든 전투 수치는 `BossController.flora` (`FloraNormalSettings`)에서 조절한다. 아래 값은 사용자 확정 수치가 아닌 첫 구현 값이다.

| 항목 | 값 |
| --- | ---: |
| 보스 HP / 전장 지름 | 36,000 / 35m |
| 기본 시전 / 패턴 간격 / 회복 | 3.5초 / 3.2초 / 2.5초 |
| 전정 / 반면 / 뿌리 / 꽃잎 피해 | 420 / 280 / 270 / 260 |
| 집합 총 피해 / 돌진 피해 | 960 / 360 |
| 뿌리 / 꽃잎 / 집합 반경 | 6 / 2.6 / 3.4m |
| 돌진 폭 / 길이 | 2.4 / 18m |
| 덩굴 제한 / 절단 거리 / 실패 피해 | 10초 / 12m / 각 300 |
| 전멸기 HP 조건 / 시전 / 씨앗 도착 | 50% / 12초 / 시작 후 2초 |
| 씨앗 밟기 / 안전지대 반경 / 바깥 피해 | 1.5m / 5.5m / 3,000 |
| 보호받은 생존자 공격력 / 지속 | +15% / 15초 |
| 이야기 대사 조건 | HP 10% 이하, 도전당 한 번 |

최저 기본 이동 속도는 현재 직업 데이터에서 7.8×0.9=7.02m/초다. 두 사람이 서로 이동하면 겹친 위치에서 12m를 벌리는 데 약 0.86초, 한 사람이 전부 이동해도 약 1.71초다. 10초 제한과 35m 전장은 일반 이동으로 충분하다. 씨앗 기본 위치는 (-7, 3), (7, 3)이며 안전지대가 가장자리 밖으로 나가지 않는다.

## 판정과 표시

- 일반 피해는 붉은 바닥 범위, 가지치기 돌진 카운터는 금색 `⚔` 문구와 선택형 효과음으로 안내한다. 기존 4키/변경 키의 카운터 기술만 `CombatCounterTarget`의 정면·거리·시간 조건으로 성공한다. 모든 직업이 성공할 수 있다. 실패한 돌진은 붉은 직선 밖으로 피할 수 있다.
- 덩굴은 생존자만 안정된 순서로 두 쌍까지 묶는다. 번호·줄·실시간 거리 표시를 준다. 기준 거리 이상이면 즉시 절단한다. 홀수 생존자는 남겨두고, 연결자 사망 시 해당 줄을 취소한다. 시간 초과 피해는 미절단 쌍에 한 번만 적용한다.
- 씨앗 두 개는 투척 시점이 지난 뒤 활성화된다. 밟기 자동 상호작용과 안전지대 생성은 호스트가 한 번만 처리한다. 최종 피해 순간 열린 안전지대 안의 생존자를 보호하며, 두 지대 중 어느 곳이든 사용할 수 있다. 이때만 +15% 공격 상태를 15초 부여한다. 중복 씨앗은 값을 더하지 않고 만료시각을 갱신한다. 전투 종료·재도전 시 제거한다.
- HP 10%의 두 대사는 공격 시전바·기믹 알림과 분리된 대사 UI에 순서대로 표시한다. 빠른 처치를 막지 않는다.
- 피해와 회복은 기존 전투 처리·기록 경로를 사용한다. 카운터 미성공, 덩굴 시간 초과, 씨앗 활성화, 안전지대 보호가 전투 이벤트에 남는다.

## 남은 연결과 검증 경계

실제 성소 장면과 다섯 번째 동료 데이터·해금 목록은 현재 프로젝트에서 확인되지 않았다. 확정 Stage 2 개인 클리어 영수증으로 `Stage2GardenCleared`를 계산하고, 성소 장면에 붙일 시각 바인딩을 제공했다. **동료 해금과 성소 자산의 실제 연결은 아직 완료되지 않았다.** 임의 직업/이름을 만들거나 파티 슬롯을 교체하지 않았다. F 세 선택은 등록된 12직업 경로에서 확인했다. 기존 레거시 직업의 단일 F 선택은 별도 데이터 작업이 필요하다.

명령 기반으로 `Run-FloraNormalChecks.ps1`의 규칙 17개, Guardian 노멀 20,052개, 하드 1,656개, `Run-CombatMetricsChecks.ps1`의 관리 코드·에디터 코드 컴파일과 지표 1,042개가 통과했다. Unity 에디터 컴파일, 실제 1인+AI 3인 플레이와 4인 Steam 동기화는 실행하지 않아 미검증이다. `research/cactbot` 두 자료는 현재 작업 폴더에 없다.

## 사용자 플레이 확인 순서

1. 개발 테스트 저장 프로필에서 Stage 1을 클리어하고 북쪽 문으로 Stage 2에 진입한다. 헌화를 조사한 경우 설정한 독백 하나가 보이고, 조사하지 않아도 전투가 시작돼야 한다.
2. 탱커 플레이어 + AI 3명으로 전정 방어, 반면·뿌리 회피, 꽃잎 산개, 집합, 금색 카운터를 확인한다. 덩굴은 두 쌍이 서로 멀어져 절단되고 AI는 직업 스킬 없이 이동해야 한다.
3. 씨앗 두 개가 열린 뒤 AI가 양쪽을 사용하고 안전지대에 남는지 확인한다. 바깥은 피해, 안쪽은 보호 및 +15% 15초가 한 번만 적용돼야 한다. 10% 대사 두 줄은 공격 안내를 가리지 않고 순서대로 나와야 한다.
4. 힐러 플레이어로 다시 도전해 전정·집합·덩굴 실패 뒤 회복 및 씨앗 이동 중 회복을 확인한다.
5. 딜러 플레이어로 다시 도전해 일반 카운터를 4키 또는 사용자 설정 키로 성공시키고, 실패 시 직선 밖에서 생존하는지 확인한다. 덩굴 중 보스를 처치해 잔여 오브젝트 정리와 기존 처치·F·포탈 흐름을 확인한다.
6. 재도전과 전멸 후 재시작에서 씨앗·덩굴·버프·HP 예약이 초기화되는지 확인한다. 실제 성소 장면에 바인딩한 뒤 꽃의 검은 재와 IX시 관, 동료 데이터 연결을 별도로 확인한다.

# Stage 3 하드 — 침묵의 종루 : 울리지 않는 대종, 캄파넬라

## 확정 흐름과 초기 구현안

사용자 확정 흐름은 강화된 일반 전투 → 잔향이 남는 I~IV 조율 → HP 40% 강제 타종 무력화 → 변신 컷씬 → 종치 봉쇄 소개 → 강화된 2페이즈 → HP 25% 마지막 조율과 봉쇄 → 처치다. 기존 노멀의 번호·발판·카운터·무력화·처치·V A/B·X시 관 경로를 재사용한다. 극한과 12회 누적 전멸 규칙은 추가하지 않았다. 아래 수치, 후속 공격, 임시 변신 외형, 구동부 HP는 **하드 초기 구현값**이며 사용자 확정 수치가 아니다.

`BossController.CampanellaHard`는 Stage 3의 hard 난이도에서만 켜진다. `campanella` 노멀 값은 수정하지 않고 `campanellaHard`에 별도 `combat`과 특수 수치를 둔다. HP 잠금·회복·새 보스 처치는 없다. 40%와 25% 조건은 현재 핵심 기믹의 종료 및 회복 경계에서 우선 처리하며 처치 확정 후 남은 예약은 정리한다. 파티는 1탱·1힐·2딜, 기존 R·F 사용 가능, V나 특정 직업·루트·카드는 필수가 아니다.

## 초기 조정값

모두 `BossController.campanellaHard` (`CampanellaHardSettings`) 및 `campanellaHard.combat` (`CampanellaNormalSettings`) 인스펙터에서 조절한다. `healthOverride=0`이므로 현재 Stage 3 노멀 HP **42,000**을 사용한다. 하드 전용 HP가 확정되면 `healthOverride`를 지정한다. `attackTempo=1.2`는 일반 시전 3.5→2.92초, 기본 패턴 간격 3.2→2.67초, 기본 자동 공격 간격, 일반 회복 2.5→2.08초에 **한 번만** 적용한다. 후속 기본값 2.4÷1.2=**2초**다. Time.timeScale과 Animator 전체 속도는 바꾸지 않는다.

`patternWeights`의 여덟 값은 사슬 압착·청동다리·억눌린 진동·봉인추·공명 분담·사슬 폭주·침묵의 조율·흔들리는 종치 순서다. 초기값은 모두 1이며 각 값 1~4회의 추첨 주머니를 섞는다. 변신 전에는 종치 후보를 제외하고, 변신 후 첫 봉쇄 다음 종치를 단독 소개한 뒤 후보에 포함한다. 같은 패턴의 즉시 반복을 가능한 한 피하고 주머니 단위로 모든 후보를 포함한다.

## 패턴과 상태

- 사슬 압착은 탱커 표식을 유지하고 2초 간격의 직접 피해 2회다. 청동다리는 한쪽→반대쪽 반면, 억눌린 진동은 중심→외곽이다. 방향과 원점은 예고 후 고정한다. 일반 붉은 피해 범위는 마지막 0.4초에 생성하고 시전바·준비 자세·표식은 계속 유지한다.
- 봉인추는 추적→1초 전 위치 고정→마지막 0.4초 범위 강조→낙하→2초 가시 잔향이다. 다음 핵심 기믹 전에 잔향을 지운다. 공명 분담은 기존 집합·분담, 사슬 폭주는 금색 ⚔ 일반 카운터를 유지한다. 모든 직업이 일반 카운터를 성공할 수 있다.
- 조율은 기존 생존자 무작위 번호 I→IV와 호스트 위치 판정을 사용한다. 담당이 미리 서 있어도 성공한다. 성공한 판에는 **성공 판 주변만** 1.5초 잔향 경고 후 한 번 폭발하며, 다음 번호와 시간을 함께 표시한다. 담당 AI는 성공 뒤 판 밖으로 이동하고 다음 AI는 자기 판을 유지한다. 실패·미배정·담당자 사망·부활·AI 대체는 노멀 정책을 따른다. 줄곧 판 위에서 기다리면 잔향 피해를 받는다.
- HP 40% 강제 타종은 공통 실제 무력화 누적을 쓴다. 성공이면 8초 그로기와 회복 뒤 변신, 실패면 불완전한 타종 충격과 회복 뒤 변신이다. 전멸·처치 시 변신 예약은 취소한다. 변신은 HP를 유지하고 기존 `RaidStageCutscenePresentation`의 카메라·입력 복구를 사용한다. 호스트 건너뛰기는 변신 종료로 확정한다.
- 변신 후 첫 종치 봉쇄는 중앙 파란 원·🛡·준비 문구, 실제 창의 밝은 카운터 안내·효과음으로 구분한다. 호스트의 기존 `CombatCounterTarget`이 정면·거리·기술 적중을 1회 소비하고 **탱커만** 성공시킨다. 성공 후 탱커는 기존 힘겨루기 입력 제한을 받으며 자기 방어기·포션, 아군 회복·보호를 허용한다. 다른 파티원은 기존 공격 가능한 쫄 타기팅으로 구동부를 파괴한다. 구동부 파괴는 1.5초 뒤 예고된 해제 충격파와 6초 그로기로 이어진다. 카운터 실패·시간 초과·탱커 사망은 실패 충격파 한 번과 회복 시간으로 이어진다. 피해 내역은 기존 전투 기록에 남는다.
- 신규 **흔들리는 종치**는 변신 후 첫 봉쇄 다음에 단독 소개한다. 첫 직선과 반대 위치의 복귀 직선이 2초 간격으로 판정된다. 이후 기존 여섯 공격·조율의 반복 후보에 들어간다.
- HP 25% **마지막 침묵의 조율**은 조율·잔향을 전부 종료→3초 재집결→동일 종치 봉쇄로 진행한다. 직전 탱커 카운터로부터 10.5초가 부족하면 시작을 남은 시간만큼 대기한다고 표시한다. 탱커 사망이면 대기 없이 준비·카운터 창 만료 후 실패한다. 쿨타임 초기화와 무적 보정은 없다.

호스트가 단계·번호·구동부·피해·성공/실패를 확정하고 전투 스냅샷은 변신·탱커·발판·잔향 상태와 기존 쫄·바닥 예고를 복제한다. 보스 처치·전멸·재도전·장면 이동에는 카운터 창, 구동부, 발판, 잔향, 접촉·클립·카메라를 정리한다. 재접속은 같은 도전 상태를 이어받으며 공용 부활 4회와 저장 체크포인트 정책은 기존 경로다. 기존 처치 컷씬·V A/B·X시 관·포탈·Stage 4 출발에는 새 지급 경로를 만들지 않았다.

## 리소스 연결과 남은 확인

`BossController.campanellaHard.transformationPresentation`에 사용자 Timeline 프리팹, `transformedVisualPrefab`·`transformedAnimatorController`에 2차 외형을 연결한다. 없으면 8초 임시 준비 동작과 콜라이더 없는 갈라진 종·구동축·종치·거미다리를 사용한다. `bellContactPath` 또는 `bellContact`는 종치 접촉점이다. `aegis`·`berserker`·`dragon`의 `catchClip`·`holdClip`·`releaseClip`·`interruptClip`, 무기 `weaponContactPath`, `visualRootPath`, `contactLocalOffset`, `visualOffset`·`visualEuler`, 효과음·이펙트를 에디터에서 교체한다. 팔라딘 방패·버서커 검신 경로는 초기값이며 드래곤 브레이커 자세는 **임시 중립 연결**이다. 루트 모션은 기존 `GuardianClashClipPlayer`가 연출 중 끄고 종료 시 복구한다. 임시 종치와 구동부는 접촉만 표현하며 프레임별 피해 콜라이더를 사용하지 않는다.

일반 공격·진자 `pendulumTrigger`·`followupTrigger`와 `attackPrepCue`·`attackImpactCue`도 하드 설정에서 연결한다. 사용자 제작 UI·Timeline·애니메이션 자산은 생성 코드가 덮어쓰지 않는다. 현재 Stage 3 노멀에서 미정인 실제 여섯 번째 동료 데이터와 성소 X시 장면 바인딩은 이 작업에서도 임의로 만들지 않았다.

## 검사와 사용자 플레이 순서

명령 검사: `Run-CampanellaHardChecks.ps1` 18개, 노멀 27개, Guardian 하드 1,656개, Flora 하드 12개, CampaignSave 31,881개(임시 파일), CombatMetrics 1,042개와 관리 코드·에디터 코드 컴파일 통과. 이는 Unity 플레이·네트워크 타이밍·실제 클립·접촉·AI 화력·카메라 복구의 실행 검증이 아니다. 전체 네트워크 검사는 기초 3,737개 통과 뒤 전투 네트워크 테스트 단계에서 중단됐다. 별도 4인 Steam 검증이 필요하다. 일반 저장·업적·클라우드는 검사에서 변경하지 않았다.

개발 테스트 저장에서 **플레이어 1명+AI 3명**으로 (1) 2연타·반면 전환·중심→외곽·봉인추 잔향·금색 카운터와 신규 진자를 개별 확인, (2) I~IV 미리 서기·잔향 이탈·오답·사망·AI 번호 유지, (3) 40% 무력화 성공·실패·전멸 분기, (4) 변신 컷씬 정상 종료·건너뛰기·HP 유지·카메라/입력 복구, (5) 탱커·힐러·딜러 플레이어 역할을 바꿔 파란 카운터·맥동 회복·구동부 파괴·실패·탱커 사망·보스 처치 중 정리, (6) 25% 마지막 조율과 카운터 쿨타임, (7) 전멸·재도전·저장 복구, (8) 개발 명령 없는 전체 완주를 확인한다. 팔라딘 방패·버서커 검신과 종치의 접촉, 드래곤 임시 자세, 유지 중 떨림·관통·발 미끄러짐, 실제 4인 Steam 동기화는 **미검증**이다.

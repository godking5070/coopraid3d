# Stage 6 하드 — 성문의 쌍둥이 문지기, 야누스

## 확정 규칙과 초기 조정값

- 사용자 확정: 공유 HP와 알파 주 어그로·오메가 예고 공격, 네 말뚝의 당김→이완→최종 당김, HP 40% 두 개체의 개별 변신, 위치를 바꾸는 푸른 교차검 더블 카운터, 노멀의 1부 최종 정산·포탈·대기실 복귀. 하드에는 극한·2부·25% 별도 기믹이 없다.
- 초기 구현안: HP **60,000**(기존 Stage 6 하드 확정값 부재로 노멀 기준), 일반 시전 3.4÷1.2초, 기본 대기 3.5÷1.2초, 피해 강조 0.4초, 탱커 2연타 2초, 반면 후속 2.6초, 중심→도넛 2.5초, 방패→창 2.8초, 사슬선 I→II 3.2초. 수치는 `BossController.janusHard`의 `JanusHardSettings`에서 바꾼다. 그로기·회복·말뚝·카운터 가능 시간은 템포 배율을 적용하지 않는다.
- 두 보스 피해는 기존 `BossJanusNormal`의 공유 HP에 들어가며 동일 범위 공격의 양쪽 중복 적중을 기존 순번 규칙으로 한 번만 반영한다. AI 관전의 공격 HP 피해 배율도 기존 공용 HP 경로에서 한 번만 적용한다. HP 잠금과 별도 변신 보스·보상은 없다.

## 전투 흐름

- 기존 여섯 공격을 먼저 순서대로 사용하고 신규 **방패와 창의 교차**, **붉은 사슬 파동**을 각각 소개한다. 이후 하드 가중치 후보에서 즉시 반복을 제외해 선택한다. 알파 강타·반면, 오메가 직선·중심은 별도 후속 판정을 사용한다. 직선 잔류는 한 번의 지연 피해 판정으로 구현해 매 프레임 피해를 주지 않는다. 낙인 표식·집합 표식은 대응 시점까지 유지한다.
- HP 60% 이하에서 현재 공격을 끝내고 `정문 봉인 재강화: 장력 조율`을 한 번 시작한다. 기존 상호작용 키는 **토글**이다. 첫 누름은 당김, 이완 신호 뒤 다시 누르면 놓기, 최종 신호 뒤 다시 누르면 당김이다. 말뚝에 먼저 도착해 기다릴 수 있으며 AI도 자기 말뚝 범위에서 같은 유지 상태로 참여한다. 네 명의 유효 당김 1.5초 → 전원 해제 확인 0.7초(허용 4초) → 네 명 최종 당김 1.5초를 32초 전체 제한 안에서 처리한다. 실패 시 1,000 기본 피해 한 번과 회복 구간으로 복귀하고 재예약하지 않는다. 누락 인원은 성공으로 위장하지 않는다.
- HP 40% 이하를 한 번 예약하고 말뚝·카운터의 안전한 종료 지점에서 변신한다. 컷씬 초기 길이 8초, 공유 HP·최대 HP 유지. 두 보스의 타기팅·정면·공격 판정은 별도로 남는다. 종료 뒤 4초 재정렬을 거쳐 전투한다. 말뚝 성공으로 끊긴 정문 봉인 사슬은 다시 붙지 않는다.
- 더블 카운터는 기존 두 타깃의 호스트 판정을 재사용한다. 첫 위치는 알파 `(-5,-4)`·오메가 `(5,-4)`, 다음 위치는 알파 `(-9,-7)`·오메가 `(9,-7)`을 번갈아 사용한다. 준비 5초·실제 창 1.6초, 직전 더블 카운터 종료 뒤 최소 12초 간격이다. 기본 4키 또는 사용자 키 설정의 실제 기술, 정면·사거리·쿨타임을 확인한다. 서로 다른 두 사람이 성공해야 공통 그로기다. 한쪽 성공 시 다른 쪽 돌진만 실행한다.
- 2페이즈는 오메가 중심→외곽 뒤 회복·집합, 사슬선 I→II 뒤 회복·더블 카운터를 순차 연결한다. 40%를 60%와 함께 통과해도 말뚝→정리·회복→변신 순서다. HP 0이 먼저 확정되면 남은 상태를 취소하고 기존 최종 처치·결과·포탈을 따른다.

## 연결 위치와 남은 리소스

- `BossController.janusHard`: HP·피해·반경·말뚝 단계·카운터 위치·시간·가중치, `transformationPresentation`, `transformedAlphaPrefab`, `transformedOmegaPrefab`, 음향·Animator 트리거. 원본 `janus` 노멀 설정은 별도로 유지한다.
- 변신 Timeline은 기존 `RaidStageCutscenePresentation`의 `BossAnimator`/`BossTransform`(알파)과 `JanusOmegaAnimator`/`JanusOmegaTransform`(오메가)을 사용한다. 직접 제작 자산을 자동으로 덮어쓰지 않는다. 리소스가 없을 때의 회전 구체·방패·할버드는 **임시 표현**이다. 원본 에디터에서 몸집·접촉점·카메라를 직접 확인해야 한다.
- 기존 전장·정문·조사와 최종 보상은 `JANUS_NORMAL.md`의 연결을 그대로 사용한다. 별도 Stage 7 진입은 없다. 성문 너머 이야기와 이리스 엔딩은 새로 확정하지 않았다.

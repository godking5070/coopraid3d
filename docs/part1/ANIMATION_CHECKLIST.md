# 아스텔라 1스테이지 애니메이션 제작 체크리스트

1스테이지 노말·하드 4인 테스트에 필요한 애니메이션 목록이다. 보스 패턴은 사용자가 결정하며, 패턴별 목록은 현재 구현을 기준으로 한 제작 후보이다. 솔로 AI와 2~6스테이지는 이번 제작 범위에서 제외한다.

작성일: 2026년 11월 6일

## 확정된 테스트 직업

이번 4인 테스트는 아래 조합으로 진행한다. 직업 선정은 확정이며 루트·교체 스킬·핵심 및 보조 특성은 아직 미정이다. 이 표는 테스트와 제작 범위이며 게임에서 다른 직업의 선택을 제한하는 설정은 아니다.

| 역할 | 확정 직업 | 모델과 무기 제작 범위 | 우선 확보할 전용 애니메이션 |
| --- | --- | --- | --- |
| 탱커 | 이지스 팔라딘 | 캐릭터·검·대방패 | 검 콤보, 방패 연격, 개인 방어, 방패 카운터, 도발·지원 동작 |
| 힐러 | 실반 오라클 | 캐릭터·지팡이·경전 | 공격 시전, 단일 치유, 광역 치유, 루트 확정 후 식물 설치·발동 동작 |
| 근접 딜러 | 나이트블레이드 | 캐릭터·검과 비수 계열 무기, 구체적 구성은 모델 설계 시 확정 | 근접 3단 콤보, 선택한 교체 공격, 개인 방어, 지상 이동 |
| 원거리 딜러 | 스피릿 레인저 | 캐릭터·활·화살 | 활 전투 대기, 조준·시위 당기기·발사, 선택한 연속·강화 사격, 지상 이동 |

레인저는 소환수 없는 궁수 기준으로 잡는다. 표의 동작은 제작 분류이며 아직 정하지 않은 루트·교체 스킬을 확정하는 것은 아니다. 팔라딘 선택 오류는 사용자 재확인으로 수정 확인을 마쳤으며, 다른 세 직업의 선택·전투와 실제 4인 연결은 별도로 확인한다.

## 제작 상태와 우선순위

상태는 `확인 필요 → 제작 대기 → 제작 중 → 파일 준비 → 게임 연결 → 플레이 확인` 순으로 관리한다. `결정 대기`는 직업·패턴 등 제작 조건을 먼저 확정해야 하는 항목이다. 기존 파일의 존재만으로 게임 연결이나 플레이 확인을 완료 처리하지 않는다.

| 우선순위 | 의미 |
| --- | --- |
| 1차 필수 | 기본 전투를 연결하는 데 먼저 필요 |
| 2차 필수 | 선정한 직업과 확정 패턴을 완성하는 데 필요 |
| 조건부 | 해당 기술·상태·패턴을 사용할 때 필요 |
| 후순위 | 기본 전투 연결 이후 제작 가능 |

## 플레이어 공통 동작

공통 뼈대와 체형을 사용하는 캐릭터는 동작을 재사용한다. 무기 잡는 자세와 접촉 위치는 직업별로 보정한다. 이동 방향 4개와 사망·유지처럼 나열된 구성은 여러 클립이 필요할 수 있다.

| 번호 | 애니메이션 | 필요한 구성과 용도 | 우선순위 | 상태 |
| --- | --- | --- | --- | --- |
| P01 | 기본 대기 | 로비에서 서 있기, 반복 | 1차 필수 | 확인 필요 |
| P02 | 전투 대기 | 무기를 든 준비 자세, 무기별 변형 | 1차 필수 | 확인 필요 |
| P03 | 전투 이동 | 전진·후진·좌이동·우이동 | 1차 필수 | 확인 필요 |
| P04 | 지상 이동기 | 직업에 맞는 빠른 이동 동작, 이동 거리와 무적 여부는 게임 규칙에 따름 | 1차 필수 | 확인 필요 |
| P05 | 피격 반응 | 이동·공격을 불필요하게 막지 않는 짧은 상체 반응 | 1차 필수 | 확인 필요 |
| P06 | 사망과 사망 유지 | 쓰러지기와 부활 전까지 유지할 자세 | 1차 필수 | 확인 필요 |
| P07 | 부활 | 일어나기에서 전투 자세로 연결 | 1차 필수 | 확인 필요 |
| P08 | 기절과 행동 불가 | 유지 시간을 조절할 수 있는 반복 자세 | 조건부 | 결정 대기 |
| P09 | 넉백과 자세 회복 | 밀려나는 반응에서 전투 자세로 복귀 | 조건부 | 결정 대기 |
| P10 | 포션 사용 | 짧은 사용 제스처, 초기에는 공통 동작 재사용 가능 | 2차 필수 | 확인 필요 |
| P11 | 상호작용 | 문·포탈 등 사용, 초기에는 별도 동작 없이 기능 확인 가능 | 후순위 | 제작 대기 |
| P12 | 승리 | 짧은 클리어 포즈 | 후순위 | 제작 대기 |

## 제작 순서

| 순서 | 작업 묶음 | 완료 기준 |
| --- | --- | --- |
| 1 | 공통 리그와 대표 직업 기본 세트 | P01~P07과 J01을 준비하고 무기 장착 위치 확인 |
| 2 | 대표 직업 게임 연결 | 이동·공격·이동기·사망·부활이 연결되고 취소·전환·발 미끄러짐 확인 |
| 3 | 테스트 직업으로 확장 | 공통 동작 재사용 후 선택한 스킬과 무기 동작 추가 |
| 4 | 보스 기본 세트 | 대기·이동·일반 공격·그로기·사망 연결 |
| 5 | 노말 패턴 동작 | 확정한 노말 패턴의 예고·동작·판정 일치 |
| 6 | 하드 추가 동작 | 확정한 변신·후속 공격·협동 동작 연결 |
| 7 | 4인 통합 확인 | 호스트·클라이언트에서 동작과 판정이 일치하고 중단·재도전 후 잔류 없음 |

## 제작과 연결 기준

| 항목 | 기준 |
| --- | --- |
| 이동 | 제자리 애니메이션을 기본으로 하고 실제 위치·거리는 게임 코드가 제어 |
| 판정 | 피해·카운터·무력화 시간은 게임 코드가 관리하고 동작·효과를 그 시간에 맞춤 |

| 취소 | 사망·기절·이동기·기술 중단 시 해당 게임 규칙에 맞는 동작으로 전환 |

| 무기 | 손·무기 소켓·방패 접촉 위치를 리그 기준으로 고정 |
| 변신 | 노말·변신 모델의 리그와 클립 공유 가능 여부를 제작 전에 확인 |
| 상태 관리 | 파일 준비·게임 연결·실제 플레이 확인을 각각 별도로 기록 |

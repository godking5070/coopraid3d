# 아스텔라 완성도 분석과 개발 우선순위

2026년 11월 16일 · 분석 기준 `ingame-move-system`, `3c9ac508b0de19565379638abaa9b265694156a4`

**가장 큰 과제는 이미 구현한 전투를 완성된 외형·동작·소리·학습 경험으로 연결하는 것이다.** 12직업과 6보스, 보상, 저장·복원, AI 파티, 전투 결과의 기반이 있다. 현재 프로토타입처럼 느껴질 가능성이 큰 이유는 이 시스템들과 실제 제작물의 완성도 차이, 첫 플레이 동선, 실패 후 설명, 클리어 후 목표다.

첫 완성 범위는 **1부 4인·6보스·현재 제공하는 12직업**으로 제안한다. 먼저 Stage 1과 기존에 선정한 대표 4직업으로 최종 품질 기준을 만든 뒤 전체에 적용한다. 대표 4직업은 이지스 팔라딘·실반 오라클·나이트블레이드·스피릿 레인저이며, 루트와 선택 기술은 기존 [애니메이션 제작 체크리스트](ANIMATION_CHECKLIST.md)에 따라 확정해야 한다. 이는 전체 게임의 직업 선택을 제한하는 제안이 아니다.

이번 분석은 현재 코드·자산 연결, 보존된 11월 15일 실행 기록, 새 명령 검사에 근거한다. AGENTS.md의 실행 제한에 따라 Unity·Steam·게임 실행과 화면 조작은 하지 않았다. 실제 화면의 미감, 타격감, 사람 파티의 재미는 플레이 확인 항목으로 남긴다.

**추가할 콘텐츠의 방향**

현재 카드 보상은 공용 7종과 해당 직업 진화 2종을 기본 후보로 사용하고, Stage 1~5의 3택1과 Stage 3의 V 해금이 있다. 전체 카드 카탈로그가 31종이라는 수치와 한 직업이 실제로 보는 후보 수를 구분해야 한다. 근거는 [CharacterEvolutionCards.cs](../../Assets/Scripts/CharacterEvolutionCards.cs), [RoguelikeCardManager.cs](../../Assets/Scripts/RoguelikeCardManager.cs)다.

로그라이크 반복성을 강화하려면 카드 수량보다 **선택 후 행동이 달라지는 조합**을 먼저 설계한다. 예를 들어 같은 직업에서도 카운터·위치 선정·지원·자원 운영 중 무엇을 중시할지가 바뀌고, 선택 화면에서 현재 빌드와의 상호작용을 알 수 있어야 한다. 이는 추가 설계 제안이며 현재 카드 효과가 연결되지 않았다는 판정은 아니다.

레이드 숙련을 중심에 둘 경우 직업별 첫 클리어·노데스·카운터/무력화 성과·개인 기록·보스 도감이 기존 구조와 잘 맞는다. 탱커·힐러의 성과도 피해량과 별도로 보여준다. 2부·8인·극한은 1부 전체 완성 기준을 통과한 뒤 별도 범위로 잡는다.

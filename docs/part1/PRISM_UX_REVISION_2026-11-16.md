# Prism UI·UX 구조 개편

같은 보라색 패널·은색 테두리를 반복하던 메뉴를 화면별 구조와 행동의 우선순위로 구분했다. 메인·직업·설정·보상·기록 화면에 서로 다른 구성을 사용한다. 현재 활성 복사본은 `Assets/UI/AstellaPrismV4/UXRevision/Applied-20261116-234602-964/`이고, 비교 기준 커밋은 `71a150f24553edbfe14ee991578bc8ef68543b0a`다.

수정·은색·자수정의 정체성은 중요한 장식과 강조에 남긴다. 이름·제목의 MaruBuri와 얇은 아웃라인, 본문의 Pretendard, 숫자의 Oxanium과 두꺼운 아웃라인을 유지한다. 전투 Prism HUD의 게이지·스킬·파티·궁극기 배치와 데이터 소유권은 이번 개편 대상이 아니다. 오른쪽 `여명의 성광` 자원명과 왼쪽 고정 `HP` 글자 숨김도 유지한다.

## 구현과 보존 기준

- `AstellaPrismUXRevision.cs`와 `Menus`·`Choices`·`Auxiliary` partial은 원본 Unity에서 명시적으로 실행하는 편집 도구다. 시작·재컴파일 때 자동으로 디자인을 적용하지 않는다.
- HUD, 대상 view 7개, 조율대, FormButton·FormText 템플릿을 합친 원본 11개를 검토 가능한 복사본으로 반입한다. 원본 SHA256, 기존 객체·참조·버튼 콜백·컨트롤 의미, 전투 HUD 스냅샷을 검사한 뒤 profile과 씬의 활성 HUD를 연결한다. 이전 HUD는 삭제하지 않는다.
- 기존 장식은 활성 상태나 입력 참조를 바꾸지 않고 시각 색상만 투명하게 처리한다. 새 장식은 포인터 입력을 받지 않는다. 씬·프리팹 YAML을 직접 편집하거나 기존 metadata GUID를 교체하지 않는다.
- `AegisRouteSelectionUI`의 새로운 미리보기 흐름은 `AstellaJobSelectionDetails`가 있는 새 UI에만 적용한다. 기존 UI는 즉시 직업 선택 방식을 유지한다. 미리보기는 실제 직업을 변경하지 않고, 확정은 기존 로컬 선택·네트워크 호스트 요청 경로를 사용한다. 승인 대기 중 중복 확정을 막는다.
- `AstellaJobSelectionDetails`는 직업 정보와 선택 표시만, `AstellaUITabIndicator`는 기존 설정 탭의 활성 표시만 갱신한다. 런타임이 폰트·크기·배치를 기본값으로 덮어쓰지 않는다.
- 제목 아웃라인은 편집 도구의 공통 보정에서 승인된 남보라 `#131022`와 크기별 1·1.3 두께로 맞춘다. 기존 마루부리 검증기를 느슨하게 바꾸지 않고 적용값을 기존 검증 계약에 맞췄다.

## 시안과 검사 경계

[상호작용 시안](prototypes/astella-ux-revision.html)은 배치와 강조 순서를 확인하는 HTML이다. Unity의 실제 화면·게임 입력·저장·호스트 승인 검증으로 집계하지 않는다. 외부 요청 없이 로컬에서 동작하며 JS 문법과 Edge 렌더를 확인했다.

[최종 UI 검사 기록](C:/Astella/ui-ux-revision-20261116/final-ui-checks/results.json)은 6종 완료·실패 0개다. 직업 선택 검사는 실제 production 선택·미리보기·확정·뒤로가기 메서드와 실제 팔라딘 정의로 28개를 통과했다. UI 묶음에는 조율대 접근·기원 권한 검사 38개와 실제 카탈로그의 파티·기원·장착 스킬·카운터·복원 표시 검사 501개도 포함한다. 모달 생명주기 27개, 마지막 편집 코드의 UI 저작 안전성 67개도 통과했다. 이 수치는 화면 렌더나 실제 네트워크 실행 횟수가 아니다.

원본 Unity에서 런타임·Editor 소스 재컴파일과 편집 도구 적용을 확인했다. 이전 적용본의 Play 증거를 이번 개편의 새 검증으로 재사용하지 않는다.

# Stage 4 노멀 · 버려진 오페라 극장 : 기억의 인형사, 마리오네트

## 범위와 판정

이 문서는 Stage 4 **노멀**의 코드 연결 상태를 기록한다. 하드 분리 설정과 변신은 `MARIONETTE_HARD.md`에 기록했으며 극한은 구현하지 않았다. 4인 구성, 기존 R/F/V, 공용 부활 4회, 체크포인트·정산·보상 경로를 재사용한다. 조종 대상, 실 HP, 카운터, 무력화, 피해, 무대 차단은 호스트가 확정하고 스냅샷으로 복제한다. 이야기 인형은 전투 타깃이나 현재 파티원이 아니다.

확정 기획: 30m × 30m 주무대, 북쪽 보조 무대, 황금 실 구출, HP 30%의 12초 무력화와 동시에 진행되는 과거 인형극, 성공 즉시 관리자 방화벽, HP 10% 대사, 처치 후 XI시 관과 일곱 번째 동료 각성 연결. 현재 이리스에게 부상 상태를 주지 않는다. 일반 공격 6종, 조종 실패 정책, 구체 피해량·시전 시간은 초기 구현안이다.

## 전투 흐름

`BossMarionetteNormal.cs`의 `MarionetteStep`은 Rest → Cast/Control/Climax → Rest 또는 Groggy로 진행한다. 기본 6종을 순환하며 일곱 번째에 `배역 지정: 배신자`를 시도한다. 생존자가 한 명이면 구출을 보류한다. HP 30%가 다른 패턴 중 지나가면 해당 패턴의 안전한 종료 후 클라이맥스를 한 번 시작한다. 10% 대사는 클라이맥스 중 핵심 안내가 끝날 때까지 대기한다. 보스 처치·전멸·재도전은 실, 조종, 표식, 범위, 연극과 방화벽을 정리한다.

일반 공격: 주연 처형(탱커 단일), 반쪽의 막(반면), 비극의 중심(중심 원), 추적 조명(생존자 전원 추적 후 고정·폭발), 관객의 박수(집합 분담), 무대 돌진(금색 일반 카운터 또는 직선 회피). 카운터는 기존 4키/사용자 입력·정면·사거리·실제 기술 적중을 사용하며 전 직업이 성공 가능하다. 탱커 전용 힘겨루기는 없다.

구출에서는 대상의 이동·공격·스킬·포션 사용을 차단하고 카메라·메뉴는 유지한다. 대상을 25도 회전시키며 실을 등 뒤 1.8m의 접근 가능한 무대 안에 만든다. 무대 끝에 붙어 겹치면 안쪽으로 옮겨 타기팅 거리를 확보한다. 실은 기존 `BossAddMinion`의 독립 HP·콜라이더·타기팅·황금 연결선·이름표를 사용한다. 다른 파티원이 실제 공격으로 실을 파괴하면 즉시 조종을 해제한다. 시간 초과는 한 번의 회복 가능한 광역 피해 후 해제하며, 대상 사망·접속 해제·전멸·처치도 해제한다. 아군 피해나 자동 스킬/자원 사용은 없다.

클라이맥스 시작 때 일반 공격·실을 정리하고 12초 보라색 무력화 게이지를 표시한다. 북쪽 보조 무대에서는 검은 태양의 신의 12인 원정대 몰살 → 단장의 심장과 시계바늘 → 시간 정지 순서로 4초씩 월드 자막을 진행한다. 사용자 프리팹의 `PlayableDirector`가 있으면 함께 재생하되 그 프리팹의 카메라 컴포넌트와 충돌 콜라이더는 비활성화한다. 무력화 성공은 연극을 즉시 중지하고 방화벽을 보조 무대 앞에 내리며 `시스템 개입: 오염된 시각 데이터 차단`을 표시한다. 실패는 한 번의 광역 피해와 회복 시간 후 복귀한다. 인형극 관람 여부는 보상 조건이 아니다.

보스 모델, Animator Controller, 각 패턴 트리거, 일반 카운터/구출/클라이맥스/방화벽 효과음, `rearPuppetStagePrefab`, `firewallPrefab`은 `BossController.marionette`에서 교체한다. 등장·처치 Timeline은 기존 `RaidLobbyLayout.bossArrivals`와 `bossDefeats`의 Stage 4 항목을 사용한다. 주무대/관객/장식과 진입로 인형은 `RaidLobbyLayout.stage4OperaTheaterPrefab`과 `stage4BrokenDollsPrefab`에 연결한다. 비어 있으면 코드 기본 도형이 나온다. 사용자 제작 연출은 자동 생성 코드가 덮어쓰지 않는다. `Stage4StorySceneBindings`를 실제 성소 장면에 붙여 XI시 닫힘/열림과 동료 시각 오브젝트를 연결할 수 있다. 일곱 번째 동료의 이름·직업·기술 데이터가 없으므로 `stage4AwakenedCompanion`은 빈 선택 참조이며 파티 정원은 여전히 4명이다.

진입로 성향 데이터가 아직 연결되지 않은 구성에서는 `RaidApproachField.marionetteDevelopmentVoice`에서 개발용 대사 분기를 선택한다. 조사하지 않아도 입장된다. 이야기 해금은 별도 저장 플래그를 만들지 않고 기존 Stage 4 적격 클리어 영수증과 정산 상태에서 `CampaignRuntime.Stage4PlayStopped`로 판정한다. 개발 세션은 기존 격리 테스트 프로필을 사용해야 한다.

## 사용자 확인 순서 · 플레이어 1명 + AI 3명

1. 격리 개발 테스트 저장에서 Stage 4 노멀로 진입한다. 인형을 조사하거나 건너뛴다. 정확한 성향 독백 하나와 등장 자막/대사, 30m 정사각형 경계와 카메라를 확인한다.
2. 여섯 일반 공격을 각각 확인한다. 추적 조명은 생존자 모두 표식한 뒤 고정되고, 돌진은 금색 일반 카운터에 성공하면 공격이 취소된다.
3. 탱커·힐러·딜러 역할을 바꿔 배역 지정을 확인한다. 조종된 캐릭터는 이동·스킬·포션이 멈추고, 다른 AI는 본체가 아닌 등 뒤의 실을 타격한다. 성공·시간 초과·대상 사망 뒤 모두 조작이 돌아온다.
4. HP 30%에서 12초 무력화 성공과 실패를 각각 확인한다. 무력화 도중 카메라와 입력을 유지하고 북쪽 인형극이 동시에 진행된다. 성공 즉시 방화벽/성공 문구가 한 번 나타나며 실패에는 그 문구가 나오지 않는다.
5. HP 10% 대사를 확인하고 처치·전멸·재도전을 반복한다. 남은 실·방화벽·표식이 정리되고 클라이맥스가 재도전에서 다시 한 번 가능해야 한다.
6. 개발 명령 없이 완주해 기존 보상·중앙 포탈·대기실·Stage 5 진입과 XI시 관 시각 상태를 확인한다. 동료 데이터가 연결되기 전에는 실제 동료 선택이 열렸다고 판단하지 않는다.

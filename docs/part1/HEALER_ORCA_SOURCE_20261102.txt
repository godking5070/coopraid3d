ORCA 전달용 통합 프롬프트 — 힐러 3직업 / 9키 / 9루트
작성 기준: 2026-11-02 대화

너는 이 보스 레이드 게임의 기획 협업자다. 아래 내용을 이후 힐러 기획에 반영해 줘.
최신 사용자 조건을 이전 참고자료보다 우선한다. 사용자 조건, 현재 설계 제안, 아직 미정인 사항을 구분한다. 이 문서는 전투 밸런스 검증 결과가 아니라 새로운 설계안이다.
기존 자료에서는 실반 오라클·세라픽 바드·블러드 아포테카리의 이름, 무기, 자연·성가·약초와 혈류의 분위기를 참고한다. 예전 스킬 효과와 패널티를 자동으로 덧붙이지 않는다.

1. 유지할 사용자 조건

- 1부 4인: 탱커 1, 힐러 1, 딜러 2. 2부 8인: 탱커 2, 힐러 2, 딜러 4.
- 진행은 보스 클리어 → 대기실 정비 → 다음 보스의 고정 구조다.
- 스킬과 특성은 직접 선택한다. 원하는 빌드를 랜덤 보상으로 얻는 구조는 사용하지 않는다.
- 직업당 3루트이며, 루트마다 반복하는 판단과 조작이 달라야 한다. 같은 루트에서도 교체 스킬·특성으로 다른 운영을 선택할 수 있어야 한다.
- 스킬 키는 9개이며, 같은 키 안에서 콤보가 변한다: 1 → 1′ → 1″, 2 → 2′ → 2″.
- 공중 상태, 공중 전용 스킬·자원, 별도 착지 입력은 없다. 이동 연출에도 지상 피격 규칙을 적용한다.
- 동료 시너지를 포함한다. 특정 직업 조합이 있어야만 작동하는 필수 연계는 피한다.
- 카운터 담당은 파티에서 배정한다. 신호 중 정면 적중으로 공격 중단·그로기를 만드는 카운터와 일반 무력화를 구분한다.
- 딜러의 카운터 선택 장착 방향을 유지한다. 아래의 힐러 4번 고정은 이번 힐러 키셋 제안이다.

2. 힐러 9키 — 이번 설계 제안

1: 기본 공격 콤보. 적을 공격하고 직업 자원을 확보한다.
2: 교체 가능한 기본 치유 콤보. 매 입력 즉시 회복하며 마지막 입력으로 직업 자원을 확보한다.
3: 교체 가능한 공격·보호·지원 기술.
4: 기본 카운터.
Q: 단일 긴급 회복 + 정화 가능한 해로운 효과 1개 제거.
Space: 지상 이동.
R: 루트 핵심 기술.
F: 기본 광역 회복.
V: 직업 필살기.

중요한 변경:
- 탱커의 F는 도발·인계, 힐러의 F는 광역 회복이다. 모든 역할에 같은 슬롯 기능을 강요하지 않는다.
- 기존 힐러 E 광역 회복을 F로 옮긴다. 기존 Z 아이덴티티는 R로 통합한다. E나 Z를 열 번째·열한 번째 스킬 키로 추가하지 않는다.
- 2번을 두 번째 공격 콤보로 고정하지 않는다. 모든 교체 선택지에 첫 입력부터 직접 회복을 보장한다.
- 교체 슬롯은 2·3이다. Q·F를 공격 전용 스킬로 바꾸거나 특정 3번에 필수 치유를 의존시키지 않는다.
- 핵심 특성 1개 + 서로 다른 보조 특성 2개를 선택한다. 루트 핵심은 1·2·R만으로 완성한다.
- 공격형 3번을 골라도 단독 힐러의 기본 회복·정화 능력이 남아야 한다.

3. 공통 조작·자원·대상 규칙

- 1·2는 GCD를 공유하며 초기 검토값은 2초다. 두 콤보 진행은 독립적으로 보존한다.
- 2의 각 단계는 그 입력 시점의 지원 대상에게 회복한다. 대상 변경으로 콤보가 초기화되지 않는다. 3타를 끝내야 첫 회복이 나오는 구조는 금지한다.
- 기본 2는 직업 자원을 소비하지 않는다. 이번 초기안에서는 별도 공통 마나를 두지 않는다. 비용은 GCD 시간과 공격 기회, 강한 기술의 자원·쿨타임으로 만든다.
- Q는 초기안으로 2충전, 순차 재충전이다. 회복과 정화가 같은 충전을 쓰므로 필수 정화 수요와 긴급 회복이 동시에 처리 가능한지 별도 검증한다.
- Q 정화는 정화 가능한 효과 1개에만 적용한다. 보스 대상 표식·강제 교대 표식 등을 자동으로 지우지 않는다. 제거 우선순위는 공통 상태이상 정책으로 명시한다.
- F는 쿨타임이 있는 직접 광역 회복이다. Q·F·4·Space는 직업 자원 없이 작동한다.
- 공격 대상과 지원 대상을 별도로 유지한다. 1·공격형 3·4는 적 대상, 2·Q·지원형 3·대상형 R은 지원 대상을 참조한다.
- 지원 대상을 한 번도 지정하지 않았으면 자신이 기본 대상이다. 지정 동료가 범위 밖·사망 등으로 무효이면 사용을 막고 안내한다. 자기 회복으로 몰래 변경하지 않는다.
- 이 차단 규칙은 2·Q·단일 대상형 3/R에 적용한다. F·자신 중심 광역 R/V·공격 기술은 무효인 지원 대상 때문에 차단하지 않는다.
- 대상 선택은 파티 UI로 처리한다. 추가 스킬 키나 동료의 별도 상호작용 키를 요구하지 않는다.
- 1 완주 자원은 유효한 마지막 타격 적중, 2 완주 자원은 살아 있는 유효 아군에 대한 마지막 직접 치유 시전으로 획득한다.
- 2가 과치유여도 동일한 자원을 얻는다. 동료 힐러가 먼저 회복했다고 자원을 잃지 않는다.
- 1·2 완주의 자원 양은 동등하다. 다단히트, 적 수, 치유 대상 수로 획득량이 늘지 않는다.
- HoT, 보호막, 반사 치유, 협공 추가타, 자동 회복은 새로운 직업 자원이나 루트 성장 횟수를 만들지 않는다. 명시된 직접 입력만 인정한다.
- 보스가 공격 불가능해도 2·Q·F와 각 루트의 지원 경로가 작동한다. 허공 공격으로 공격 자원을 받는 대신 유효한 치유 입력을 사용한다.
- 전투 전 자원 파밍은 허용하지 않는 초기안이다. 스테이지 진입·재도전 때 정해진 시작 자원으로 초기화하고 대기실의 반복 시전은 자원을 생성하지 않는다. 정확한 시작값은 미정이다.
- V는 별도 필살기 게이지를 사용한다. 직업 자원·Q 충전을 자동 초기화하지 않는다. V 수급과 해금 시점은 미정이다.
- 구체적인 스토리 해금 순서는 별도 결정하되, 필수 치유·정화가 요구되는 콘텐츠에 진입하기 전에 해당 기본 기능을 확보해야 한다. 옛 F 해금 시점을 검토 없이 복제하지 않는다.
- R 채널 중에도 Q·F·4·Space가 즉시 실행된다. 필요하면 현재 채널을 취소한다. 취소한 공격·연주가 자동 완주되지는 않는다.

4. 공통 시너지·보호막 기준

- 4인에서는 모든 루트·교체 조합이 단독 힐러 역할을 수행하는 것을 목표로 한다. 8인에서는 동일 직업 힐러 둘도 서로 자원·보호막을 빼앗지 않도록 한다.
- 이전 탱커 프롬프트의 동명 보호막 규칙을 다음처럼 보완하는 제안이다: 같은 시전자의 같은 효과는 중첩하지 않고 갱신하며, 서로 다른 시전자의 보호량은 출처별로 보관한다. 합산 상한·소모 우선순위는 공통 전투 규칙에서 정하고 검증한다.
- 같은 시전자·동일 효과 재적용은 기존 남은 보호량과 새 보호량 중 큰 값을 유지한다. 약한 재적용으로 기존 잔량을 낮추지 않는다. 지속시간 갱신과 합산 상한은 공통 정책을 따른다. 수호 악절의 재적용 금지는 별도 예외다.
- 보호막 잔량 전환은 자기 시전분만 참조한다. 남의 보호막을 회복이나 공격 자원으로 가져오지 않는다.
- 보호막 소모 우선순위는 만료가 빠른 것부터 등 하나의 명시된 규칙을 사용한다. 실제로 자기 보호막이 흡수하지 않았다면 자기 보호막 소모 효과를 발동하지 않는다.
- 같은 시전자·동일 HoT는 무제한 중첩하지 않는다. 서로 다른 시전자의 HoT는 독립적으로 유지한다.
- 실제 피격량·현재 저체력·유효 회복량을 공격 보상이나 자원 수급에 직접 연결하지 않는다. 외부 회복이 손해가 되면 안 된다.
- 공격 치유는 직접 행동 1회당 고정된 치유 계수로 판정한다. 보스 취약 배율·치명타·다단히트 수가 치유량을 곱하지 않는다.
- 4인·8인의 대상 수와 총 지원량을 따로 검증한다. 파티 인원 증가로 재귀적인 치유나 추가타가 발생하면 안 된다.
- 기본 지원 사거리와 F 범위는 단독 힐이 가능한 수준으로 확보한다. 좁은 범위의 대가로 위험한 집합을 강요하지 않는다. 구체 거리는 튜닝 항목이다.
- 전투 부활의 유무·횟수·입력 방식은 아직 별도 미정이다. 특정 힐러에게만 부활을 주거나 숨은 추가 키·무료 부활·V 부활을 자동으로 추가하지 않는다.

5. 실반 오라클

정체성: 세계수·새싹·계절·가시 장미. 회복의 성장과 전달 위치, 수확 시점을 다룬다.
자원: 세계수의 꽃봉오리 최대 3개. 1·2 완주로 각각 1개 획득. 3번 선택 기술에 기본 자원 획득을 의존하지 않는다.

9키:
1 [신록의 주문]: 빛의 잎사귀 → 정령의 숨결 → 세계수의 울림. 원거리 공격 콤보.
2 [선택 치유 콤보]: 생명의 새싹 / 숲의 맥박 / 이슬방울 중 하나.
3 [선택 기술]: 가시덩굴 / 나무껍질 / 청명한 이슬 중 하나.
4 [고목의 뿌리]: 전방 중거리 카운터. 신호·정면 조건을 만족해야 한다. 일반 뿌리 공격으로 보스를 상시 속박하지 않는다.
Q [생명의 개화]: 강한 단일 직접 회복 + 짧은 HoT + 정화 가능 효과 1개 제거. 2충전.
Space [바람걸음]: 입력 방향 지상 이동. 강제 아군 이동·체공 없음.
R [루트 기술]: 생명의 묘목 / 계절의 중계 / 장미 수확.
F [대자연의 축복]: 직접 광역 회복 + 짧은 HoT. 적 대상 불필요.
V [에덴의 만개]: 강한 광역 회복 + 후속 지속 회복. 무조건 체력 100% 설정이나 부활은 없음.

2번 선택지 — 세 기술 모두 매 입력 즉시 회복하며 완주 자원은 같다:
- [생명의 새싹]: 싹틔우기 → 잎새 감싸기 → 생명의 꽃. 단일 회복 집중, 마지막 단계에 작은 HoT.
- [숲의 맥박]: 풀잎의 파동 → 뿌리의 고동 → 숲의 숨결. 지원 대상과 주변 동료를 나누어 회복, 단일 대상 회복량 감소.
- [이슬방울]: 아침 이슬 → 맑은 물결 → 새벽의 샘. 긴 사거리와 앞 단계에 배분된 회복, 총 회복량 일부 감소.
- 루트가 주 대상을 참조할 때는 지원 대상 1명만 판정한다. 주변 동료까지 루트 성장을 여러 번 일으키지 않는다.

3번 선택지:
- [가시덩굴]: 원거리 공격과 무력화. 카운터 판정 없음.
- [나무껍질]: 지정 동료 또는 자신에게 짧은 피해 감소.
- [청명한 이슬]: 지정 동료의 정화 가능 효과 1개 제거 + 작은 HoT. 추가 정화 여유를 주지만 필수 정화는 기본 Q로 처리 가능해야 한다.

O1. 세계수의 대리자 — 대상별 성장 관리
핵심 질문: 누구의 묘목을 더 빨리 자라게 할까?
- R [생명의 묘목]: 꽃봉오리 1개로 지원 대상에게 성장형 HoT 묘목 부여. 최대 3명, 한 대상당 자기 묘목 1개.
- 초기안: 자연 성장 4초마다 1단계, 3단계에 개화 후 종료. 성장할수록 HoT가 강해지고 개화 시 대상에게 추가 직접 회복.
- 자신의 2번 직접 치유가 묘목 대상에게 들어가면 해당 묘목 1단계 성장. GCD 입력 1회당 주 대상 1명에게만 적용한다. 과치유도 인정한다.
- 빨리 개화하면 남아 있던 HoT 시간은 끝난다. 남은 HoT를 전부 복제해 추가 지급하지 않는다. 즉시 개화와 긴 유지 사이에 선택이 생긴다.
- 다른 힐러의 회복은 성장·자원·개화 보상을 제거하지 않는다.
- 묘목이 이미 있는 대상이나 최대 대상 수에서 추가 설치를 시도하면 소비 없이 안내한다. 재적용으로 성장 단계를 몰래 초기화하지 않는다.
- 흐름: R로 2~3명 준비 → 1로 공격하거나 2로 필요한 묘목 성장 → 자연/촉진 개화 → 다음 대상 준비.
- 동료 시너지: 탱커는 지속 회복에 맞춰 자기 회복을 배분하고, 다른 힐러는 개화 시점을 보고 즉시 회복을 나눠 담당한다.
- 핵심 특성 [깊은 뿌리]: 묘목 최대 2명, 각 묘목의 회복 강화. 소수 집중 관리.
- 핵심 특성 [새순 순환]: 자연 성장 간격 단축, 한 묘목의 총 회복 감소. 빠른 대상 순환.

O2. 계절의 인도자 — 공간 중계
핵심 질문: 다음 치유를 어느 위치까지 전달할까?
- R [계절의 중계]: 꽃봉오리 1개로 원격 지정 위치에 계절꽃 설치. 최대 2곳, 초기 수명 20초.
- 자신의 2 완주가 각 계절꽃에서 작은 회복 파동을 발생시킨다. 2의 원래 치유는 그대로 적용한다.
- 두 파동 범위에 겹친 아군은 같은 완주에서 중계 회복을 1회만 받는다. 파동은 자원·다른 파동을 만들지 않는다.
- 최대 2곳 상태에서 R을 새로 쓰면 가장 오래된 계절꽃을 교체한다. 설치 미리보기에서 교체 대상을 표시한다.
- 계절꽃을 통과한 동료에게 짧은 이동 속도 증가. 동일 동료 재발동에는 제한을 두며 반복 통과로 무한 갱신하지 않는다.
- 아군을 강제로 이동시키거나 추가 상호작용 버튼을 요구하지 않는다. 중계 범위 밖에서도 기본 2·Q·F는 정상적으로 작동한다.
- 흐름: 분산된 위치에 R 두 곳 → 자신은 안전한 위치 유지 → 2 완주로 원격 회복 → 이동 방향에 따라 교체.
- 동료 시너지: 산개조·원거리조가 힐러에게 모이지 않고 회복받으며, 이동 속도로 복귀를 지원한다.
- 핵심 특성 [깊은 숲]: 계절꽃 최대 1곳, 범위·회복 강화. 합류 지점 지원.
- 핵심 특성 [움직이는 계절]: R 길게 입력으로 가장 오래된 계절꽃을 커서 위치로 이동. 별도 이동 재사용 제한, 수명 갱신·자원 반환 없음. 기본 R 설치는 유지.

O3. 가시나무 마녀 — 유한한 수액의 수확
핵심 질문: 지금 수확할까, 한 번 더 성장시킬까?
- R [장미 수확] 비활성 시: 꽃봉오리 1개 소비, 자신에게 장미 수액 저장 상태 시작. 초기 지속 12초, 성장 최대 3단계.
- 저장 중 자신의 1 직접 공격 적중 또는 2 직접 치유 입력마다 1단계 성장. 한 GCD 행동당 최대 1회. 2의 과치유도 인정한다.
- HoT·도트·추가타·Q·F·3은 성장시키지 않는다. 공격을 선택하든 치유를 선택하든 성장 속도는 같다.
- 활성 중 R 재입력: 현재 성장분을 수확, 자신의 지원 범위에 광역 회복. 유효한 공격 대상이 있으면 별도의 가시 피해도 발생.
- 치유량은 단계와 고정 치유 계수로 결정한다. 적에게 실제로 준 피해·적 존재 여부와 무관하게 회복한다.
- 수확하면 저장 상태 종료. 준비 중 새 저장을 중첩할 수 없다.
- 만료까지 수확하지 않으면 저장 회복의 일부만 자동 방출하는 초기안이다(검토값 50%). 공격은 발생하지 않고 상태는 종료한다.
- 흐름: R 준비 → 1 또는 2로 성장 → 필요한 순간 R 수확 → 다시 준비.
- 동료 시너지: 다른 힐러는 수확 예정 시점을 보고 즉시 회복을 아끼거나 앞선 피해를 담당한다. 보스 공격 불가 구간도 2로 성장·수확 가능.
- 핵심 특성 [빠른 수확]: 성장 최대 2단계, 작은 수확을 자주 사용.
- 핵심 특성 [완숙 장미]: 성장 최대 4단계와 긴 저장 시간, 마지막 단계 보상 강화. 늦은 대규모 회복 준비.

6. 세라픽 바드

정체성: 천상의 하프·성가·합창. 동료와의 응답, 보호막의 층, 연주 지속을 다룬다.
자원: 공명음 최대 3개. 1·2 완주로 각각 1개 획득.
이 초기안의 음표는 같은 자원 단위다. 약사의 배합과 겹치는 별도의 음표 순서 퍼즐을 만들지 않는다.
기본 직접 회복은 Q·F·모든 2번에 확보한다. 보호막이 깨진 뒤 체력을 복구하지 못하는 힐러로 만들지 않는다.

9키:
1 [천상의 음률]: 스타카토 → 크레센도 → 소프라노 피어싱. 원거리 공격 콤보.
2 [선택 치유 콤보]: 독주 선율 / 합창 선율 / 행진 선율 중 하나.
3 [선택 기술]: 불협화음 / 앙코르 / 순풍의 행진 중 하나.
4 [포르티시모]: 전방 중거리 음파 카운터. 정면·신호 조건 유지.
Q [수호천사의 독주]: 강한 단일 직접 회복 + 작은 보호막 + 정화 1개. 2충전.
Space [글리산도 스텝]: 입력 방향 지상 이동. 기본 무적 없음.
R [루트 기술]: 협연 지휘 / 수호 악절 / 발키리의 연주.
F [성가대의 합창]: 직접 광역 회복 + 보호막. 공명음이 없어도 사용 가능.
V [영웅들의 행진곡]: 강한 직접 광역 회복 + 파티 보호막. 무제한 중첩·완전 무적 없음.

2번 선택지:
- [독주 선율]: 첫 음 → 감싸는 선율 → 독주 종결. 매 입력 단일 회복, 마지막에 작은 보호막.
- [합창 선율]: 낮은 화음 → 퍼지는 성가 → 합창 종결. 매 입력 지원 대상과 주변 동료 회복, 단일 회복량 감소.
- [행진 선율]: 발맞춤 → 순풍의 선율 → 행진 종결. 매 입력 직접 회복, 마지막에 대상의 짧은 이동 속도 증가. 순수 회복량 일부 감소.

3번 선택지:
- [불협화음]: 즉발 공격·무력화. 카운터 아님.
- [앙코르]: 직전에 자신이 사용한 Q 또는 F의 기본 즉시 회복 부분만 낮은 계수로 재현(초기 50% 검토). Q 기록은 현재 지원 대상, F 기록은 현재 자신 중심 범위를 사용한다.
- 앙코르는 정화·보호막·HoT·충전·루트 효과·특성 발동을 복제하지 않는다. Q/F 기록이 없으면 사용 불가. 자신을 다시 녹음하거나 자원을 생성하지 않는다.
- [순풍의 행진]: 주변 동료의 짧은 이동 속도 증가. 동료 이동기 쿨타임 초기화·강제 이동 없음.

B1. 용맹의 지휘자 — 동료 호출과 응답
핵심 질문: 누구에게 협연을 요청하고, 돌아온 화답을 언제 치유에 쓸까?
- R [협연 지휘]: 공명음 1개로 다른 아군 1명에게 작은 보호막과 협연 요청을 부여한다. 같은 대상에게 미완료 요청을 중복 부여하지 않는다.
- 대상이 이후 직접 공격 적중, 직접 치유 사용, 개인 방어 사용 중 하나를 수행하면 요청에 응답한다. 명중 없는 허공 공격, 자동 공격·도트·추가타는 응답 아님.
- 응답하면 바드에게 화답 1개를 전달한다. 공명음으로 되돌려 주는 것이 아니라 다음 합창을 위한 별도 상태다.
- 초기 8초 안에 응답하지 않아도 만료 시 같은 화답을 전달한다. 움직이느라 행동하지 못한 동료 때문에 지원량이 사라지지 않는다. 응답의 장점은 일찍 준비되는 것이다.
- 진행 중 요청 수 + 보관 화답 수의 합은 최대 3. 화답은 짧은 보관 시간 후 소멸하며 무한 비축하지 않는다. 사망·이탈한 요청 대상은 요청 만료 규칙으로 마감한다.
- 자신의 다음 2 완주가 보관 화답을 전부 소비하여 추가 파티 보호막인 화답 합창을 발동한다. 공명음 기본 획득은 1회만 발생한다.
- 요청 대상 수가 아니라 각 요청·화답의 상태를 UI에 표시한다. 다른 아군의 회복이 요청을 취소하지 않는다.
- 흐름: 행동할 동료에게 R → 응답으로 화답 확보 → 필요한 시점에 2 완주 → 화답 합창.
- 동료 시너지: 딜러의 공격, 탱커의 방어, 힐러의 직접 치유 모두 합창 준비에 기여한다. 별도 동료 입력 키는 없음.
- 핵심 특성 [독주 지휘]: 요청+화답 상한 1, 지정 동료의 즉시 보호 강화, 합창 비중 감소. 한 명 집중 보호.
- 핵심 특성 [합창 지휘]: 상한 3 유지, 요청 대상의 초기 보호 일부를 화답 합창으로 이동. 여러 동료의 행동을 모아 파티 보호.

B2. 성역의 수호성가 — 다층 보호와 잔량 전환
핵심 질문: 다음 피해를 위해 층을 남길까, 남은 층을 지금 회복으로 쓸까?
- R [수호 악절] 비활성 시: 공명음 2개로 범위 내 아군 각각에게 3층의 보호 악절 부여. 초기 지속 12초.
- 한 대상에게는 한 층만 활성화되고 나머지는 대기한다. 한 피해 판정에 한 층까지만 사용할 수 있다.
- 자기 활성 층이 실제 피해를 흡수하면 그 층은 소모되고, 다음 층은 그 피해 판정이 끝난 뒤 활성화한다. 같은 한 방을 여러 층으로 막지 않는다.
- 다른 보호막만 피해를 흡수했다면 자기 층은 소모하지 않는다. 같은 시전자 악절 중복 부여는 금지한다.
- 활성 중 R 재입력 [잔향 정산]: 각 동료에게 남은 자기 층을 제거하고 잔량 일부를 직접 회복으로 전환. 없어진 보호량을 그대로 다시 지급하지 않는다.
- 정산은 같은 전장에 살아 있는 최초 부여 대상에게 남은 자기 보호분만 적용한다. 이 저장분의 정산은 현재 거리와 무관하며 새로운 대상은 추가하지 않는다. 단순 층 수가 아니라 각 대상의 활성·대기 층에 실제 남아 있는 자기 보호 예산으로 계산한다.
- 정산 후에는 다음 피해를 막을 층이 남지 않는다. 자연 만료 시 미사용 층은 소멸하고 자동 전량 회복하지 않는다.
- 모든 대상의 자기 층이 소모·정산·만료되면 활성 상태를 즉시 종료하고 R은 새 수호 악절 준비로 돌아간다. 빈 정산 상태를 유지하지 않는다.
- 흐름: 연속 피해 전에 R → 층 상태 확인 → 다음 피해를 위해 유지 / 이미 체력이 낮으면 R 정산.
- 동료 시너지: 다른 힐러가 즉시 회복을 담당하면 층을 남길 수 있고, 다른 보호막이 먼저 흡수하면 자기 층을 후속 피해에 보존한다.
- 핵심 특성 [두터운 악절]: 층 수 2, 각 층 보호 강화.
- 핵심 특성 [연속 악절]: 층 수 4, 각 층 보호 감소. 여러 번의 피해 대응.

B3. 발키리의 진혼곡 — 유지할 연주와 끊을 연주
핵심 질문: 다음 악절까지 이어갈까, 즉시 중단하고 직접 대응할까?
- R [발키리의 연주]: 토글 채널. 초기안은 악절당 2초, 최대 3악절. 느린 이동 가능.
- 다음 악절을 시작할 때 공명음 1개 예약. 그 악절을 끝내면 소비를 확정하고 주변 파티 회복 및 유효 적 대상 음파 공격.
- 예약한 음표는 즉시 사용 가능 수에서 제외하며 다른 기술에 중복 사용하지 못한다. 완료 또는 취소 중 하나로만 처리하고 취소 반환은 1회만 수행한다.
- 적 대상이 없거나 공격이 실패해도 파티 회복은 작동한다. 실제 공격 피해가 치유량을 결정하지 않는다.
- 다음 악절 자원이 없으면 종료한다. 연주 자체로 공명음을 생성하지 않는다.
- 미완료 악절을 취소하면 그 악절에 예약한 음표를 상한 내 반환하고 진행은 잃는다. 이미 완료한 악절 비용은 반환하지 않는다.
- R 재입력, 1·2·3 공격/지원 입력, Q·F·4·Space가 연주를 중단하고 해당 행동을 수행한다.
- 흐름: 음표 확보 → R로 연주 → 악절마다 회복 → 다음 피해·이동·정화에 맞춰 유지/중단.
- 동료 시너지: 일정 간격의 회복을 담당하고 다른 힐러가 중간의 단일 피해를 맡을 수 있다. 한 명 힐러일 때는 Q/F로 즉시 전환한다.
- 핵심 특성 [즉흥 후렴]: 짧은 악절, 최대 2악절, 악절당 효과 감소. 이동 사이에 끼우기 쉬운 연주.
- 핵심 특성 [완주 악장]: 최대 3악절 유지, 마지막 악절 보상 강화, 앞선 악절 효과 감소. 유지할 구간을 선별.

7. 블러드 아포테카리

정체성: 약초 비약·은침·혈류. 기계 주사기보다 환상적인 약사와 시술의 분위기.
기본 자원: 진홍 영약 0~100. 1·2 완주로 각각 20 획득.
광기의 연금술사만 영약 게이지를 3칸 배합 재료로 교체한다. 게이지와 성분을 이중으로 요구하지 않는다.
자기 체력을 자원으로 소모하지 않으며, 보스를 공격할 수 없다고 기본 치유가 중단되지 않는다.

9키:
1 [은침술]: 은침 투척 → 경혈 자극 → 활력 추출. 원거리 공격 콤보.
2 [선택 치유 콤보]: 회복 처방 / 분무 처방 / 완충 처방 중 하나.
3 [선택 기술]: 예비 약제 / 산성 비약 / 완충 연무 중 하나.
4 [마비 약초탄]: 전방 중거리 카운터. 상시 보스 마비는 없음.
Q [응급 영약]: 강한 단일 회복 + 짧은 단일 피해 감소 + 정화 1개. 2충전.
Space [안개 걸음]: 입력 방향 지상 이동. 기본 무적·공중 상태 없음.
R [루트 기술]: 혈류 연결 / 조합 처방 / 연속 시술.
F [만병통치 연무]: 직접 광역 회복 + 짧은 후속 회복. 영약이나 적 대상 불필요.
V [현자의 붉은 돌]: 강한 광역 회복과 후속 회복, 유효 적에게 별도 공격. 공격 성공·피해량에 회복이 종속되지 않음.

2번 선택지:
- [회복 처방]: 활력액 → 회복액 → 재생 영약. 매 입력 단일 회복, 마지막에 작은 HoT.
- [분무 처방]: 약초 분무 → 생기 분무 → 치유 연무. 매 입력 주 대상과 주변 동료 회복, 단일 회복량 감소.
- [완충 처방]: 진정액 → 보호액 → 완충 영약. 매 입력 직접 회복, 마지막에 작은 보호막. 순수 회복량 일부 감소.

3번 선택지:
- [예비 약제]: 영약 20 추가. 광기의 연금술사에서는 마지막 1·2 완주로 얻은 성분을 1개 추가하며 기록이 없으면 회복 성분. 무작위 성분 없음.
- 예비 약제는 자체 쿨타임으로 제한한다. 자원 상한에서 실제 변화가 없으면 사용·쿨타임 소비를 막는다. 배합이 가득 차 있어도 반대 성분 교체가 가능하면 유효한 사용이다.
- [산성 비약]: 원거리 공격·무력화. 카운터와 별개.
- [완충 연무]: 자신 또는 지정 동료에게 작은 보호막과 짧은 HoT. 영약 소비 없음, 자체 쿨타임.

A1. 혈류 공명자 — 치유 연결의 재배정
핵심 질문: 내 행동으로 발생하는 추가 회복을 누구에게 보낼까?
- R [혈류 연결] 비활성 시: 영약 40 소비, 지원 대상 1명에게 작은 즉시 회복과 초기 12초 연결.
- 연결 중 자신의 1 직접 공격 적중 또는 2 직접 치유 입력마다 연결 대상에게 고정 계수의 추가 회복. 한 GCD 행동당 최대 1회.
- 2의 기본 회복은 원래 지원 대상에게 유지한다. 따라서 한 사람에게 집중하거나 두 사람을 나누어 회복할 수 있다.
- 2가 과치유여도 연결 회복은 작동한다. 실제 피해량·타수·치유량·저체력에 비례하지 않는다.
- 활성 중 R 재입력: 연결을 현재 지원 대상으로 이동. 자원 소비·추가 즉시 회복 없음, 종료 시각 갱신 없음. 짧은 재지정 간격 제한.
- 사망·거리 이탈 시 자동으로 다른 아군을 고르지 않는다. 연결 타이머는 유지하고 R로 유효한 대상에게 옮길 수 있다.
- 흐름: 탱커에게 R → 1로 공격하며 연결 회복 → 다른 동료에게 2로 직접 회복 → 피해 분포가 바뀌면 R로 연결 이동.
- 동료 시너지: 주 탱커·카운터 담당·연속 대상자 등 역할 변화에 따라 회복 흐름을 재배치한다.
- 핵심 특성 [집중 혈류]: 단일 연결의 회복 강화. 한 명 지속 보호.
- 핵심 특성 [분기 혈류]: 연결 2개에 총 회복 예산을 분할. 활성 중 R 짧게로 첫 연결, 길게로 둘째 연결 지정. 두 연결에 동일 인물을 지정하지 않는다. 연결 하나만 유효하면 그 몫만 지급한다.

A2. 광기의 연금술사 — 순서가 아닌 성분 비율
핵심 질문: 다음 처방에 회복과 촉진을 어떤 비율로 담을까?
- 이 루트의 자원은 배합 재료 3칸이다. 영약 0~100 획득·소비를 함께 적용하지 않는다.
- 1 완주: 적색 촉진 성분 1개. 2 완주: 청색 회복 성분 1개.
- 3칸 미만이면 추가한다. 가득 차 있으면 새 성분과 반대인 성분 1개를 교체한다. 전부 같은 성분이면 변화 없음.
- 성분의 순서는 효과에 영향을 주지 않는다. 빨강 1·파랑 2는 얻은 순서와 관계없이 같은 처방이다.
- R [조합 처방]: 성분 3개를 모두 소비해 기본 광역 회복과 배합 효과. 영약을 별도로 소비하지 않는다.
- 파랑 3: 재생약 — 기본 광역 회복 + 강화 HoT.
- 파랑 2·빨강 1: 방호약 — 기본 광역 회복 + 보호막.
- 파랑 1·빨강 2: 진통약 — 기본 광역 회복 + 짧은 피해 감소.
- 빨강 3: 촉진약 — 기본 광역 회복 + 동료의 후속 직접 공격을 지원하는 협공 효과.
- 촉진약의 협공은 동료별 1회, 짧은 유효 시간, 4인·8인 총 예산 별도 설정. 자동 공격·도트·추가타로 재귀 발동하지 않는다.
- 적 대상이 없어도 모든 처방의 기본 회복은 작동한다. 촉진약의 공격 지원만 유효한 후속 공격이 필요하다.
- 보스가 공격 불가능할 때도 2 세 번 완주로 재생약을 준비할 수 있다.
- 흐름: 다음 피해에 맞춰 1·2 완주 비율 선택 → 필요하면 꽉 찬 배합을 교정 → R 처방.
- 핵심 특성 [단일 성분 정제]: 같은 성분 3개 처방의 추가 효과 강화, 혼합 처방의 추가 효과 일부 감소.
- 핵심 특성 [복합 반응]: 혼합 처방 강화, 단일 성분 처방의 추가 효과 일부 감소. 기본 직접 회복은 모든 처방에서 유지.

A3. 기적의 집도의 — 후속 처치권의 배분
핵심 질문: 다음 처치를 같은 환자에게 할까, 다른 환자에게 넘길까?
- R [연속 시술] 비활성 시: 영약 40 소비, 현재 지원 대상에게 1단계 안정화 즉시 실행.
- 1단계 [안정화]: 즉시 회복 + 짧은 피해 감소.
- 2단계 [봉합]: R 재입력으로 현재 지원 대상에게 직접 회복 + 보호막.
- 3단계 [예후 관리]: R 재입력으로 현재 지원 대상에게 HoT와 다음 직접 치유 1회에 반응하는 고정 추가 회복 표식.
- 2·3단계는 최초 영약 비용에 포함되며 추가 영약을 소비하지 않는다. 처음부터 세 단계를 끝내야 회복하는 구조가 아니다.
- 같은 대상을 계속 선택하거나 단계마다 다른 대상을 선택할 수 있다. 세 명을 반드시 치료하도록 강제하지 않는다.
- 최초 시술부터 초기 12초 안에 후속 처치권을 사용한다. 만료하면 미사용 권리는 소멸한다. 각 단계 사이에 짧은 입력 간격 제한을 둔다.
- Q·F·2·이동·카운터를 사이에 사용해도 남은 시술 단계는 전체 제한 시간 안에서 보존한다.
- 예후 표식은 자신의 또는 다른 힐러의 직접 치유로 1회 발동하고 소모한다. HoT·자동 회복·예후 추가 회복 자신은 다시 발동시키지 않는다. 자원도 생성하지 않는다.
- 동료가 먼저 회복하면 남은 처치를 다른 환자에게 돌릴 수 있다. 저체력 유지·실제 치유량으로 영약·공격 보상을 주지 않는다.
- 흐름: R로 첫 환자 안정화 → 상황 확인/기본 치유 → R로 같은 환자 또는 다른 환자 봉합 → R로 예후 관리.
- 핵심 특성 [전담 주치의]: 세 처치를 같은 대상에게 사용하면 마지막 예후 효과 강화. 중간에 대상을 바꿔도 기본 시술은 정상 작동.
- 핵심 특성 [순회 진료]: 2·3단계에서 직전 단계와 다른 대상을 고르면 작은 주변 회복 추가. 같은 대상 반복 시에도 기본 시술 유지.

8. 공용 보조 특성 — 서로 다른 2개 선택

아래는 힐러 3직업 공통 후보이며 초기 수치·보호량은 미검증이다. R 자원 규칙을 바꾸거나 추가 스킬 키를 만들지 않는다.

1) [비상 비축]: Q 최대 충전 2→3. 충전 하나의 재충전 시간이 길어지는 대가(초기 +25% 검토). 초반 여유와 장기 회복 주기의 교환.
2) [긴 손길]: 2·Q의 직접 지원 사거리 증가(초기 +5m 검토). F 범위·R 중계 범위·연결 유지 거리는 바꾸지 않는다.
3) [넓은 돌봄]: F 범위 증가, F 쿨타임도 소폭 증가. 넓은 산개 대응과 사용 빈도의 교환.
4) [안전한 처치]: Q 사용 시 대상에게 작은 추가 보호막. 별도 재발동 제한, 같은 보호막 중첩 금지. 실제 정화 성공·저체력을 요구하지 않는다.
5) [잔여 처방]: 자기 Q·F 기본 직접 회복의 초과분 일부를 상한 있는 짧은 HoT로 전환. 각 대상별 상한, 같은 효과 갱신만 허용. 해당 HoT는 자원·루트 성장·새 초과분 전환을 일으키지 않는다.
6) [기동 지원]: Space 사용 시 자신과 가까운 유효 지원 대상 1명에게 짧은 이동 속도 증가. 대상 강제 이동·이동기 쿨타임 초기화 없음. 같은 효과 중첩 금지.

필수 정화·사거리·광역 회복을 특정 보조 특성으로만 해결하게 설계하지 않는다. 기본 키셋으로 처리 불가능하면 특성 필수화 대신 기본 기술이나 보스 요구량을 재검토한다.

9. 같은 루트의 빌드 예

O1 세계수의 대리자:
- 집중 양육: 2 생명의 새싹 / 3 나무껍질 / 핵심 깊은 뿌리 / 보조 안전한 처치+비상 비축. 두 명의 묘목과 탱커 보호를 관리.
- 새순 순환: 2 숲의 맥박 / 3 청명한 이슬 / 핵심 새순 순환 / 보조 넓은 돌봄+긴 손길. 여러 대상의 빠른 개화와 분산 치유.

B2 성역의 수호성가:
- 두터운 방벽: 2 독주 선율 / 3 앙코르 / 핵심 두터운 악절 / 보조 안전한 처치+비상 비축. 굵은 피해를 보호하고 즉시 회복 보완.
- 연속 보호: 2 합창 선율 / 3 순풍의 행진 / 핵심 연속 악절 / 보조 넓은 돌봄+긴 손길. 여러 번의 피해와 이동·산개 지원.

A3 기적의 집도의:
- 전담 치료: 2 회복 처방 / 3 예비 약제 / 핵심 전담 주치의 / 보조 안전한 처치+비상 비축. 한 환자의 연속 피해를 따라 3단계 처치.
- 순회 진료: 2 분무 처방 / 3 완충 연무 / 핵심 순회 진료 / 보조 긴 손길+기동 지원. 안정화·봉합·예후를 서로 다른 환자에게 배분.

9개 루트 전체에는 위의 두 핵심 특성 후보와 2·3 선택지가 있다. 같은 루트의 자유도는 기본 회복을 제거하거나 다른 루트의 핵심을 복제하는 방식으로 만들지 않는다.

10. 혼동하지 말아야 할 차이

- 오라클 묘목은 여러 대상의 성장 관리, 오라클 수액은 자신의 유한한 저장 상태를 언제 수확할지 판단하는 운영이다.
- 오라클 중계는 치유 전달 위치의 선택이며, 탱커 성채의 통과 보호막을 그대로 복제하지 않는다.
- 바드 지휘는 동료 행동의 응답을 다음 2 완주에 활용한다. 약사의 성분 배합처럼 자기 입력 기호를 조합하지 않는다.
- 바드 다층 보호는 앞으로 들어올 피해와 남은 보호량을 관리한다. 바드 연주는 자신의 행동 시간을 채널에 투자한다.
- 약사 연결은 매 행동의 추가 회복을 누구에게 보낼지 결정한다. 약사 시술은 이미 확보한 서로 다른 후속 처치권을 어느 환자에게 쓸지 결정한다.
- 약사 배합은 재료 비율이며 순서가 아니다. 드래곤 브레이커의 탄창 순서 연계와 구분한다.
- 딜힐 계열도 적이 없어지면 기본 회복이 마비되지 않는다. 공격은 선택 가능한 치유 운영 경로이며 생존의 유일한 조건이 아니다.

11. ORCA가 정리할 결과와 검증 항목

이 명세를 반영할 때 다음을 구분해서 제시해 줘.
1) 이전 자료에서 대체할 버튼 배치·패널티·자원 규칙과 유지할 직업 콘셉트.
2) 각 직업의 9키 표, 교체 2·3 목록, 루트별 R과 자원 흐름.
3) 루트별 동료 시너지, 핵심 특성, 보조 특성, 같은 루트의 다른 빌드.
4) 4인 단독 힐, 8인 동일/다른 직업 2힐, 공격 불가 구간의 운영 예.
5) 치유·보호 계수, 쿨타임, 범위, 시작 자원, 부활 정책, 스토리 해금 등 아직 미정인 사항.

우선 확인할 구조적 문제:
- 9키를 초과하거나 필수 기능을 교체 슬롯에 숨기지 않았는가?
- 기본 2의 첫 입력부터 회복하는가? 적이 없어도 자원을 확보하는가?
- Q 긴급 회복과 필수 정화 수요가 충전·재충전 안에 들어오는가?
- 다른 힐러의 회복·보호막이 내 자원·처치권을 빼앗지 않는가?
- 4인·8인의 치유·보호·협공 총량과 소모 판정이 유효한가?
- HoT·자동 치유·추가타·앙코르가 자원이나 자체 효과를 재귀 생성하지 않는가?
- 채널 취소 후 Q·F·카운터·이동이 실제로 실행되는가?
- 부활과 필살기 해금을 임의로 확정하지 않았는가?

# Stage 5 하드 — 눈뜬 절대심판, 유스티티아

## 범위와 상태 흐름

- 확정 기획: 강화된 일반 전투 → **질량 재측정 1/2·2/2** → HP 40% 변신 → **부당한 추** 단독 소개 → HP 35% **부당한 추 한 회차 → 재집결·회복 → 유죄 선고 무력화** → 일반 전투·처치. 극한과 25% 전용 기믹은 추가하지 않았다. HP 잠금과 숨겨진 피해 감소도 없다.
- 기존 `BossJustitiaNormal` 상태 기계를 하드에서 확장한다. 노멀 설정과 질량 생성·중앙 완충 띠·호스트 최종 판정·카운터·무력화·보상·저장 경로를 재사용한다. 40%와 35%를 한 번에 통과하면 변신, 첫 부당한 추, 35% 종합 순서를 따른다. 현재 패턴의 안전한 끝과 실제 회복 상태 뒤에 다음 단계가 시작된다. 보스가 먼저 죽으면 예약 단계를 취소한다.
- 초기 수치는 `BossController.justitiaHard`의 `JustitiaHardSettings`에 있다. 노멀 `justitia`에는 적용하지 않는다. Stage 5 하드 확정 HP가 없어 **노멀 52,000을 임시 기준**으로 사용한다.

| 항목 | 값 |
|---|---:|
| 보스 HP | 52,000 (임시) |
| 일반 준비·시전·기본 대기 배율 | 1.2배, 기준 시간 ÷ 1.2 한 번 |
| 일반 붉은 범위 강조 | 타격 전 0.4초 |
| 금색 일반 카운터 가능 창 | 1.6초 |
| 탱커 2타 / 반면 후속 / 중심→외곽 간격 | 2 / 2.6 / 2.5초 |

| 낙인 잔류 | 2.2초, 반경 2.7m, 피해 120 한 번 |
| 재측정 회차 / 중간 회복 | 각 11초 / 4초 |

| 35% 재집결·회복 | 5초 |
| 35% 무력화 | 10초, 요구량 500, 성공 그로기 8초 |
| 무력화 중 파티 맥동 | 2.5초 간격, 피해 140, 남은 시간과 다음 시점 표시 |
| 실패 피해 | 천칭 720, 무력화 1,020 (회복 가능한 초기값) |

탱커 타격 600, 반면·신규 직선 380, 낙인 350, 중심 380, 분담 총량 1,200, 돌진 480도 하드 전용 초기값이다. 컷씬·카운터 창·천칭 계산·이동·무력화·그로기·회복은 1.2배 계산에서 제외한다. 전체 `Time.timeScale`과 Animator 속도는 변경하지 않는다. 기본 이동 속도 7.8m/s 기준으로 양날 후속 2.4초에 최대 18.7m, 증거 말소 후속 3.2초에 최대 25.0m 이동할 수 있다. 예고된 기본 목표 간 이동은 각각 약 14m, 12m다. 실제 충돌·경로는 사용자 Play에서 확인한다.

## 질량·AI·판정

- 일반 재측정은 첫 배정과 최종 판정 뒤 4초 회복·재배치, **새 질량** 공개와 11초 두 번째 판정으로 진행한다. 첫 결과를 다시 쓰지 않는다. 이전과 우연히 동일한 배정이면 값을 회전하거나 2인 균일 후보를 바꾼다.
- 부당한 추는 좌·우 중 한쪽에 질량 2를 투하한다. 파티 합계와 추 합계를 따로 표시하며 `JustitiaHardRules.ValidWeight`로 양쪽에 실제 플레이어가 있는 정답만 선택한다. 예를 들어 `[2,2,2,2] + 추 2`는 거부한다. 후보가 부적합하면 현재 인원과 추 질량으로 계산한 유효 후보로 바꾸고 사건을 남긴다. 추는 공격 대상·충돌물이 아니다.
- 호스트가 고정된 월드 X축과 중앙 ±0.65m 띠에서 마지막 위치를 한 번 판정한다. 0 대 0, 중앙 미배정, 사망한 참가자는 성공으로 위장하지 않는다. 참가자 사망 시 기존 노멀의 회차당 1회 새 예고·재배정 정책을 사용하며 반복 변화는 취소한다.
- `JustitiaHardRules.BestMask`가 공개 질량·추·인간의 현재 쪽·AI 현재 쪽으로 최소 이동 분할을 고른다. 재측정에는 새 목표를 계산한다. AI 4인 관전에서는 네 자동 전투 캐릭터만 배정하며 관전자는 제외한다. AI 공격 피해 테스트 배율은 질량·추·무력화 수치·시간에 곱하지 않는다.
- 일반 후속과 재측정·추·무력화는 겹치지 않는다. 힐러는 재측정 실패 후 회복하고, 35%에서는 재집결 후 맥동 사이에 회복·무력화를 판단한다. 실패 피해는 마지막 예약 맥동과 같은 순간에 중복되지 않는다.

## 리소스 연결

- `BossController.justitiaHard`: 하드 HP·피해·반경·시간·가중치, 양날 반경 `doubleEdgeRadius`, 외곽 반경 `ringOuterRadius`, 추 위치 `weightOffset`와 `weightVisualPrefab`, 변신 `transformationPresentation`, 2차 형태 `transformedVisualPrefab`/`transformedAnimatorController`, 변신·추·맥동 음향, 양날/증거/추 트리거. 1페이즈 모델·Animator를 비워두면 노멀 `justitia`에 연결한 사용자 자산을 재사용한다.
- 변신 Timeline이 없거나 실패하면 임시 황금 구체와 8초 연출을 사용한다. 2차 모델이 없으면 균열 몸체·노출 구동축·저울 날개·대검 임시 형상을 사용한다. 모델 콜라이더는 비활성화하며 기존 보스 타기팅과 실제 피해 범위는 별도다. 사용자 제작 리소스를 자동 생성 코드가 덮어쓰지 않는다.
- 등장·처치 컷씬은 기존 Stage 5 `RaidLobbyLayout.bossArrivals`·`bossDefeats`와 정산 흐름을 사용한다. 성소 XII시·동료 데이터 바인딩은 노멀의 `Stage5StorySceneBindings`·`RaidLobbyLayout.stage5AwakenedCompanion` 위치를 유지한다. 데이터 미정으로 실제 여덟 번째 동료의 이름·직업·스킬 해금은 여전히 미완성이다.

- AI 4인 관전: Stage 5 **하드**를 100% 피해 배율로 시작해 네 AI만 질량을 받는지, 1/2와 2/2에 서로 다른 배치를 계산하는지, 추를 포함한 합계를 맞추는지, 35%에서 힐러 회복과 무력화가 병행되는지 확인한다. 배율 변경 기록과 질량·추·무력화 불변도 확인한다.
- 실제 AI 성공률, 느린 캐릭터 경로, 모델·Timeline·카메라 복구, 시각 가독성, 동일 세션 재접속·4인 Steam 동기화·저장 후 실제 정산은 사용자 검증 전까지 **미검증**이다.

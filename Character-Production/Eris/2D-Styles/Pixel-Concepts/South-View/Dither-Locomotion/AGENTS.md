# 이리스 2D 모션 미리보기

- 모션을 수정하기 전에 아틀라스 PNG를 검수용으로 보관합니다. 작업 후 `Review-Locomotion.ps1 -BaselineAtlas`에 해당 파일을 전달해 전후 비교를 만듭니다.
- 결과는 왼쪽 수정 후, 오른쪽 수정 전의 동기화 미리보기로 공유합니다. 이전·다음, 재생·정지, 속도, 프레임 번호 선택을 제공하고, 번호를 누르면 양쪽을 같은 장에 정지시킵니다.
- Orca 채팅에서 생성된 비교 화면을 첨부합니다. 휴대폰에서 볼 때는 해당 모션의 번호별 PNG와 반복 GIF도 함께 공유합니다.

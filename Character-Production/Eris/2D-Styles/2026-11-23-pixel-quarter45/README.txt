이리스 45도 쿼터뷰 도트 시안 5종 (2026-11-23)

기준
  원화: godking5070/캐릭터-컨셉아트 브랜치
        Character-Production/Eris/Texturing/Reference/Iris_Concept_UserReference.png
  느낌: 사용자가 보낸 45도 온라인 RPG 도트 스프라이트(76×96 화면 캡처)
        검은 1px 외곽선, 파스텔 명암, 약 3등신 SD. 캡처 이미지는 저장소에 넣지 않았습니다.
  방향: 45도 내려다본 시점, 이리스가 화면 왼쪽 아래(남서)를 보는 대기 자세.

만든 방식
  이미지 생성 없이 직접 찍은 도트입니다. 원화의 후드·머리·꽃·코트·소매·부츠를
  부위별 도형으로 잡고 8배로 세밀하게 나눈 뒤 다수결로 픽셀을 정했습니다.
  그다음 명암·외곽선·눈·입·단추·자수를 픽셀 단위로 넣었습니다.
  tools/iris_pixel.py 하나로 5종을 모두 다시 만들 수 있습니다.

결과 (투명 배경 PNG, 무접미 파일이 실제 도트 크기)
  01-classic-mmo       클래식 MMO 도트      47×75   검은 1px 외곽선, 4단 파스텔, 머릿결 선. 참고 이미지와 가장 가까움
  02-hd-detail         HD 고밀도 도트       89×144  5단 명암, 색이 든 외곽선(셀아웃), 큰 눈과 별 동공
  03-tiny-sd           초미니 SD 도트       34×49   약 2등신, 큰 머리·작은 몸, 2px 눈
  04-pastel-lineless   파스텔 무외곽선 도트 53×85   검은 선 없이 주변 색으로 외곽, 밝은 파스텔
  05-retro-dither      레트로 디더 도트     47×75   제한 팔레트, 남색 외곽선, 그림자·머리 그라데이션을 체크무늬 디더로 표현
  *-x4/x6/x8.png       같은 그림을 정수배로 키운 확인용
  sheet.png            5종을 비슷한 화면 크기로 키워 보라색 바닥 위에 나란히 둔 비교
  sheet-native.png     5종을 실제 도트 크기로 나란히 둔 비교(-x3은 3배 확대)
  index.html           Orca·브라우저에서 여는 비교 페이지. 바닥색을 바꿔 볼 수 있음

다시 만들기
  Blender에 들어 있는 Python(numpy 포함)으로 실행합니다.
  "C:\Program Files\Blender Foundation\Blender 5.3\5.3\python\bin\python.exe" tools/iris_pixel.py 출력폴더 [01 02 ...]
  도형 좌표는 build_shapes(), 그림체별 크기·비율·팔레트·외곽선 규칙은 STYLES에 있습니다.

확인한 것
  5종 생성과 실제 크기·확대본·바닥 합성 비교를 직접 눈으로 확인했습니다.

미확인·한계
  Unity 임포트와 실제 게임 화면, 다른 캐릭터와 함께 놓았을 때의 크기 비교는 아직 하지 않았습니다.
  대기 1장만 만들었습니다. 8방향·걷기·달리기 프레임은 고른 그림체로 이어서 만듭니다.
  얼굴이 정면에 가깝게 보여 45도 회전감이 약할 수 있습니다.
  흰 후드와 소매가 붙는 오른쪽은 작은 크기에서 한 덩어리로 보일 수 있습니다.
  초미니 SD는 소매와 후드 자락이 구분되지 않습니다.

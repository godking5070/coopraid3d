이리스 2D 스프라이트 시안

index.html에서 30가지 그림체를 비교할 수 있습니다. 미리보기 높이와 밝은 배경,
어두운 배경, 투명 격자를 바꿔 게임 화면 크기에서 실루엣을 확인하세요.
그림을 클릭하면 확대하고, PNG 버튼으로 개별 리소스를 받을 수 있습니다.

Front-Variations/index.html
사용자가 고른 도트 그림체를 정면 전신 대기 자세로 풀어낸 추가 시안 5장입니다.

Eight-Directions/index.html
기본형 정면 도트를 기준으로 그린 8방향 대기 자세와 한 장으로 모은 시트입니다.

Sprites 폴더
이리스 원화와 최신 3D 작업본을 참조한 전신 대기 자세 30장입니다.
아이보리 후드, 남색 의상, 금색 장식, 분홍빛 머리끝, 별이 있는 파란 눈을
픽셀, 셀·만화, 그래픽, 회화, 수공예, 일러스트 그림체로 제안합니다.
이미지는 각각 알파 채널이 있는 PNG입니다. 원본 픽셀 크기는 파일마다 다릅니다.

Motion 폴더
01 콘솔 저해상도 도트와 06 선명한 셀 채색의 걷기·별꽃 마법 예시가 있습니다.
동작마다 여섯 포즈를 3열 2행의 투명 PNG 한 장으로 제공합니다.
걷기는 반복합니다. 별꽃 마법은 대기 → 준비 → 모으기 → 발동 → 후속 동작 → 복귀 순서입니다.
각 동작의 발 기준점을 고정했고, 마법 발동 시점은 네 번째 칸입니다.

sprite-manifest.json에 PNG 크기, 칸 크기, 발 기준점, 프레임별 재생 시간과
마법 발동 이벤트가 있습니다. 좌표는 이미지 왼쪽 위부터 시작하고,
프레임은 첫 행의 왼쪽부터 오른쪽으로 읽은 뒤 다음 행으로 넘어갑니다.
Unity 원본 프로젝트에서 확인할 때는 선택한 PNG를 2D Sprite로 임포트한 뒤
모션 시트를 manifest의 칸 크기와 발 기준점으로 나눌 수 있습니다.

imagegen-prompts.txt에 기본 내장 ImageGen의 참조와 사용한 프롬프트가 있습니다.

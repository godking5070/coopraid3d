- **8방향 대기 시트 순서** (좌→우, 위→아래):
  - 1행: `↓ 정면(S)` · `↘ 우전방(SE)` · `→ 우측(E)` · `↗ 우후방(NE)`
  - 2행: `↑ 후면(N)` · `↖ 좌후방(NW)` · `← 좌측(W)` · `↙ 좌전방(SW)`
- **4방향 달리기 시트 순서** (행당 8프레임 루프):
  - 1행: `↙ 좌전방(SW)` · 2행: `↘ 우전방(SE)` · 3행: `↖ 좌후방(NW)` · 4행: `↗ 우후방(NE)`
- **Unity Normalized Pivot (좌하단 원점)**: 모든 프레임 공통 **`(0.5, 0.111111)`**

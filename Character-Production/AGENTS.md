# 캐릭터 2D 모션 제작

- 새 걷기·달리기 등 캐릭터 모션은 해당 캐릭터의 3D 모델에 목표 동작을 적용하는 것부터 시작한다. 사용자가 원하는 Mixamo 등 3D 모션을 선택하고, 맞는 원본 FBX가 프로젝트에 있으면 재사용한다.
- 게임 카메라와 같은 방향과 각도에서 한 주기를 일정 간격으로 렌더한다. 같은 어깨·팔꿈치·손목, 골반·무릎·발목의 화면 좌표와 가림 순서를 2D 포즈의 기준으로 삼는다. 마지막 프레임에서 첫 프레임으로 이어지는 구간도 같은 궤적을 따른다.
- 2D 시트와 함께 원본 모션, 샘플링 시각, 카메라, 피벗을 기록한다. 프레임 순서와 재생을 확인하고, 특히 소매와 손의 위치를 양옆 프레임과 비교한다.
- 2D 모션을 수정할 때는 대상 그림체마다 한 주기의 전신 프레임 전체를 처음부터 새로 제작한다. 기존 2D 원화는 캐릭터의 얼굴·의상·부츠 비율과 그림체를 맞추는 참고로 사용한다.
- 새로 그린 전신 프레임은 같은 캔버스와 피벗에 맞춘다. 실제 재생 속도와 반복 경계에서 소매·손·발이 가려졌다 나타나는 구간과 발을 디디는 자세를 확인한다.

# 아스텔라 · 30° 좌우 달리기

첨부된 수호기사와 같은 도트 그림체로 이리스 포함 13종의 좌우 달리기를 그렸습니다. 캐릭터당 오른쪽과 왼쪽에 8장씩, 총 208장입니다. 의상, 눈 크기와 비율, 머리와 장비의 도트 윤곽은 초기 8방향 대기 시트(`9929b6d`)를 참고했습니다. 13종의 대기 시트는 Unity 원본 프로젝트에서 쓰는 텍스처와 SHA-256이 일치했습니다.

카메라 고도는 수평에서 30°입니다. 같은 직교 가이드로 두 방향을 그려 정수리와 어깨 윗면, 가까운 부츠와 먼 부츠의 깊이가 드러나도록 맞췄습니다. 골반과 다리의 위치에도 동일한 30° 투영을 적용했습니다. 1번과 5번에서 지지하는 발이 교대하고 4번과 8번에서는 두 발이 들립니다.

## 보기

- `index.html`에서 캐릭터와 방향을 선택합니다. 오른쪽 메뉴에서 직전·다음 프레임, 게임 원본 대기 스프라이트, 직전 달리기 시트를 비교합니다.
- **전장 크기로 보기**를 펼치면 첨부된 레이드 화면과 같은 크기로 현재 프레임을 봅니다.
- 캐릭터 폴더에 게임용 PNG 시트, 번호별 PNG, 모바일에서도 여는 반복 GIF를 넣었습니다.

## Unity 가져오기

게임용 시트는 투명 1024 × 320px입니다. 위 행은 오른쪽, 아래 행은 왼쪽이며 각 행의 열은 1–8번입니다. 원본 프로젝트의 Sprite Editor에서 128 × 160px 셀로 자르고 왼쪽 아래 기준 피벗을 (0.5, 0.2)로 설정합니다. Point 필터와 압축 없음을 사용합니다. 프레임 길이는 `roster.json`에 있습니다.

## 검수

각 방향에서 8→1과 반대발로 넘어가는 구간까지 돌려보고 어깨와 손의 움직임, 치맛단과 발목의 경계를 확대했습니다. `verify-assets.ps1`은 208장의 연결·알파·여백·중복, 13개 GIF의 반복과 프레임 길이, 원본 대기 시트와 납품 파일의 해시를 확인합니다. `pixel-audit.json`에는 투영 각도, 몸통 움직임, 머리 위치를 맞춘 얼굴 픽셀, 착지와 416개 정강이·부츠 연결 측정값을 기록했습니다.

Unity 플레이와 실제 모바일 기기에서의 재생은 미검증입니다.

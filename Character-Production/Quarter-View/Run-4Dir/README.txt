# 아스텔라 · 수평에서 30° 내려다보는 달리기

아스텔라 원화 12종과 이리스의 전신 달리기입니다. 캐릭터마다 아래·오른쪽·위·왼쪽에 8장씩, 총 416장입니다. 첨부된 레이드 화면에 맞춰 낮은 시점에서 보이는 정수리, 어깨, 신발의 면을 다시 그렸습니다. 골반·무릎·발목은 30° 직교 투영으로 배치했습니다. 착지와 밀기에 맞춰 골반과 가슴을 움직이고, 접힌 팔과 장비, 머리끝과 옷자락을 같은 주기에 맞췄습니다.

`index.html`에서 캐릭터와 방향을 선택합니다. 1–8번을 눌러 멈추고 오른쪽 메뉴에서 앞뒤 프레임이나 수정 전 시트를 비교합니다. 확대 메뉴에서 표정, 손과 장비, 치마와 부츠를 확인할 수 있습니다. **전장 크기로 보기**는 첨부 화면 일부에 약 72px 높이로 같은 셀을 표시합니다.

## 파일

- `*_Run_4Dir.png`는 1024 × 640 px 투명 시트입니다. 행은 아래·오른쪽·위·왼쪽이며 열은 1–8번입니다.
- `*_Frames.png`는 번호가 붙은 32장, `*_Preview.gif`는 네 방향을 함께 반복하는 파일입니다. `roster.json`에 캐릭터별 여덟 프레임의 길이와 파일명이 들어 있습니다.
- Unity 원본 프로젝트에서는 128 × 160 px로 자릅니다. 왼쪽 아래 기준 피벗 (0.5, 0.2), Point 필터, 압축 없음으로 확인합니다.

## 프레임 검수

1. 전체 방향의 32장을 펼쳐 머리 크기, 어깨 폭, 허리부터 발끝까지의 비율을 비교합니다. 좌우의 비대칭 장비가 캐릭터의 같은 쪽에 있는지 확인합니다.
2. 1×와 0.5×에서 8→1을 포함한 한 주기를 확인합니다. 1→2→3과 5→6→7에서는 번갈아 지지하는 다리와 상체가 같은 리듬으로 움직이고, 4번과 8번에서는 발이 떨어지는지 봅니다.
3. 얼굴 픽셀을 위치에 맞춰 비교하고, 팔·손·장비와 치마·다리를 확대합니다. 뒤에서 보이는 소매와 가려진 손, 발목·부츠의 연결, 옷자락 경계를 따로 봅니다.
4. `verify-assets.ps1`은 416장의 알파, 여백·연결·중복, 13개 GIF의 루프와 시간, 파일 해시를 검사합니다. `pixel-audit.json`에는 각 방향의 8개 전환과 832개 정강이·부츠 연결, 뼈 길이와 정렬한 얼굴 픽셀 측정값이 들어 있습니다.

Unity 원본 프로젝트와 실제 휴대폰 재생은 미검증입니다.

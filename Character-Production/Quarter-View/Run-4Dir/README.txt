# 아스텔라 4방향 달리기

이리스와 같은 둥근 치비 그림체로 원화 12종의 달리기를 제작했습니다. 캐릭터마다 아래·오른쪽·위·왼쪽에 8장씩, 총 384장입니다. 출처는 아스텔라 캐릭터 컨셉 원화와 50° 쿼터뷰 대기 스프라이트입니다. 성격은 원화의 표정과 자세, 장비를 다루는 방식에서 해석했습니다.

`index.html`에서 캐릭터와 방향을 고릅니다. 아래 번호를 누르면 해당 위치에 멈추고, 오른쪽에서 직전 또는 다음 프레임을 나란히 볼 수 있습니다. 머리·표정, 팔·손·장비, 치마·다리·부츠를 확대할 수 있습니다. 같은 폴더의 캐릭터별 PNG와 GIF 링크는 HTML 아래에 있습니다.

## 리소스 규격

- `*_Run_4Dir.png`는 1024 × 640 px 투명 시트입니다. 행은 위에서부터 아래·오른쪽·위·왼쪽, 열은 1–8번입니다.
- Unity 원본 프로젝트에서 128 × 160 px 그리드로 자릅니다. Pivot은 왼쪽 아래 기준 (0.5, 0.2)입니다. Point 필터와 압축 없음을 사용합니다.
- `*_Frames.png`에는 번호가 붙은 32장이 있고, `*_Preview.gif`는 네 방향을 함께 반복합니다. `roster.json`에는 파일 경로, SHA-256, 캐릭터별 8장 재생 시간이 들어 있습니다.
- 1번에서 왼발이 닿고 5번에서 오른발이 닿습니다. 4번과 8번은 공중이며, 양옆 보기에서 화면 가까운 다리는 같은 쪽 다리로 유지됩니다. 앞뒤 보기는 보폭에 따라 발의 깊이가 서로 교대합니다.

## 프레임 검수

1. 32장 전체를 펼쳐 방향별 머리와 장식, 같은 표정, 장비 쥔 손의 위치를 확인합니다. 위 방향에서 앞쪽에 접힌 손은 몸에 가려지고, 바깥으로 보이는 소매는 머리 윤곽과 이어지는지 봅니다.
2. 팔·손과 다리·부츠를 확대해 손목과 발목의 연결, 반대편 다리가 가려지는 순서, 치맛단과 허벅지의 경계를 봅니다. 1↔5번, 2↔6번, 3↔7번, 4↔8번에서는 발 역할이 교대하는지 확인합니다.
3. 정지 비교 후 1×와 0.5×로 재생합니다. 8→1을 포함해 머리카락, 팔과 신발이 갑자기 커지거나 사라지는 구간을 한 프레임씩 확인합니다.
4. Windows PowerShell에서 `verify-assets.ps1`을 실행해 384장의 크기, 알파, 연결 상태, 프레임 중복, GIF 반복과 시간을 확인합니다. `pixel-audit.json`에서 제작 시 측정한 착지 좌표 이동량과 머리 픽셀 비교 결과를 확인할 수 있습니다.

수호기사의 고정된 발 끝과 소매·장비 주변 윤곽을 정리했습니다. 랜스 창기사의 위 4·8번에 보이던 반대쪽 부츠 가장자리 픽셀을 없앴습니다. 시간술사의 회중시계를 위쪽 보기에서도 캐릭터의 오른손에 배치했습니다. 제작용 확대판에서 12종의 좌우와 프레임 전후를 두 차례 검토했습니다.

Chrome 데스크톱과 390px 모바일 에뮬레이션에서 48개 방향 주기를 각각 재생하고, 양쪽 캔버스의 확대 이미지와 원본 셀이 일치하는지 비교했습니다. GIF 12개에서 여덟 장의 디코딩, 반복 플래그와 재생 시간을 확인했습니다. Unity와 실제 휴대폰에서의 재생은 미검증입니다.
